# 단계6Q — 퀸 기술별 자동시전

퀸의 감염·인스네어·브루들링 생성·패러사이트를 각각 켜고 끌 수 있다. 기본은 모두 꺼짐이다. 연구·에너지·소유권·시야·몸체 사거리·수송·스테이시스·공유 마법 대기는 수동 기술과 같은 최종 검사를 사용한다. 자동 접근이나 무료 연구/에너지는 없다. 선택한 아군 퀸의 설정만 렌더에 제공한다.

## 조작과 우선순위

명시적인 네 버튼은 연구/에너지 부족 중에도 설정할 수 있고, 일시정지 중에는 비활성화한다. 여러 퀸 중 일부만 켜져 있으면 `일부 켜짐`으로 표시하고 누르면 전체를 켠다. 모두 켜져 있으면 전체를 끈다. 부대 슬롯의 설정을 등록하는 퀸들에게 상속하며, 개별 일부 선택 변경은 슬롯 기본값을 덮어쓰지 않는다. 다른 종류 유닛으로 슬롯을 바꾸면 퀸 기술 기본값을 정리한다. 기존 힐링·스테이시스 토글 정책은 유지한다.

이동·공격·정지·위치 사수·순찰·수동 기술·수송 명령을 받은 뒤20틱(1초) 기다린다. 대기·위치 사수·이동 완료 상태에서만 판단한다. 설정 켜기와 부대 등록도 같은 유예를 준다. 안정적인 ID 순서로5틱마다 최대4기씩 회전 검사하고, 한 퀸은 한 번에 한 기술만 사용한다. 성공 후 시야 캐시를 갱신한다.

1. **감염**: 보이는 사거리 안의 완료된 적 테란 커맨드 센터 중 체력50% 미만인 대상을 고른다. 체력·거리·ID 순으로 결정하며 기존 영 에너지 비용을 유지한다.
2. **인스네어**: 아직 느려지지 않은 적 공격 유닛2기 이상이 맞고, 시전자 외 맞을 아군이 없는 지점을 고른다. 임시 브루들링은 적 군집 점수에서 제외한다. 가장 가까운16개 표적과 각각의 가까운 이웃 중간점을 후보로 제한하고 적 수·거리·좌표로 결정한다. 최소 군집 수는 전체 적 유닛 수가 아닌 새 효과를 받는 유효 공격 유닛 수다.
3. **브루들링 생성**: 총 생산비(미네랄+가스, 묶음 생산은 개체당)100 이상인 유효한 지상 공격 유닛을 가격·거리·ID 순으로 고른다. 연구가 끝나고 유효 표적이 실제 사거리 안에 있으면150에너지를 모으는 동안 패러사이트를 보류한다. 일꾼·대상 부적격·사거리 밖·연구 전에는 이 예약을 하지 않는다.
4. **패러사이트**: 내 감염 비트가 없는 보이는 적을 고른다. 실명하지 않은 탐지기 → 공격 유닛 → 그 외 비일꾼 → 일꾼 순이며 가격·거리·ID로 결정한다. 임시 브루들링은 제외한다.

전략 AI 전체나 원작 자동시전의 복제가 아닌 현재 게임의 선택 기능이다. 수동 인스네어의 아군 피해 가능성이나 수동 브루들링 대상 정책은 바꾸지 않는다. 감염된 테란의 자동 근접 자폭은 기존 전투 규칙을 계속 사용한다.

## 연습·저장

`/stark-rift-dev` → **감염 연습**에서 감염/패러사이트를 확인한다. 퀸 선택 → 감염 자동 켜기 → 손상된 센터 왼쪽 위 빈 지점으로 이동하면 유예 후 자동 감염한다. 패러사이트는75에너지 회복 후 주변 적 SCV를 대상으로 작동한다.

**저그 → 특수 연습**의 새 게임에는 오른쪽 질럿2기를 둔다.5번 부대 퀸으로 인스네어 자동 켜기 → 퀸즈 네스트에서 유료 연구 → 자연75에너지 회복 후 두 질럿 자동 감속. 브루들링 연구 후4번 부대 퀸을22,24 근처 빈 지점으로 옮기고 브루들링 생성/패러사이트 자동을 켜면150에너지까지 예약한 뒤 질럿을 처리한다. 기존 저장에는 질럿·자원·설정을 추가하지 않는다.

엔진0.27.0-stage6q, 저장/스키마26, 프로토콜27. 경제 데이터 버전은6P와 동일하다. 과거 형식6..25의 원본 체크섬·버전별 데이터/전투/시야 해시를 검사해 이행하며,25 원문은 `.stage6p-backup`에 그대로 보관한다. 기존 감염 건물/생산·자폭 결과·브루들링 절대 수명·패러사이트·에너지·부대·명령·RNG를 보존한다. 옛 저장에 새 자동시전 상태/슬롯 기술을 끼워 넣은 위장을 거절한다. 현재 상태는 살아 있는 퀸 참조·고유 정렬·기술 순서·유예 시간 범위를 검사하고 죽은 퀸 참조를 지운다. 부대 등록의 선택 속성에 `undefined`를 기록하지 않아 원본/복원 상태의 정규 JSON 비교를 유지한다.

## 검증과 후속

단위 검사는 기본 꺼짐·원자적 토글·우선순위·연구/에너지·시야/사거리·아군 배제·새 군집·가치와 예약·탐지기와 기존 감염 제외·수동 유예·이동/수송/스테이시스·공유 대기·회전 예산·부대 상속·저장 결정성·과거 위장 거절·렌더 소유권을 포함한다. 브라우저 검사는360/390 세로 터치, 실제 Worker/Pixi, 유료 연구·자연 에너지 회복·네 기술 자동 발동·설정과 효과 재접속·부대 등록·가로 회전 일시정지를 사용한다. 형식12..25의 실제 이전 공개 저장27개를 별도로 재생한다. 실제 Android/iOS·하드웨어 GPU 검증은 수행 환경이 확보될 때 별도로 진행한다.

다음 후보는 디파일러 기술 묶음·적 전략 AI·원작 접근/선행 애니메이션·최종 그래픽이다. 이 단계 완료가 게임 전체 완료를 뜻하지 않는다.
