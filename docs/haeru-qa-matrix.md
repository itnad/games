# 해루질럿 QA 매트릭스

## 공통 준비

1. `/haeru-dev`에서 현재 저장값을 내보냅니다.
2. 검증할 프리셋을 고정 시드로 실행합니다.
3. 완료 후 내보낸 JSON을 **저장값 복원**에 붙여 넣고 복원합니다.

## 필수 뷰포트

| 크기 | 목적 | 통과 기준 |
| --- | --- | --- |
| 360×640 | 작은 Android | 상단 HUD·하단 기술바·오버레이 기본 버튼이 겹치지 않음 |
| 390×844 | 일반 Android/iPhone | 해산물 도감 목록이 패널 내부에서 스크롤되고 닫기 버튼이 고정됨 |
| 412×915 | 큰 Android | 정산 패널 접기·펼치기와 출정 버튼을 한 손으로 조작 가능 |

가로 화면에서도 치명적 잘림이 없어야 하지만 게임 밸런스의 기준 화면은 세로입니다.

## 핵심 시나리오

| 영역 | 절차 | 기대 결과 |
| --- | --- | --- |
| 첫 실행 | 저장 초기화 후 1단계 | 튜토리얼 중 4분 타이머 정지, 4개 행동 완료 후 시작 |
| 충돌 튜토리얼 | 연습 게·바위 접촉 | 피해 표현 1회, 체력 복구, 안전 위치 복귀 |
| 최종 귀환 | 4분 경과 | 밀물 1초 전환, 베이스캠프 등장, 도착 전에는 성공하지 않음 |
| 이어하기 | 플레이 중 나가기·새로고침 | 메인에서 동일 월드·시드·체력·타이머로 이어짐 |
| 저장 이동 | 내보내기 → 초기화 → 복원 | 알려진 해루질럿 키만 복원되고 프리셋 세션은 제거됨 |
| 어두운 갯벌 | 4단계 랜턴 Lv.1/Lv.6 | 어둠 밖 사물은 보이지 않고 레벨에 따라 밝기·각도·거리가 점진 증가 |
| 깊은 펄 | 5단계 | 불규칙 웅덩이, 발 빠짐, 발자국, 장화 완화, 개불 채집 확인 |
| 모기떼 | 6단계 | 피해 6, 체력 10 미만 무피해 문구, 기피제 1회 방어 |
| 그물 | 비밀 기술 프리셋 | 캐릭터 바로 위 투척 금지, 밀집 지역 조준, 구속 뒤 피해·해제 |
| 실패 | 체력 0 | 실패 정보 한 줄, 메인은 해루질럿으로, 길게 누르기 비밀 재도전 확인 |

## 자동 검사

```bash
npm run test:haeru
npx eslint app/mudflat-*.ts app/mudflat-*.tsx app/mudflat-*.js
npm test
```

Canvas 품질과 실제 터치·브라우저 뒤로가기는 자동 문자열 검사만으로 통과 처리하지 않습니다. 배포 전 실제 브라우저에서 최소 390×844 시나리오를 확인합니다.
