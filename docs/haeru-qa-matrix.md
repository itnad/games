# 해루질럿 QA 매트릭스

## 공통 준비

1. `/haeru-dev`에서 현재 저장값을 내보냅니다.
2. 일반 QA 프리셋은 고정 시드로 실행합니다. 감독모드는 기본 무작위 시드로 관찰하고, 문제 재현 시 로그의 시드를 입력합니다.
3. 완료 후 내보낸 JSON을 **저장값 복원**에 붙여 넣고 복원합니다.

## 필수 뷰포트

| 크기 | 목적 | 통과 기준 |
| --- | --- | --- |
| 360×640 | 작은 Android | 상단 HUD·하단 기술바·오버레이 기본 버튼이 겹치지 않음 |
| 390×844 | 일반 Android/iPhone | 해산물 도감 목록이 패널 내부에서 스크롤되고 닫기 버튼이 고정됨 |
| 412×915 | 큰 Android | 정산 패널 접기·펼치기와 출정 버튼을 한 손으로 조작 가능 |

가로 화면에서도 치명적 잘림이 없어야 하지만 게임 밸런스의 기준 화면은 세로입니다.

## 핵심 시나리오

| 영역 | 절차 | 기대 결과 |
| --- | --- | --- |
| 첫 실행 | 저장 초기화 후 1단계 | 튜토리얼 중 4분 타이머 정지, 4개 행동 완료 후 시작 |
| 충돌 튜토리얼 | 연습 게·바위 접촉 | 피해 표현 1회, 체력 복구, 안전 위치 복귀 |
| 최종 귀환 | 4분 경과 | 밀물 1초 전환, 베이스캠프 등장, 도착 전에는 성공하지 않음 |
| 이어하기 | 플레이 중 나가기·새로고침 | 메인에서 동일 월드·시드·체력·타이머로 이어짐 |
| 저장 이동 | 내보내기 → 초기화 → 복원 | 알려진 해루질럿 키만 복원되고 프리셋 세션은 제거됨 |
| AI 감독모드 | 기존 이어하기가 있는 상태에서 `/haeru-dev` 맨 위 AI 감독모드 영역의 `무작위 시드 관전 시작` | 실행마다 새 시드로 시작함. AI가 실제 충돌·피해 규칙으로 이동하고 레벨업 때만 멈춤. 선택 후 자동 재개하고, 성공 시 정비·다음 출정을 자동 수행함. 종료 후 기존 이어하기·최고 점수·열린 단계는 변하지 않음 |
| 감독 시드 재현 | 감독 플레이 로그의 `seed`를 재현 시드에 입력하고 `입력 시드로 재현` | 입력한 시드로 1단계가 시작되고 새 로그의 `seed`가 일치함. 로그 `viewport`에 창 크기·화소 비율·최초 Canvas 크기가 남음 |
| 감독 이동·채집 | 감독모드로 1단계 초반을 관전하고 감독 플레이 로그를 복사 | 바위 근처 조개구멍에도 방향을 뒤집거나 멈추지 않고 돌아가 호미질을 끝냄. 쫓아오는 게는 게 속도에 맞춰 물러나며 집게가 닿는 거리에서 잡고, 다가오지 않는 게는 그 거리에 서서 잡음. 닿을 수 없거나 진전이 없는 목표, 체력이 줄지 않는 게는 `target-released` 로그를 남기고 다른 목표로 넘어감. 호미질 중 바위 뒤집기가 함께 진행됨 |
| 감독 돌진 복어 | 감독모드로 3단계 이후를 관전하고 감독 플레이 로그를 복사 | 돌진 복어가 가까이 오면 `복어 물러나며 채집 중`으로 바뀌어 약 96px 거리를 지키며 집게로 때림. 132px에서 서다 가다를 되풀이하지 않아 같은 복어에 대한 `decision` 로그가 수백 건 쌓이지 않음. 접촉 직전이거나 느린 지형에서는 `거리를 벌리는 중`으로 최대 속도 이탈. 멀리 있는 복어 때문에 호미질을 미리 버리지 않음. 물러나는 길의 물골에는 들어가지 않고 따라 비켜 감 |
| 감독 경험치·호미질 | 감독모드로 1단계를 관전하며 작살·뜰채를 고르고 감독 플레이 로그를 복사 | 게 무리 한가운데의 경험치를 향해 둘레만 돌지 않고(`잡은 경험치 회수 중`인데 거리가 늘어나는 기록이 없음), 무리가 지나간 자리의 경험치를 돌아가 주움. 0.5초 남은 호미질을 게가 다가온다고 버리지 않고, 가던 구멍을 연달아 바꾸지 않음. 같은 종류의 게를 4초마다 갈아타지 않고 때리던 게를 마저 잡음 |
| 감독 대왕 박하지 | 감독모드로 1단계 200초 이후를 관전하고 감독 플레이 로그를 복사 | `boss-spawned` 직후 `대왕 박하지에게 다가가는 중` → `대왕 박하지 둘레를 돌며 채집 중`으로 바뀌고 집게가 보스에 오래 닿도록 둘레를 돎. 잡으면 `boss-caught`, 못 잡으면 `stage-clear`에 남은 체력 비율이 남음. 잡을 속도가 안 나오면 `target-released`(제시간에 잡기 어려움) 뒤 다른 일을 함. 귀환 알림(230초)이 뜨면 보스를 두고 돌아가 240초 전에 베이스캠프에 도착함(게 무리에 둘러싸여 있었어도 `밀물 귀환 실패` 피해가 없음) |
| 감독 귀환 | 감독모드로 2·3단계(물골)를 관전 | 2단계 돌발 물살은 언덕배기 거리와 현재 속도에 따라 최소 8초 전부터 대비하고 피해 없이 피함. 베이스캠프가 물골 건너편에 있어도 물골을 건너 240초 전에 캠프에 도착함. 여유가 있으면 안전한 경험치나 가까운 호미질을 마친 뒤 이동하고, 여유 3초 이내에는 곧장 귀환함. 복어가 쫓아오는 중에도 캠프 반대쪽으로 달아나지 않음 |
| 캠프 안 경험치 | 귀환 알림 전에 캠프 안쪽에 경험치 보석이 남도록 한 뒤 안으로 이동 | 채집 도구는 멈추지만 경험치 보석은 플레이어에게 날아와 획득되고 경험치 표시가 증가함 |
| 감독 위험 판단 | 감독모드로 3·5·8단계까지 관전 | 바위·낙석·깊은 펄·위험 생물을 회피하고 돌발 물살에는 언덕배기, 최종 복귀에는 베이스캠프를 우선함. 사망 결과에는 마지막 직접 피해 원인이 표시됨 |
| 어두운 갯벌 | 4단계 랜턴 Lv.1/Lv.6 | 어둠 밖 사물은 보이지 않고 레벨에 따라 밝기·각도·거리가 점진 증가 |
| 깊은 펄 | 5단계 | 불규칙 웅덩이, 발 빠짐, 발자국, 장화 완화, 개불 채집 확인 |
| 진주 보물 연출 | 일반 원정 실행 중 주인공을 빠르게 5회 연속 터치 | 드래그 없이 각 터치를 0.85초 안에 이어가면 실제 진주 1개·점수·경험치 오브젝트·조과통이 반영되고 보물 발견 연출이 표시됨. 일시정지·튜토리얼·베이스캠프·종료 상태에서는 작동하지 않음 |
| 3단계 이상 초반 밀도 | 3·5·8단계 새 원정 시작 후 첫 60초 | 단계별 8·12·18마리가 화면 가장자리 바깥에서 진입하고, 약한 게·새우의 출현 간격과 이동속도가 단계별로 상승함. 강한 생물과 어린이 모드는 추가 속도 보정 없음 |
| 게 일렬 돌진 | 4·5·6·7단계에서 돌진 이벤트를 원정 후반까지 관전 | 단계별로 2·3·4·5줄이 생성되고 각 줄은 빈칸 없이 같은 방향으로 돌진함. 줄당 게 수는 초반 8마리 이상에서 점차 늘어 후반 최대 20마리가 되며, 5줄 × 20마리를 넘지 않음 |
| 모기떼 | 6단계 | 피해 6, 체력 10 미만 무피해 문구, 기피제 1회 방어 |
| 그물 | 비밀 기술 프리셋 | 캐릭터 바로 위 투척 금지, 밀집 지역 조준, 구속 뒤 피해·해제 |
| 실패 | 체력 0 | 실패 정보 한 줄, 메인은 해루질럿으로, 길게 누르기 비밀 재도전 확인 |
| 오늘의 갯벌 | 메인에서 일일 출정 | 날짜·단계·고정 장비 확인, 기존 이어하기 저장 유지 |
| 메인 원정 위계 | 해루질럿 메인 진입 | 일반 원정 준비·시작 버튼이 먼저 보이고 오늘의 갯벌은 접힌 일일 이벤트로 표시 |
| 일일 기록 | 귀환 성공 또는 나가기·체력 0 | 무제한 재도전, 최고 귀환 기록만 갱신, 실패는 기존 기록 유지, 도전 횟수 미표시 |
| 결과 공유 | 일일 결과에서 공유 | Web Share 지원 시 공유 시트, 미지원 시 문구·주소 복사 |
| 날짜 전환 | 한국 표준시 자정 이후 재접속 | 새 단계·시드와 새 참가 기회 표시 |

## 자동 검사

```bash
npm run test:haeru
npx eslint app/mudflat-*.ts app/mudflat-*.tsx app/mudflat-*.js tests/mudflat-*.test.mjs
npm test
```

Canvas 품질과 실제 터치·브라우저 뒤로가기는 자동 문자열 검사만으로 통과 처리하지 않습니다. 배포 전 실제 브라우저에서 최소 390×844 시나리오를 확인합니다.
