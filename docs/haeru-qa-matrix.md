# 해루질럿 QA 매트릭스

## 공통 준비

1. `/haeru-dev`에서 현재 저장값을 내보냅니다.
2. 일반 QA 프리셋은 고정 시드로 실행합니다. 감독모드는 기본 무작위 시드로 관찰하고, 문제 재현 시 로그의 시드를 입력합니다.
   - 프리셋에 없는 조합은 **맞춤 원정 빌더**에서 모드·단계·기술 레벨·활성 기술·캐릭터·장비·시드를 직접 고릅니다. 시드는 `단계별 고정`이 프리셋과 같은 값이고, `직접 입력`으로 재현 시드를 넣을 수 있습니다. 실행 버튼은 검증 오류가 있으면 비활성화되고 오류 목록이 아래에 뜹니다.
3. 완료 후 내보낸 JSON을 **저장값 복원**에 붙여 넣고 복원합니다.
