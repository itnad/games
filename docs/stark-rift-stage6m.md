## 생산과 에너지

드론은 완성된 레어를 선행 조건으로 퀸즈 네스트를150/100·375경제틱(18.75초)에 건설한다. 기존 저그 크립·드론 소모/취소·건설 환불을 따른다. 퀸은 네스트가 있어야 해처리/레어의 라바를 사용해100/100·313틱(15.65초)·인구2로 생산한다. 기존 생산 대기열의 전액 취소 환불과 라바 소비 정책을 그대로 사용한다. 원작의 별도 알 엔티티·애니메이션은 현재 생산 대기열 추상화에 포함하지 않는다.

퀸은 체력120·공중·유기체이며 기본 공격·탐지·수송 능력이 없다. 기본 최대 에너지200·새 생산50, 원작24프레임/초·프레임당8/256 회복과 나머지를 사용한다. 게메이트 마이오시스는 네스트150/150·1042경제틱(52.1초), 최대250·새 생산62.5다. 연구가 현재 에너지를 즉시 늘리지 않는다. 유닛의 이동 실루엣과 에너지 UI를 제공한다.

## 인스네어

네스트100/100·500경제틱(25초)에 연구한다. 퀸이 에너지75로9타일(288px) 안 지점에 시전한다. 사거리는 시전자 몸체와 지점의 포함 거리다. 현재 다른 지점 주문과 같은 즉시 적용 방식이며 자동 접근·원작 투사체 비행과 시전 애니메이션 선행시간은 재현하지 않는다. 사거리 밖은 거절하고 이동 후 다시 지정한다. 공유 대기18틱(0.9초)은 현재 주문 UI의 고정 정책이며 자동시전은 제공하지 않는다. 성공하면 시전자 이동·탐색을 정리한다.

지점을 중심으로 원작64px 반폭의 정사각형과 몸체가 겹치는 지상/공중·유기체/기계·아군/적 유닛에 적용한다. 건물·시전자 자신·탑승자·현재 잠복·스테이시스 대상은 제외한다. 다른 퀸은 대상이 될 수 있다. 피해를 주지 않는다. 이미 감속된 대상은 지속시간을 갱신하고 효과를 중첩하지 않는다.75상태주기×8프레임=600프레임=500틱(25초)이며 수송·스테이시스·시전자 사망 중에도 시간이 경과한다. 드론 건설 취소는 상태를 유지하며 건물 완성은 해제한다.

원작의 가산 상태 수정자를 사용한다. 스팀팩+1, 인스네어-1이며 음수이면 이동속도 floor(기본/2), 무기 간격은 기본+floor(기본/4), 범위5..250프레임이다. 둘이 함께 있으면 기본 속도·무기 간격으로 상쇄된다. 기본 속도 열과 이미 예약된 다음 공격 틱·공격 나머지·피해 대상의 이동 지시는 보존한다. 아직 없는 다른 이동/공격 속도 업그레이드는 추가하지 않는다. 가속도·회전 관성은 기존 직접 속도 이동 모델의 범위 밖이다.

인스네어는 보이는 타일 안에서 개인/영구/아비터 은폐 유닛을 탐지기 없이 노출한다. 안개를 새로 밝히지 않으며 은폐 자체와 에너지 소모를 취소하지 않는다. 만료·복구 시 다시 기존 은폐/탐지 규칙을 따른다. 이미 인스네어인 유닛이 나중에 잠복해도 타이머를 임의 해제하지 않는다. 리스토레이션은 기존50에너지로 실명과 인스네어를 함께 제거하고 체력·스팀팩·은폐·스테이시스는 유지한다.
