# Playroom 게임 규칙 전수검사 기록

이 문서는 게임마다 **어느 판본을 기준으로 구현했는지**, 공식 규칙과 현재 코드의 차이가 무엇인지, 어떤 보정을 완료했는지를 기록한다. 전통 게임처럼 단일 저작권자나 단일 공식 규칙이 없는 경우에는 적용한 변형을 명시한다.

## 검증 완료

| 게임 | 적용 기준 | 확인·보정 결과 |
|---|---|---|
| 오목 | 15×15 자유룰, 시작 시 `정확히 5목`/`5목 이상` 선택 | 선택한 연결 판정이 게임 중 유지됨. 렌주 금수 규칙은 적용하지 않는 선택형 오목임을 유지한다. |
| 메모리 | 4×4 Concentration 관습 규칙 | 두 장 공개, 같은 그림 확보, 전 카드 소진 후 다수 득점 승리 흐름 확인. 단일 국제 공식 규칙은 없다. |
| 리버시 | [World Othello Federation 공식 규칙](https://www.worldothello.org/about/about-othello/othello-rules/official-rules/english) | 흑 선공, 반드시 뒤집는 수만 허용, 합법 수가 없을 때만 패스, 양쪽 모두 둘 수 없으면 종료를 확인했다. |
| 만칼라 | 6구 Kalah 표준 규칙 | 상대 저장소 건너뛰기, 마지막 돌이 내 저장소면 추가 차례, 빈 내 구덩이 착지 시 맞은편 포획, 한쪽 소진 시 정산을 확인했다. `만칼라` 전체가 아닌 Kalah 변형이다. |
| 해전 | [Hasbro Battleship 공식 설명서](https://www.hasbro.com/common/instruct/40044.pdf) | 기존 8×8·3척 축소판을 10×10, 5척(5·4·3·3·2), 총 17칸으로 수정했다. 함선은 가로/세로로 겹치지 않게 배치한다. 현재는 빠른 자동 배치 방식이다. |
| 체커 | American Checkers/English Draughts 표준 | 잡기 의무, 연속 잡기, 킹 이동을 확인했다. 잡기 도중 마지막 줄에 도달해 킹이 되면 즉시 턴이 끝나도록 수정했다. |
| 장기 | 한국 장기 기본 행마·차림 | 차·포·마·상·사·궁·졸의 행마, 포의 다리, 궁성 대각선, 장군 회피, 한 수 쉼을 확인했다. 빠져 있던 안상·바깥상·왼상·오른상 네 가지 마·상 차림 선택을 추가했다. 빅장·반복 점수 판정은 운영 규정 차이가 있어 후속 옵션 검사 대상으로 남겼다. |
| 나인 멘스 모리스 | Nine Men's Morris 표준 | 9개 배치, 밀 완성 시 제거, 밀 밖의 말 우선 제거, 3개일 때 비행, 2개 이하 또는 이동 불가 패배를 확인했다. 화면 설명에 빠진 승리 조건을 추가했다. |
| 고누 | 네줄고누 막기 변형 | 고누는 지역별 말판·행마가 달라 단일 공식 규칙으로 표시하지 않는다. 현재 네 줄 말판 막기 변형임을 설명에 명시했다. |
| 도미노 | 더블식스 2인 Draw Dominoes 변형 | 28장, 7장씩 배분, 놓을 수 없으면 더미에서 뽑기, 막히면 남은 눈 합 비교를 확인했다. 양끝 모두에 놓을 수 있을 때 방향을 플레이어가 직접 고르도록 수정했다. |
| 백개먼 | [USBGF 기본 규칙](https://usbgf.org/beginners-guide-to-backgammon/) 단판 | 시작에 각자 한 개를 굴려 높은 쪽이 두 눈으로 선공하도록 수정했다. 가능한 최대 주사위 수 사용과, 하나만 쓸 수 있을 때 높은 눈 우선 규칙을 추가했다. 더블링 큐브·매치 점수는 쓰지 않는 단판 모드임을 명시했다. |
| 차이니즈 체커 | [Hasbro 1994 설명서](https://www.hasbro.com/common/instruct/ChineseCheckers.PDF) 2인 | 반대편 10칸, 인접 한 칸 또는 말 하나를 넘는 연속 도약, 말 제거 없음, 한 차례 한 말 이동을 확인했다. |
| 잉카 골드 | [IELLO Diamant 2016 영문 규칙서](https://iellogames.com/wp-content/uploads/2016/10/Diamant_Rulebook_EN_V1_Light.pdf)의 유물 변형 | 15개 보물(17 포함), 위험 5종×3장, 유물 5·7·8·10·12, 5회 탐험, 동점 공동 승리를 확인했다. 다른 Incan Gold 판본과 혼동하지 않도록 화면에 IELLO 2016 유물 변형을 명시했다. |
| 큐윅스 | [NSV Qwixx 기본 규칙](https://www.nsv.de/wp-content/uploads/2025/06/QwixxOnBoard_GB.pdf)에 수록된 원본 규칙 | 공용 흰 주사위 합, 현재 선수의 흰+색 조합, 왼쪽에서 오른쪽 체크, 5칸 선행 후 잠금, 실패 −5, 종료·삼각수 점수를 확인했다. |
| 러브레터 | [Z-Man Games 2019 21장 규칙](https://images.zmangames.com/filer_public/5b/6c/5b6c17d7-7e0e-4b70-a311-9a6c32066010/ll-rulebook.pdf) | 2~6인 21장 구성, 2인 공개 제거 3장, 백작부인 강제 사용, 첩자 보너스, 인원별 호감 목표를 확인했다. 쿠키 테마는 규칙만 같고 비공식 재창작 테마다. |
| 미니빌 | Machi Koro 기본판 규칙 | 시작 건물·3코인, 빨강→파랑/초록→보라 해결 순서, 주요 건물 1장 제한, 네 랜드마크 비용·효과, 건설 즉시 승리를 코드와 대조했다. |

## 후속 정밀검사 대기

위너스 서클, 다이아몬드, 주사위 대결, 빛과 그림자의 대결, 픽 피크닉, SD 간담 디럭스, 스코틀랜드 야드, 화이트채플, 7원더스, 카멜 업, 티츄, 현금흐름 탈출, 바카라, 시계탑, 스타워즈 에픽 듀얼을 순차 검사한다.

현금흐름 탈출은 직전 검사에서 원작 Cashflow의 이동·기부·실직·Fast Track·파산 규칙을 보정했으며, 독자적 한국형 자산·금액·표현을 사용하는 학습용 재구성임을 유지한다.

## 검증 원칙

1. 출판사·공식 협회 규칙서를 먼저 사용한다.
2. 판본 차이가 있으면 현재 구성물과 일치하는 판본을 고르고 화면에 표시한다.
3. 단일 공식 규칙이 없는 고전 게임은 변형 이름과 하우스 룰을 숨기지 않는다.
4. 승패·점수·강제 행동·턴 종료처럼 결과에 영향을 주는 규칙은 엔진 테스트를 추가한다.
5. 원작 전체를 재현하지 않은 게임을 `공식 규칙과 동일`하다고 표현하지 않는다.
