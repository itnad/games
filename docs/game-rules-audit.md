# paperoid 게임 규칙 전수검사 기록

이 문서는 게임마다 **어느 판본을 기준으로 구현했는지**, 공식 규칙과 현재 코드의 차이가 무엇인지, 어떤 보정을 완료했는지를 기록한다. 전통 게임처럼 단일 저작권자나 단일 공식 규칙이 없는 경우에는 적용한 변형을 명시한다.

## 2차 보완 — 티츄

- 기준: [Fata Morgana/Rio Grande 영문 규칙서](https://cdn.1j1ju.com/medias/f4/75/98-tichu-rulebook.pdf)의 4인 팀전.
- 용으로 이긴 트릭은 용의 25점을 포함해 승자가 선택한 상대 한 명에게 주도록 사용자 선택 단계를 추가했다.
- 같은 팀이 1·2등으로 완주하면 세 번째 완주자를 기다리지 않고 즉시 라운드를 끝내며 200점을 적용한다.
- 양 팀이 목표 점수 이상에서 동점이면 승자를 정하지 않고 다음 라운드를 계속한다.
- 작은 티츄는 카드 교환 전부터 첫 카드를 내기 전까지 선언할 수 있도록 선언 가능 시점을 바로잡았다.

## 검증 원칙

1. 출판사·공식 협회 규칙서를 먼저 사용한다.
2. 판본 차이가 있으면 현재 구성물과 일치하는 판본을 고르고 화면에 표시한다.
3. 단일 공식 규칙이 없는 고전 게임은 변형 이름과 하우스 룰을 숨기지 않는다.
4. 승패·점수·강제 행동·턴 종료처럼 결과에 영향을 주는 규칙은 엔진 테스트를 추가한다.
5. 원작 전체를 재현하지 않은 게임을 `공식 규칙과 동일`하다고 표현하지 않는다.
