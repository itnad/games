# 단계6K · 마린 스팀팩과 메딕 치료 연계

2026-11-17. 원작 BWAPI4.4.0과 고정 OpenBW 커밋의 연구·사용·속도·공격 간격 규칙을 추출했다. `tools/stark-rift-data/extract-stim.py`가 출처와 원본 파일 SHA256을 포함한 `stim-original.json`을 재생성한다.

## 구현 범위

스팀팩은 아카데미에서100/100·원작1200프레임, 경제시간50% 환산500틱(25초)에 연구한다. 한 번만 연구하며 취소 시 전액 환불한다. 현재 유닛 목록의 마린에 제공한다. 일반 운영과 특수 연습 모두 연구 비용이 필요하고 기존 연습 배치·자원·부상 마린·메딕을 유지한다. 연습에 완료된 스팀팩 연구를 부여하지 않는다.

사용은 원래 체력10을 정확히 소모한다. 표시 HP가 아닌 1/256 실제 HP가10을 넘어야 한다. 공격 방어력·보호막·에너지는 소모량에 관여하지 않는다. 선택한 마린 중 사용할 수 있는 대상만 안정 ID 순서로 처리한다. 선택한 마린에 즉시 적용하는 `castAbility:stim-packs`이며 지점 지정은 필요하지 않다. 부대 내 저체력·스테이시스·수송 중·다른 유닛은 제외한다. 탑승 대기 중 활성화는 기존 탑승 지시를 유지한다.

원작37상태주기×8프레임=296프레임을20Hz247틱(12.35초)으로 환산한다. 이동속도는1.5배이며 기본 속도 열은 변경하지 않는다. 원작 무기 쿨다운을 floor(기본/2), 최소5프레임으로 계산한다. 마린은15→7프레임이다. 기존24:20 공격 나머지 계산을 유지하며 진행 중인 공격 대기시간은 즉시 재설정하지 않는다. 재사용은 다시 체력10을 지불하고 시간을 갱신하며 배율은 중첩하지 않는다.

이동·공격·정지·사수·진형과 경로 탐색 예약을 보존한다. 시간이 수송·스테이시스 중에도 경과하며 만료하면 원래 속도와 쿨다운 계산으로 돌아간다. 리콜은 버프를 해제하지 않는다. 현재 소유권 검증은 종족 혼합을 허용하지 않으므로 리콜 연계의 유닛 간 직접 검사는 향후 혼합 소유권을 위한 하위 함수 검증이다. 제거·사망 시 버프 참조를 정리한다.

메딕은 스팀팩으로 생긴 부상을 기존 자동/수동치료 규칙으로 회복한다. 같은 틱에 치료가 진행되면 표시 HP 감소가10보다 작게 보일 수 있지만 실제 지불10과 회복량은 분리해서 계산한다. 원작 고정소수점 경계값을 검사한다. 390px 실제 시험에서 메딕이 첫 환자 치료 후 다른 유닛의 정지 위치에 밀려 두 번째 환자의 사거리 밖에 멈추는 문제를 발견했다. 접근 목적지는 실제 충돌·예약과 치료 사거리를 모두 만족하는 반타일 격자에서 선택하며, 기존 A* 경로 탐색과 이동 처리는 유지한다. 일반 부대의 추가 진형 간격은 치료 접근에 적용하지 않는다. 이 수정은 단계6K 전투 규칙에 포함하며 이전 단계6J 규칙 해시는 보존한다.

## 화면과 조작

`/stark-rift-dev` → 테란 → 특수 연습 → 새 테스트 시작 → 스팀팩 아카데미 선택 → 스팀팩 연구. 스팀팩 마린 선택 후 사용한다. 메딕 선택 → 치료 →1번 부대로 먼저 치료한 후 사용하면 소모·회복 연계를 확인하기 쉽다. 연구 전/체력 부족/일시정지 시 버튼을 비활성화한다. 남은 시간과 주황색 윤곽·가속 효과를 표시한다. 수송 탑승 목록에도 남은 시간을 제공한다. 보이지 않는 유닛의 버프는 렌더 패킷에 포함하지 않는다.

## 저장과 검증

엔진0.21.0-stage6k, 저장·스키마20, 프로토콜21. 형식6..19를 원본 체크섬·이전 데이터/전투 규칙 확인 후 이행한다. 형식19 메딕 치료 예약·수동/자동 설정·에너지·경로·명령·RNG를 그대로 보존한다. 기존 저장에 연구·유닛·자원을 추가하지 않는다. 원본19는 `.stage6j-backup`에 바이트 그대로 남긴다. 이전 형식이 스팀팩 필드·연구를 위장하면 거절한다. 버프 타이머·중복 참조·잘못된 대상·연구 누락은 현재 저장에서도 거절한다.

게임 회귀검사, 빌드와 공유·기존 게임 검사, 랩·성능 검사, 360/390px 실제 Worker/Pixi 터치·연구500틱 완료·체력 소모/치료·활성 버프 저장 복구·만료 및 이전 실서비스 저장 복구로 확인한다. 최종 수치와 게시 버전은 별도 검증 영수증에 기록한다. Chromium SwiftShader 검증은 실제 Android/iOS·하드웨어 GPU 검증을 대신하지 않는다.
