# 해루질럿 게임 기획 기준

이 문서는 현재 구현의 플레이 규칙과 용어를 설명합니다. 수치의 최종 원본은 `app/mudflat-survivor-engine.js`, 화면 흐름의 최종 원본은 `app/mudflat-survivor-game.tsx`입니다.

## 1. 핵심 플레이 흐름

1. 화면을 터치한 채 드래그해 채집꾼을 이동합니다.
2. 집게·호미질과 습득한 채집기술은 조건을 만족하면 자동으로 작동합니다.
3. 해산물을 채집해 경험치와 조과를 얻고, 돌·해산물 접촉과 환경 위험을 피합니다.
4. 3분 50초에 귀환 안내와 함께 지도 밖에 **베이스캠프**가 나타나고, 기본 원정 시간 4분이 되면 **밀물**이 시작됩니다(귀환 안내는 밀물 10초 전, `MUDFLAT_RETURN_GUIDE_SECONDS`).
5. **베이스캠프**에 실제로 도착해야 성공합니다. 4분 생존만으로는 성공하지 않습니다. 밀물이 시작된 뒤에는 이동이 크게 느려지고 체력이 계속 줄어듭니다.
6. 성공하면 조과를 코인으로 정산하고 정비 화면에서 다음 원정을 준비합니다. 체력이 0이면 실패합니다.

튜토리얼 중에는 원정 시간이 흐르지 않습니다. 튜토리얼은 이동, 집게 끝으로 채집, 호미질, 충돌 위험을 직접 수행한 뒤 완료됩니다.

## 2. 표준 용어

| 용어 | 의미 | 쓰지 않는 혼용 표현 |
| --- | --- | --- |
| 베이스캠프 | 최종 밀물 때 복귀해야 하는 안전·정산 지점 | 정비소, 귀환 지점 |
| 정비 화면 | 성공 후 장비·음식·기술을 확인하는 화면 | 베이스캠프(화면 자체를 가리킬 때) |
| 돌발 물살 | 스테이지 도중 반복되는 짧은 환경 이벤트 | 밀물 |
| 언덕배기 | 돌발 물살을 피하는 밝은 회색 안전지대. 물살이 지나갈 때마다 새 자리로 옮겨집니다 | 모래톱, 캠프, 고정 언덕배기 |
| 밀물 | 4분 뒤 시작되는 최종 복귀 이벤트 | 돌발 물살 |
| 채집기술 | 레벨업으로 배우고 강화하는 기술 묶음 | 스킬(사용자 표시에서는 지양) |
| 기술 인벤토리 | 익힌 모든 선택 기술과 레벨을 보관하는 목록 | 기술 창고, 스킬 목록 |
| 활성 기술 | 인벤토리 중 원정에서 작동하는 최대 6개 | 장착 기술, 선택 슬롯 |
| 보관 | 활성에서 내려 레벨만 유지하는 상태 | 해제, 삭제, 봉인 |
| 운석 | 떨어질 자리가 먼저 표시된 뒤 떨어져 큰 피해를 주고 바위로 남는 환경 위험 | 낙석 |

## 3. 모드

- 일반 모드: 기본 스킨 또는 비밀 선택인 루미를 사용합니다. 집게와 호미질은 기본 기술이며, 그 외 채집기술은 **기술 인벤토리**에 몇 개든 익혀 두고 그중 최대 6개만 **활성 기술**로 골라 원정에 씁니다.
  - 인벤토리(`levels`)는 익힌 모든 선택 기술의 레벨을 보관하고, `activeSkills`가 원정에서 작동하는 최대 6개를 정합니다. 보관(비활성) 기술은 레벨을 잃지 않으며 효과만 꺼집니다. 전기 스파크·그물 투척 해금에 쓰는 마스터리 수는 인벤토리 기준으로 셉니다.
  - 원정 중 레벨업 선택지에는 활성 기술 레벨업과 미습득·보관 기술이 함께 나옵니다. 활성 6개가 가득 찬 채 새 기술을 고르면 **교체 선택 화면**이 열려 어떤 활성 기술을 보관으로 내릴지 사람이 고릅니다. 취소하면 선택지로 돌아갑니다. 감독모드에서도 이 선택은 감독이 하고 AI는 멈춘 채 기다립니다.
  - 정비 화면의 채집기술 패널은 `활성 N / 6`을 표시하고, 익힌 기술을 눌러 활성·보관을 바꿉니다. 기술 훈련은 인벤토리의 모든 기술에 허용되며, 새로 익힌 기술은 자리가 있으면 바로 활성화되고 가득 차 있으면 `보관` 표시와 함께 인벤토리에 들어갑니다. 코인 부족·최고 레벨 비활성화와 클릭 뒤 거절하는 `trainSkill` 방어 로직은 유지합니다.
- 어린이 모드: 캐릭터별 시작 기술을 사용하고 자동 기술 중심으로 진행합니다. 장거리 자동 뜰채는 현재 화면 안의 대상만 획득합니다.

## 4. 정규 스테이지 정체성

| 단계 | 이름 | 핵심 특징 |
| --- | --- | --- |
| 1 | 초입 갯벌 | 튜토리얼, 기본 이동·채집, 완화된 바위 밀도 |
| 2 | 차오르는 물골 | 물골, 약 48초 주기의 돌발 물살, 언덕배기 |
| 3 | 바위 갯벌 | 많은 바위, 여러 물골, 가까이에 나타나는 숨은 돌 |
| 4 | 어두운 갯벌 | 제한 시야, 랜턴 방향 시야, 숨은 패류와 패류 가치 보너스, 가까이에 나타나는 숨은 돌 |
| 5 | 깊은 펄 | 불규칙한 깊은 펄, 이동·발 빠짐 위험, 개불 숨구멍, 장화 완화 |
| 6 | 거센 갯벌 | 바람, 해산물 무리, 물골, 약 43초 주기의 돌발 물살과 언덕배기 |
| 7 | 대조기 갯벌 | 약 27초 주기의 더 잦은 돌발 물살과 언덕배기, 약한 바람 |
| 8 | 마지막 물때 | 어둠·바람·운석·물골·돌발 물살(약 31초 주기)의 복합 환경, 강화 대왕 박하지 |
| 9+ | 끝없는 물때 | 환경 조합과 보조 목표가 단계별 시드로 결정되는 반복 원정 |

스테이지 수치, 장비 성능, 생물 체력·보상·가격은 이 문서에 복제하지 않습니다. 반드시 엔진 상수와 `/haeru-dev` 프리셋으로 확인합니다.

**언덕배기**는 돌발 물살이 있는 모든 단계(2·6·7·8단계와 끝없는 물때의 "거센 돌발 물살")에서 같은 규칙을 따릅니다. 처음에는 출발 지점 바로 옆에 있다가 원정 시작 7초 뒤, 그리고 돌발 물살이 한 번 지나갈 때마다 그 순간 플레이어가 있는 곳에서 약 170~230px 떨어진 새 자리로 옮겨집니다. 물살이 닿는 순간 언덕배기(반경 112px) 안이나 베이스캠프 안에 있으면 피해가 없고, 밖에 있으면 `10 + 단계` 피해를 입습니다. "고정 언덕배기"라는 것은 따로 없습니다. 단계 설정의 `safeZone` 값 `"fixed"`·`"moving"`은 예전 구분의 흔적으로, 지금 게임은 둘을 똑같이 다룹니다(`"none"`인지만 봅니다).

**모기떼**는 특정 단계의 특징이 아닙니다. 2단계부터 모든 단계에서 판마다 `(단계 − 1) × 10%`(최대 90%) 확률로 그 판에 나올지가 정해지고, 나오는 판에서는 발생 시점마다 같은 확률로 나타납니다.

운석은 떨어질 자리에 점선 원과 "운석" 표시가 먼저 나타나고, `MUDFLAT_METEOR_FALL_SECONDS`(엔진 상수, 예전 낙석의 4배 속도) 뒤에 떨어집니다. 표시 안에 있으면 큰 피해를 입고, 떨어진 자리에는 바위가 남습니다. 8단계와 끝없는 물때의 "운석 지대" 조합에서 나옵니다.

끝없는 물때의 보조 목표는 원정 중 체력·경험치 막대가 있는 왼쪽 위 HUD 카드 안에 `목표` 줄로 표시합니다. 진행률 막대와 `채집 45 / 120`, `돌 4 / 9`, `체력 36% / 50%` 형식의 카운터를 보여 주고, 달성하면 초록색으로 바뀝니다. 별도 카드를 게임 화면 위에 띄우지 않으며, 목표 전문은 출정 화면·일시정지 화면·정비 화면에서 확인합니다. HUD 카운터와 단계 성공 정산은 `mudflatEndlessObjectiveProgress`의 같은 판정을 사용합니다.

일시정지 화면의 **계속 채집하기** 버튼은 제목 바로 아래에 둡니다. 원정 정보 카드가 길어도 화면을 끌어내리지 않고 바로 누를 수 있어야 합니다.

4단계부터 발생하는 게 돌진 이벤트는 화면 밖에서 가로 한 줄을 이룬 작은 게들이 같은 방향으로 빠르게 지나갑니다. 4단계는 2줄에서 시작해 5·6·7단계에서 3·4·5줄로 늘고, 원정 후반으로 갈수록 줄당 개체 수가 8마리에서 최대 20마리까지 증가합니다. 8단계 이후에도 최대 5줄·줄당 20마리를 넘지 않습니다. 줄 폭은 마리당 38px(20마리면 722px)이고 화면 밖 약 560px(세로 화면 기준)에서 초당 `218 + 단계 × 7`px로 달려와 2초 남짓이면 닿습니다. **후반 물결은 기본 이동속도로는 옆으로 피할 수 없게 한 것이 의도입니다**(4·5단계는 180초 이후, 6단계 128초 이후, 7단계 75초 이후, 8단계는 첫 물결부터). 작은게는 체력이 2라 채집기술로 줄에 구멍을 내거나, 장화로 속도를 올리거나, 피해를 감수해야 합니다.

## 5. 실패·저장·비밀 진입

- 생존 중 원정은 5초 간격과 페이지 이탈 시 현재 월드 전체를 로컬 저장합니다.
- 뒤로가기 또는 나가기 확인 화면을 통해 이동해도 해루질럿 메인에서 이어할 수 있습니다.
- 일반 재도전은 장비·기술·경험치·코인을 초기화합니다.
- 길게 누르기 재도전과 단계 선택 길게 누르기는 발견형 기능이지만, 회귀 검증이 필요한 정식 동작입니다.
- `/haeru-dev`의 고정 시드 프리셋은 사용자 진행이 아니라 개발·QA 재현용입니다.
- 레벨업 때 제시되는 채집기술 세 가지는 시드와 무관하게 그때그때 무작위로 뽑습니다(`Math.random`). 같은 시드를 다시 해도 선택지는 달라질 수 있습니다. 뽑힌 선택지는 저장되므로 새로고침으로 다시 뽑을 수는 없습니다.
- `/haeru-dev`의 AI 감독모드는 실제 원정 규칙을 AI 이동으로 반복 관전하는 밸런스 도구입니다. 다만 감독모드에서는 AI 주변(720px)의 조개구멍이 3개 미만이면 구멍을 더 만들고 24개를 넘으면 먼 것부터 정리하므로, 조개구멍 분포는 일반 원정과 다릅니다. 감독은 관전하는 사람을 뜻하며, 원정 중 레벨업 채집기술과 단계 성공 뒤 정비 화면의 회복 음식·기술 훈련·장비·소모품 구매, 다음 출정 시점을 직접 선택합니다. 플레이·레벨업·정비 화면은 일반모드와 같은 표시 구성을 사용하고, 일시정지 화면에만 AI 리포트용 로그 복사 버튼을 추가합니다. AI 이동·로그 수집·일반 저장 미반영은 내부 동작으로 구분합니다. 선택한 구매와 잔액은 감독 로그에 남기되 감독 결과는 일반 진행·최고 점수·순위에 기록하지 않습니다.

## 6. 변경 원칙

- 승리 조건, 스테이지 특징, 저장 의미를 바꾸면 이 문서와 `app/game-objectives.js`, 관련 테스트를 같은 커밋에서 고칩니다.
- 화면 문구를 먼저 정하고 코드 변수의 의미가 다르면 코드도 함께 정리합니다.
- 밸런스 수치는 엔진에 한 번만 정의하고 문서에서는 의미와 원본 위치를 안내합니다.

## 7. 오늘의 갯벌과 통합 순위

- 메인 화면에서는 일반 원정을 주 흐름으로 먼저 보여주고, 오늘의 갯벌은 접힌 `일일 이벤트` 배너로 보조 배치합니다.
- 한국 표준시 날짜마다 2~8단계 중 하나와 결정적 시드가 고정됩니다.
- 모든 참가자는 기본 스킨, 일반 모드, 동일한 채집기술·장비로 시작합니다.
- 브라우저별 익명 참가자는 횟수 제한 없이 재도전하며 하루 최고 귀환 기록 하나만 순위에 남깁니다.
- 도전 횟수는 저장하거나 공개하지 않습니다. 실패와 중도 이탈은 순위 기록을 낮추거나 다음 도전을 막지 않습니다.
- 순위는 귀환 성공 기록만 대상으로 `점수 → 채집 수 → 짧은 원정 시간` 순서로 정렬합니다.
- 진행 중인 일반 원정과 정비 저장은 오늘의 갯벌을 시작해도 유지됩니다.
- 현재는 전체 통합 순위만 제공합니다. 추후 로그인과 친구 관계가 도입되면 같은 기록 테이블의 참가자 식별값을 기준으로 친구 필터를 추가합니다.
- 결과 카드는 Web Share API를 우선 사용하고 지원하지 않는 브라우저에서는 공유 문구와 주소를 복사합니다.
