# 해루질럿 게임 기획 기준

이 문서는 현재 구현의 플레이 규칙과 용어를 설명합니다. 수치의 최종 원본은 `app/mudflat-survivor-engine.js`, 화면 흐름의 최종 원본은 `app/mudflat-survivor-game.tsx`입니다.

## 1. 핵심 플레이 흐름

1. 화면을 터치한 채 드래그해 채집꾼을 이동합니다.
2. 집게·호미질과 습득한 채집기술은 조건을 만족하면 자동으로 작동합니다.
3. 해산물을 채집해 경험치와 조과를 얻고, 돌·해산물 접촉과 환경 위험을 피합니다.
4. 기본 원정 시간 4분이 지나면 **밀물**과 최종 복귀 단계가 시작됩니다.
5. 지도 밖에 나타난 **베이스캠프**에 실제로 도착해야 성공합니다. 4분 생존만으로는 성공하지 않습니다.
6. 성공하면 조과를 코인으로 정산하고 정비 화면에서 다음 원정을 준비합니다. 체력이 0이면 실패합니다.

튜토리얼 중에는 원정 시간이 흐르지 않습니다. 튜토리얼은 이동, 집게 끝으로 채집, 호미질, 충돌 위험을 직접 수행한 뒤 완료됩니다.

## 2. 표준 용어

| 용어 | 의미 | 쓰지 않는 혼용 표현 |
| --- | --- | --- |
| 베이스캠프 | 최종 밀물 때 복귀해야 하는 안전·정산 지점 | 정비소, 귀환 지점 |
| 정비 화면 | 성공 후 장비·음식·기술을 확인하는 화면 | 베이스캠프(화면 자체를 가리킬 때) |
| 돌발 물살 | 스테이지 도중 반복되는 짧은 환경 이벤트 | 밀물 |
| 언덕배기 | 돌발 물살을 피하는 밝은 회색 안전지대 | 모래톱, 캠프 |
| 밀물 | 4분 뒤 시작되는 최종 복귀 이벤트 | 돌발 물살 |
| 채집기술 | 레벨업으로 배우고 강화하는 기술 묶음 | 스킬(사용자 표시에서는 지양) |

## 3. 모드

- 일반 모드: 기본 스킨 또는 비밀 선택인 루미를 사용합니다. 집게와 호미질은 기본 기술이며 그 외 최대 6개 채집기술을 익힙니다.
- 어린이 모드: 캐릭터별 시작 기술을 사용하고 자동 기술 중심으로 진행합니다. 장거리 자동 뜰채는 현재 화면 안의 대상만 획득합니다.

## 4. 정규 스테이지 정체성

| 단계 | 이름 | 핵심 특징 |
| --- | --- | --- |
| 1 | 초입 갯벌 | 튜토리얼, 기본 이동·채집, 완화된 바위 밀도 |
| 2 | 차오르는 물골 | 물골, 약 48초 주기의 돌발 물살, 고정 언덕배기 |
| 3 | 바위 갯벌 | 많은 바위, 여러 물골, 가까이에 나타나는 숨은 돌 |
| 4 | 어두운 갯벌 | 제한 시야, 랜턴 방향 시야, 숨은 패류와 패류 가치 보너스 |
| 5 | 깊은 펄 | 불규칙한 깊은 펄, 이동·발 빠짐 위험, 개불 숨구멍, 장화 완화 |
| 6 | 거센 갯벌 | 바람, 모기떼, 해산물 무리, 물골과 돌발 물살 |
| 7 | 대조기 갯벌 | 더 잦은 돌발 물살, 위치가 바뀌는 언덕배기, 모기떼 |
| 8 | 마지막 물때 | 어둠·바람·낙석·물골·모기떼의 복합 환경, 강화 대왕 박하지 |
| 9+ | 끝없는 물때 | 환경 조합과 보조 목표가 단계별 시드로 결정되는 반복 원정 |

스테이지 수치, 장비 성능, 생물 체력·보상·가격은 이 문서에 복제하지 않습니다. 반드시 엔진 상수와 `/haeru-dev` 프리셋으로 확인합니다.

## 5. 실패·저장·비밀 진입

- 생존 중 원정은 5초 간격과 페이지 이탈 시 현재 월드 전체를 로컬 저장합니다.
- 뒤로가기 또는 나가기 확인 화면을 통해 이동해도 해루질럿 메인에서 이어할 수 있습니다.
- 일반 재도전은 장비·기술·경험치·코인을 초기화합니다.
- 길게 누르기 재도전과 단계 선택 길게 누르기는 발견형 기능이지만, 회귀 검증이 필요한 정식 동작입니다.
- `/haeru-dev`의 고정 시드 프리셋은 사용자 진행이 아니라 개발·QA 재현용입니다.

## 6. 변경 원칙

- 승리 조건, 스테이지 특징, 저장 의미를 바꾸면 이 문서와 `app/game-objectives.js`, 관련 테스트를 같은 커밋에서 고칩니다.
- 화면 문구를 먼저 정하고 코드 변수의 의미가 다르면 코드도 함께 정리합니다.
- 밸런스 수치는 엔진에 한 번만 정의하고 문서에서는 의미와 원본 위치를 안내합니다.

## 7. 오늘의 갯벌과 통합 순위

- 한국 표준시 날짜마다 2~8단계 중 하나와 결정적 시드가 고정됩니다.
- 모든 참가자는 기본 스킨, 일반 모드, 동일한 채집기술·장비로 시작합니다.
- 브라우저별 익명 참가자는 횟수 제한 없이 재도전하며 하루 최고 귀환 기록 하나만 순위에 남깁니다.
- 도전 횟수는 저장하거나 공개하지 않습니다. 실패와 중도 이탈은 순위 기록을 낮추거나 다음 도전을 막지 않습니다.
- 순위는 귀환 성공 기록만 대상으로 `점수 → 채집 수 → 짧은 원정 시간` 순서로 정렬합니다.
- 진행 중인 일반 원정과 정비 저장은 오늘의 갯벌을 시작해도 유지됩니다.
- 현재는 전체 통합 순위만 제공합니다. 추후 로그인과 친구 관계가 도입되면 같은 기록 테이블의 참가자 식별값을 기준으로 친구 필터를 추가합니다.
- 결과 카드는 Web Share API를 우선 사용하고 지원하지 않는 브라우저에서는 공유 문구와 주소를 복사합니다.
