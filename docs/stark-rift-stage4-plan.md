# 4단계 구현 계획

2026-11-11. 세로 전용 내부 검증 화면에 경제·건설·생산을 연결한다. 공개 라우트/게임 목록은 기존 노출 정책을 유지한다.

1. BWAPI v4.4.0의 원작 수치 표를 추출하고 출처 해시·20Hz/50% 시간 변환·생산/선행 조건을 검증한다.
2. 시작 본부·일꾼 4·미네랄 50·종족별 인구수와 저그 오버로드/라바 상태를 구성한다.
3. 자원 고갈·운반·동시 채취 예약과 본진 지역/시야에 제한된 자동 채취를 연결한다. 명시적 이동·정지는 자동 채취보다 우선한다.
4. 직사각형 건물 배치·미리보기, SCV 지속 건설/재개, 드론 변태/취소, 프로브 독립 워프, 크립·파일런 동력·애드온을 연결한다.
5. 5개 대기열·비용/인구 예약·취소 환불·반복 생산·연구·집결지·막힌 출구 대기를 저장 가능한 상태로 구성한다.
6. 알아볼 수 있는 본부·일꾼·병력·자원 표시와 자원/인구 HUD·건설/생산 패널을 적용하고 세 종족 내부 시나리오에서 조작한다.
7. 경제 보존·중복/부족 접수·생산/건설 취소·배치/동력·저장 복원 결정성·Worker/브라우저를 검증하고 같은 소스를 원격에 반영한다.

O-01은 권장안을 채택한다. 단발 생산은 사용 가능한 비용·인구수가 있을 때만 접수해 예약하며, 반복 생산은 조건 충족까지 대기한다. 원작 프레임은 24프레임/초 기준으로 20Hz 변환 후 절반 시간을 적용하고 가장 가까운 정수 틱으로 반올림한다. 이동 최고속도는 절반으로 만들지 않는다.

4단계 콘텐츠는 세 종족의 본부·보급·가스·기본 생산/연구와 애드온 경로에 필요한 부분집합이다. 전체 유닛·건물·기술은 6단계다. 최종 아트·애니메이션을 완성했다고 표시하지 않는다. 4단계 완료 판정은 구현/검증 결과가 나온 뒤 기록한다.

## 적용 계약

- 비용/인구는 명령 실행 틱에 검증하고 즉시 예약한다. 같은 틱의 후속 명령도 예약 후 잔액을 본다. 여러 생산 건물을 선택한 단발 주문은 사용 가능한 대기열 중 가장 짧은 하나에 들어간다(동률은 엔티티 ID).
- 반복 예약은 건물당 한 종류이며 사용자 대기열이 비었을 때 한 주문을 채운다. 최신 반복 지정이 이전 지정을 대체한다. 자원·인구·라바·동력 부족은 대기하며 사용자 주문을 재배열하지 않는다.
- 도착 전 건설 예약은 100%, 착공 후 건설 취소는 미네랄/가스 각각 정수 내림 75%를 환불한다. 유닛·연구 수동 취소는 100%이며 저그 알 취소는 소비한 라바를 돌려주지 않는다. 연구 건물 파괴는 75% 환불이다.
- 드론은 착공할 때 건물로 변태하며 취소 시 기존 체력의 드론으로 돌아온다. SCV는 건설에 계속 참여하며 이동·정지로 중단한 뒤 SCV 선택→미완성 건물 터치로 재개한다. 프로브는 착공 후 해방된다.
- 채취는 노드당 한 작업자가 잠근다. 이동과 운반은 기존 경로·충돌 시스템을 거친다. 자동 채취는 현재 일꾼과 완성된 아군 본부가 같은 기지 구역 안에 있고 보이는 자원에만 발동한다. 고갈 미네랄은 통행 가능해지며 고갈 가스는 회당 2를 준다.
- 라바/알은 이번 부분집합에서 해처리별 저장 상태와 병렬 생산 주문으로 표현한다. 라바 3개 상한과 자연 재생 시간은 경제 50% 가속 대상이 아니며 변태 시간에만 적용한다. 전투 가능한 개별 라바/알 개체는 전체 콘텐츠 단계에서 추가한다.
- 크립 확산은 원본의 8방향 이웃 수 우선/동률 무작위 선택을 따르되 저장된 `map` RNG를 사용한다. 10×6.25타일 타원 범위와 자연 확산 시간은 경제 가속 대상이 아니다. 파괴 뒤 크립 소멸은 전투 생명주기 단계에서 연결한다.
- 단계 4 시야는 아군 개체의 로컬 작업 범위만 제공한다. 고지대·탐지·마지막 정보 30초 등 완전한 전장의 안개는 단계 5이다. 잔액·작업 상태·생산/연구 대기열은 아군 정보만 렌더 메시지에 담는다.
- 내부 세 종족 시나리오가 실제 시작 자원으로 동작한다. 개발 전용 화면은 공개 게임 목록/라우트에 연결하지 않는다. `npm run dev:stark-rift-lab`로 실행하며 기본 시나리오는 테란 기지 운영이다.
- 연속 배치는 `placeBuilding.payload.queued`로 명시한다. 테란/프로토스는 현재 작업을 유지하며 후속 16개를 저장한다. 저그는 아직 건설하지 않는 선택 드론을 사용한다. 명시적 다른 작업 명령은 건설 연결을 중단하며 남은 예약은 취소/재개 대상으로 유지한다.
