## 1. 프로젝트 원칙

- 이전 Claude 초안과 그 초안을 기반으로 만든 Stark Rift 구현은 사용하지 않는다.
- 기존 Stark Rift 소스, 테스트, 설계 문서는 삭제된 상태이며 신규 기획을 기준으로 다시 만든다.
- 현재 단계에서는 게임 코드를 만들지 않고 규칙과 조작 체계를 먼저 확정한다.
- 게임의 기준 콘텐츠는 스타크래프트 1 브루드워의 테란, 저그, 프로토스 유닛과 건물이다.
- 미세조작을 줄이고 자원 채취, 생산, 건설, 정찰, 이동, 전투, 대열과 전략 선택에 집중한다.
- 모바일 세로 화면을 기본으로 한다.

## 2. 경기 기본 규칙

- 기본 대전은 플레이어 대 AI의 1대1 섬멸전이다.
- 목표 경기 시간은 8~12분이다.
- 기본 지도 크기는 96×96타일이다.
- 2대2 또는 4인전 지도는 128×128타일을 사용한다.
- 최대 인구수는 100이다.
- 유닛의 비용, 체력, 보호막, 공격력, 방어력, 사거리, 인구수 비용, 기술 에너지 비용과 업그레이드 효과는 브루드워 수치를 기준으로 한다.
- 자원 채취, 건설, 생산, 연구와 저그 변태 시간은 원작의 50%로 단축한다.
- 이동속도와 무기 공격주기는 원작 기준을 유지한다.

### 2.1 시작 상태

- 본부 건물 1개
- 일꾼 4기
- 미네랄 50
- 종족별 원작 시작 인구수

### 2.2 승패 조건

커맨드 센터, 해처리·레어·하이브, 넥서스의 공통 명칭은 **본부 건물**이다.

- 상대의 모든 본부 건물을 파괴하면 즉시 승리한다.
- 자신의 모든 본부 건물을 잃으면 패배한다.
- 건설 중인 본부 건물도 생존 거점으로 인정한다.
- 다른 유닛과 일반 건물이 남아 있어도 본부 건물이 없으면 패배한다.
- 양쪽의 마지막 본부 건물이 같은 순간 파괴되면 무승부다.
- 마지막 본부 건물의 위치를 자동으로 공개하지 않는다.
- 언제든 항복할 수 있다.
- AI 대전은 일시정지할 수 있다.
- 앱이 백그라운드로 전환되면 자동으로 일시정지하고 저장한다.
- 다시 접속하면 진행 중인 경기를 이어서 시작한다.

## 3. 세로 화면 구성

화면을 세로 방향으로 1:2:1 비율로 나눈다.

- 상단 25%: 미니맵, 자원, 인구수, 본부 수, 알림, 확대, 경기 메뉴
- 중앙 50%: 메인 전장
- 하단 25%: 부대 슬롯, 선택 정보, 생산·건설·기술·명령

기기별 안전 영역과 브라우저 UI를 고려해 25:50:25를 기준으로 조금씩 보정하되, 전장 크기는 메뉴 전환 중 바뀌지 않게 한다.

### 3.1 카메라 확대

- 근접: 약 14×16타일
- 기본: 약 18×20타일
- 광역: 약 24×27타일
- 핀치 중에는 부드럽게 변하고 손을 떼면 가까운 단계에 맞춘다.
- 확대 수준은 실제 시야와 공격 사거리에 영향을 주지 않는다.
- 광역 화면에서는 유닛을 단순 아이콘으로 바꾸어 가독성과 성능을 유지한다.
- 빈 지형에서 시작한 드래그는 카메라 이동이다.
- 화면 가장자리 자동 스크롤은 기본적으로 끄고 설정에서 활성화할 수 있다.

## 4. 미니맵과 상단 정보 패널

상단 너비의 약 55%를 정사각형 미니맵에 사용하고 나머지 영역에 정보를 배치한다.

### 4.1 미니맵 표시

- 아군 유닛: 종족색 점
- 아군 건물: 유닛보다 큰 사각형
- 본부 건물: 테두리가 있는 큰 아이콘
- 현재 발견된 적: 빨간색
- 마지막으로 확인한 적: 30초 동안 흐려지는 반투명 표시
- 정찰하지 않은 지역: 검은색
- 정찰했지만 현재 시야가 없는 지역: 어두운 지형색
- 현재 메인 화면 영역: 흰색 사각 테두리
- 선택한 부대: 밝은 테두리
- 집결지와 순찰 지점: 명령 아이콘

### 4.2 미니맵 조작

- 기본 터치: 카메라 즉시 이동
- 기본 드래그: 카메라 연속 이동
- 생산 건물 선택 후 터치: 집결지 설정
- 순찰 명령 중 터치: 순찰 지점 설정
- 수송선 하차 명령 중 터치: 이동 후 하차 지점 설정
- 일반 유닛 선택 상태에서 터치: 카메라 이동
- 공격 기술은 미니맵에서 사용하지 않는다.
- 명령 모드에서는 미니맵 테두리와 커서를 명령 색상으로 바꾼다.

### 4.3 상단 정보

- 미네랄
- 베스핀 가스
- 현재 인구수/최대 인구수
- 보유 본부 건물 수
- 대기 중인 일꾼 수
- 경기 시간
- 근접·기본·광역 확대 버튼
- 일시정지와 설정 메뉴

인구수는 80%부터 노란색, 90%부터 주황색, 생산이 막히면 빨간색으로 표시한다. 부족한 자원으로 명령을 내리면 해당 자원 수치를 붉게 점멸한다.

### 4.4 알림 우선순위

1. 본부 건물 공격
2. 아군 부대 공격
3. 인구수 부족
4. 건설·생산·연구 완료
5. 일꾼 대기
6. 자원 고갈

- 최근 알림을 최대 3개 표시한다.
- 같은 알림은 묶어서 횟수를 표시한다.
- 알림을 터치하면 발생 위치로 카메라를 이동한다.
- 생산 완료 알림을 터치하면 해당 건물 또는 유닛을 선택한다.
- 알림을 옆으로 밀면 제거한다.
- 은폐된 적에게 공격받으면 위치만 알리고 적의 정체는 표시하지 않는다.
- 본부 공격은 강한 진동, 일반 공격은 짧은 진동을 사용한다.

## 5. 선택과 부대 슬롯

### 5.1 전투 유닛 선택

- 짧은 터치: 해당 유닛 한 기 선택
- 길게 누르기: 주변의 같은 종류 유닛을 가까운 순서로 최대 10기 선택
- 길게 누르는 동안 선택 반경과 포함될 유닛을 미리 표시한다.
- 빈 부대 슬롯이 있으면 선택한 그룹을 자동 등록한다.
- 슬롯이 가득 차면 교체할 슬롯을 선택한다.
- 기존 부대의 유닛을 다른 슬롯에 넣을 때는 이동 내용을 확인한 뒤 재등록한다.

### 5.2 부대 슬롯

- 전투 부대 슬롯은 5개다.
- 슬롯 하나에는 같은 종류의 전투 유닛을 최대 10기 등록한다.
- 슬롯 터치: 해당 부대 선택
- 슬롯 두 번 터치: 선택 후 해당 부대 중앙으로 카메라 이동
- 슬롯을 가로로 훑기: 지나간 부대들을 복수 선택
- 슬롯에서 중앙 전장으로 위쪽 스와이프: 공격이동
- 일부 유닛이 파괴돼도 슬롯을 유지한다.
- 부대가 전멸하면 슬롯을 자동으로 비운다.
- 새 유닛을 기존 슬롯에 보충할 수 있다.

### 5.3 일꾼 선택

- 짧은 터치: 일꾼 한 기 선택
- 길게 누르기: 주변 일꾼 최대 10기를 임시 작업반으로 선택
- 일꾼 작업반은 전투 부대 슬롯을 사용하지 않는다.

## 6. 이동과 공격 명령

- 선택 후 지형 터치: 이동만 수행
- 선택 후 적 유닛 또는 적 건물 터치: 집중공격
- 선택된 유닛 또는 부대 슬롯에서 목표 지점까지 스와이프: 공격이동
- 아군 유닛 터치: 해당 아군을 새로 선택
- 이동 전용 명령에서는 적을 만나도 목적지까지 이동한다.
- 목적지 도착 후 일반 경계 상태로 전환한다.
- 수송선은 기본적으로 이동 전용이며 자동으로 적을 피하지 않는다.

명령 우선순위는 다음과 같다.

1. 적 직접 지정 집중공격
2. 이동 전용 명령
3. 공격이동과 전투 태세

## 7. 대열과 전투 태세

### 7.1 대열

- 전열: 병력을 옆으로 넓게 배치하는 기본 전투 대열
- 종대: 좁은 길과 장거리 이동
- 분산: 광역 공격 피해를 줄이도록 간격 확대

좁은 통로에서는 임시로 종대로 압축하고 통과 후 선택한 대열로 복귀한다. 느린 부대에 전체 이동속도를 강제로 맞추지 않고 목적지에서 대열을 완성한다.

### 7.2 전투 태세

- 자율 교전: 가까운 적과 위협도가 높은 적을 공격하고 짧게 추격
- 대열 유지: 추격을 줄이고 대열과 지원 유닛을 보호
- 목표 돌파: 목적지를 우선하며 경로를 막거나 사거리 안에 있는 적만 공격

## 8. 자동 표적 선택

표적 우선순위는 다음과 같다.

1. 플레이어가 직접 지정한 목표
2. 현재 아군을 공격하는 적
3. 아군 지원·공성 유닛을 위협하는 적
4. 사거리 안의 전투 유닛
5. 가까운 일꾼
6. 방어 건물과 생산 건물
7. 본부 건물과 일반 건물

- 공격할 수 없는 공중·지상 목표는 제외한다.
- 탐지되지 않은 은폐 유닛은 선택하지 않는다.
- 같은 부대 안에서 필요한 예상 피해량만 배분해 과도한 집중을 줄인다.
- 직접 지정한 목표에는 선택된 병력이 집중공격한다.
- 근접 유닛은 적 주위로 퍼져 포위한다.
- 원거리 유닛은 최대 사거리를 유지한다.
- 지원 유닛은 아군 최전선 뒤에 머문다.
- 목표를 너무 자주 바꾸지 않도록 짧은 목표 유지 시간을 둔다.

## 9. 자원과 일꾼

- 미네랄, 베스핀 가스, 인구수 체계를 유지한다.
- 본진과 확장기지는 모두 자원 반납 거점이다.
- 가스 건물을 건설해야 가스를 채취할 수 있다.
- 자원은 고갈되며 고갈된 가스에서 원작처럼 소량을 채취할 수 있다.
- 미네랄 한 덩이당 일꾼 2기를 적정 포화로 표시한다.
- 세 번째 일꾼부터 효율이 낮아진다.
- 가스는 일꾼 3기를 적정 포화로 표시한다.
- 자원 UI에 현재 일꾼 수와 권장 수를 표시한다.

### 9.1 일꾼 자동 행동

- 목적지에 도착해 할 일이 없으면 기본적으로 정지한다.
- 자신의 시야 안에 아군 본진 또는 확장기지와 자원이 함께 있을 때만 자동 채취한다.
- 가까운 자원 중 일꾼이 덜 배치된 곳을 우선한다.
- 적 지역이나 정찰 경계에서는 자원을 찾기 위해 돌아다니지 않는다.
- 명시적인 이동, 건설, 정찰 명령은 자동 채취보다 우선한다.
- 공격받으면 알림만 보내고 자동 후퇴하지 않는다.
- 새로 생산된 일꾼도 주변 기지와 자원이 보일 때만 자동 채취한다.
- 자원이 고갈되면 같은 지역에서 다른 자원과 반납 거점을 확인할 수 있을 때만 재배치한다.

## 10. 건설

- 일꾼 선택 후 하단의 건설 버튼으로 건물을 선택한다.
- 메인 화면에서 배치 지점을 터치하면 반투명 미리보기를 표시한다.
- 건설 가능 위치는 초록색, 불가능한 위치는 빨간색이다.
- 자원 채취 동선을 방해하는 위치는 노란색으로 경고한다.
- 다시 터치하거나 확인 버튼을 누르면 건설을 시작한다.
- 가스 건물은 간헐천을 직접 터치한다.
- 미니맵에서는 건설하지 않는다.
- 건물 배치는 숨겨진 격자를 사용하지만 유닛 이동은 자유 이동이다.

종족별 원작 규칙을 유지한다.

- 테란: SCV가 건설을 지속하고 애드온 공간을 확보해야 한다.
- 저그: 드론이 건물로 변태하고 크립 제약을 받는다.
- 프로토스: 프로브가 워프를 시작하고 파일런 동력 제약을 받는다.

건물 버튼을 길게 누르면 연속 건설 모드를 켠다. 여러 일꾼이 선택돼 있으면 배치 위치에서 가까운 명령 가능한 일꾼부터 배정한다.

## 11. 생산과 연구

### 11.1 생산 건물 선택

- 짧은 터치: 생산 건물 하나 선택
- 길게 누르기: 주변의 같은 종류 생산 건물 선택
- 건물 그룹은 부대 슬롯을 사용하지 않는 임시 선택이다.

### 11.2 생산

- 유닛 버튼 터치: 대기열에 한 기 추가
- 여러 건물을 선택하면 대기열이 짧은 건물부터 분배
- 건물별 생산 대기열 최대 5개
- 유닛 버튼 길게 누르기: 반복 생산 켜기·끄기
- 자원 또는 인구수가 부족하면 대기하고 조건이 충족되면 재개
- 진행 중인 생산은 원형 게이지로 표시
- 대기열 항목은 두 번 터치해 취소
- 환불 비율은 원작 규칙을 따른다.

### 11.3 집결지

- 생산 건물을 선택한 뒤 메인 화면 또는 미니맵을 터치해 집결지를 설정한다.
- 전투 유닛은 집결지까지 공격이동한다.
- 일꾼은 집결지까지 이동만 수행한다.

### 11.4 연구와 업그레이드

- 능력 연구와 수치 업그레이드를 탭으로 구분한다.
- 버튼에 현재 단계, 최대 단계, 비용, 남은 시간, 선행 건물과 적용 유닛을 표시한다.
- 같은 연구는 중복 시작할 수 없다.
- 여러 연구 건물을 선택하면 비어 있는 건물에 자동 배정한다.
- 연구 취소는 두 번 터치로 확인한다.

## 12. 수송

### 12.1 탑승

1. 드롭십, 셔틀 또는 수송 가능한 오버로드 선택
2. 탑승 버튼 터치
3. 메인 화면의 아군 유닛 또는 하단 부대 슬롯 터치
4. 대상 유닛이 수송선까지 이동해 탑승

- 여러 수송선을 선택하면 원작의 수용 공간에 맞춰 자동 분배한다.
- 공간이 부족하면 가까운 유닛부터 탑승한다.
- 수송 중에도 기존 부대 슬롯을 유지한다.
- 오버로드는 원작의 수송 업그레이드 후 사용할 수 있다.

### 12.2 하차

- 하차 버튼을 누르고 메인 화면 또는 미니맵에서 지점을 지정한다.
- 현재 위치를 지정하면 즉시 하차한다.
- 메인 화면에서는 지정한 대열에 맞춰 배치한다.
- 미니맵에서는 해당 지역의 가장 가까운 유효 지형에 하차한다.
- 여러 수송선은 서로 겹치지 않도록 위치를 나눈다.
- 하차한 유닛은 기존 부대 슬롯과 전투 태세를 유지한다.
- 수송선이 파괴되면 탑승 병력도 소멸한다.

### 12.3 개별 하차

- 수송선을 선택하면 탑승 유닛을 개별 초상화로 표시한다.
- 초상화에는 유닛 종류, 체력, 보호막과 에너지를 표시한다.
- 초상화를 한 번 터치하면 해당 유닛만 현재 위치에 즉시 하차한다.
- 여러 초상화를 차례로 터치해 원하는 유닛만 순서대로 내릴 수 있다.
- 전체 하차 버튼을 별도로 둔다.
- 초상화를 길게 누르면 하차시키지 않고 상세 정보를 보여준다.

## 13. 기본 기술 규칙

### 13.1 스팀팩

- 마린·파이어뱃이 실제 교전을 시작할 때 주변에 치료 가능한 메딕이 있으면 자동 사용한다.
- 메딕의 에너지가 부족하거나 유닛 체력이 너무 낮으면 자동 사용하지 않는다.
- 효과가 끝나기 전에는 중복 사용하지 않는다.
- 메딕이 없을 때는 사용자가 기술 버튼으로 수동 사용한다.

### 13.2 시즈 모드

- 사용자가 기술 버튼으로 직접 토글한다.
- 여러 탱크를 선택하면 동시에 전환한다.
- 시즈 상태에서 이동 명령을 받아도 자동으로 해제하지 않는다.

### 13.3 사이오닉 스톰

- 하이 템플러가 여러 적에게 공격받으면 사거리 안에서 적이 가장 밀집한 영역에 자동 시전한다.
- 한 명의 적에게만 공격받으면 스톰을 쓰지 않고 가까운 교전 중인 아군 뒤로 후퇴한다.
- 자신이 공격받지 않는 교전에서는 가장 밀집한 적을 향해 이동하되 아군 최전선보다 앞으로 나가지 않는다.
- 전방 아군이 없으면 적에게 접근하지 않는다.
- 아군 피해와 기존 스톰 영역을 고려해 중복을 방지한다.
- 여러 하이 템플러는 서로 다른 지역을 맡는다.
- 사용자가 직접 지정하면 수동 명령을 우선한다.
- 자동 스톰은 기본 활성화하며 기술 버튼을 길게 눌러 끌 수 있다.

### 13.4 상태 변화 기술

클로킹, 버로우와 시즈 모드처럼 자신의 상태를 바꾸는 기술은 수동 토글이다.

- 고스트·레이스 클로킹: 수동 토글
- 저그 버로우: 수동 토글
- 러커: 직접 버로우해야 공격 가능
- 이동·공격 명령으로 자동 해제하지 않음
- 다크 템플러·옵저버 영구 은폐와 아비터 은폐장은 원작 고유 효과 유지

## 14. 대상 지정 기술과 자동 시전

### 14.1 공통 조작

- 기술 버튼 짧게 터치: 한 번 수동 사용
- 기술 버튼 길게 누르기: 조건부 자동 시전 켜기·끄기
- 자동 상태는 기술 버튼에 `A`로 표시한다.
- 부대를 선택하고 토글하면 같은 시전자 전체에 적용한다.
- 새로 부대에 들어온 같은 종류 유닛은 부대의 설정을 이어받는다.
- 저장 후 이어서 할 때 자동 시전 설정도 유지한다.
- 수동 지정은 자동 판단보다 우선한다.
- 여러 시전자가 같은 대상 또는 영역에 기술을 중복 사용하지 않는다.
- 자동 시전을 위해 아군 최전선보다 앞으로 나가지 않는다.

### 14.2 기본 자동 기술

- 메딕 힐
- 메딕 리스토레이션
- 사이언스 베슬 디펜시브 매트릭스
- 하이 템플러 사이오닉 스톰
- 리버 스캐럽 자동 보충
- 캐리어 인터셉터 자동 보충

### 14.3 선택 가능한 자동 시전

- 메딕: 옵티컬 플레어
- 고스트: 락다운

- 디파일러: 다크 스웜, 플레이그

- 벌처 스파이더 마인 배치
- 클로킹, 버로우, 시즈 모드

### 14.5 자동 시전 목표 배분

- 메딕은 탐지기와 시야가 넓은 적에게 옵티컬 플레어를 분산한다.
- 고스트는 시즈 탱크, 골리앗, 드라군, 리버, 캐리어 등 고가 기계 유닛에 락다운을 분산한다.
- 범위 기술은 이미 적용된 영역을 피한다.
- 죽을 만큼 피해가 예약된 대상에 고비용 기술을 낭비하지 않는다.
- 에너지가 부족한 시전자는 후방에서 대기한다.

## 15. 시야, 정찰과 탐지

- 한 번도 보지 못한 지역은 검은색이다.
- 정찰했지만 현재 시야가 없는 지역은 어두운 전장의 안개로 표시한다.
- 아군이 이동하거나 파괴되면 해당 지역의 실시간 시야는 즉시 사라진다.
- 적 유닛은 마지막 위치에 흐린 표식으로 남고 30초 동안 점차 사라진다.
- 마지막 위치 표식은 갱신되지 않으며 공격할 수 없다.
- 적 건물은 마지막으로 확인한 모습을 기억하고 다시 정찰했을 때 갱신한다.
- 지형과 자원 위치는 한 번 정찰하면 계속 기억한다.
- 은폐·버로우 유닛은 탐지기가 있는 현재 시야에서만 표시한다.
- 탐지되지 않은 적은 메인 화면과 미니맵에서 선택하거나 공격할 수 없다.

## 16. 지형 규칙

- 지형은 저지대, 고지대, 경사로, 통로와 이동 불가 지역으로 나눈다.
- 지상 유닛은 절벽, 물과 우주 지형을 통과할 수 없고 경사로로만 고지대로 이동한다.
- 공중 유닛은 지형 이동 제약을 무시한다.
- 저지대에서 고지대를 공격하면 약 50% 확률로 빗나간다.
- 아군이 고지대 시야를 확보하면 빗나감 불이익을 제거한다.
- 기술과 범위 효과는 고저 차이로 빗나가지 않는다.
- 고지대에 별도 공격력·방어력 보너스를 주지 않는다.
- 사거리와 시야가 확보되면 절벽 너머를 공격할 수 있다.
- 대형 유닛과 아군·적군 모두 충돌 판정을 적용한다.
- 목적지가 막혀 있으면 가장 가까운 도달 가능 위치까지 이동하고 경고한다.

## 17. 첫 지도: 균열 분지

96×96타일의 180도 회전 대칭형 1대1 지도다.

- 플레이어 A는 북서쪽, 플레이어 B는 남동쪽에서 시작한다.
- 본진은 고지대이며 경사로 하나로 앞마당과 연결한다.
- 중앙은 여러 방향에서 진입할 수 있는 넓은 저지대다.
- 좌우에는 외곽 확장기지를 배치한다.
- 중심을 가로지르는 우주 균열은 지상 이동 불가 지형이다.
- 중앙의 짧은 경로와 좌우의 넓은 우회 경로를 제공한다.
- 첫 지도에는 섬과 파괴 가능한 장애물을 넣지 않는다.
- 중앙 자원 지역은 네 방향이 열려 있어 장기간 방어하기 어렵게 만든다.
- 시즈 탱크나 리버가 중앙 전체를 한 지점에서 통제하지 못하도록 고지대를 분리한다.

### 17.1 자원 배치

각 진영에는 다음 거점을 둔다.

- 본진: 미네랄 8, 가스 1
- 앞마당: 미네랄 7, 가스 1
- 외곽 확장기지: 미네랄 6, 가스 1
- 중앙 경쟁 지역: 미네랄 8, 가스 2

지도는 미네랄 거리, 가스 거리, 건설 공간과 본진 간 이동 거리를 대칭으로 맞춘다. 경기 전에 지도 형태와 자원 위치를 볼 수 있지만 경기 중 적의 현재 상태는 정찰해야 한다.

## 18. 하단 명령창

하단 맨 위에는 부대 슬롯 5개를 고정한다. 아래 영역은 왼쪽 약 28%를 선택 정보에, 오른쪽을 4×2 명령 격자에 사용한다.

### 18.1 선택 정보

- 초상화와 이름
- 체력, 보호막, 에너지
- 선택된 유닛 수
- 현재 대열과 전투 태세
- 클로킹, 버로우, 시즈와 수송 상태
- 자동 시전 중인 기술
- 초상화를 길게 누르면 상세 능력치 표시

### 18.2 기본 명령

- 정지: 현재 이동·공격·순찰 명령 취소 후 일반 경계 상태
- 위치 사수: 이동하지 않고 사거리 안의 적만 공격
- 순찰: 현재 위치와 지정 지점을 반복 이동하고 교전 후 경로 복귀
- 대열: 전열·종대·분산 선택
- 태세: 자율 교전·대열 유지·목표 돌파 선택

자주 쓰는 기술은 최대 3개를 바로 표시한다. 기술이 더 많으면 마지막 칸에 더보기 버튼을 표시한다. 핵 공격과 리콜 같은 위험한 기술은 더보기 화면에 둔다.

모든 터치 버튼은 최소 52dp로 유지한다.

## 19. AI 공통 원칙

- AI도 플레이어와 같은 자원, 생산 시간, 시야와 전장의 안개를 사용한다.
- 정찰하지 않은 병력, 건물과 확장기지를 알 수 없다.
- 숨겨진 생산 대기열과 플레이어 명령을 읽지 않는다.
- 난이도에 따라 유닛 능력치와 비용을 바꾸지 않는다.
- 본부 건물을 맵 구석에 지어 패배만 지연하지 않는다.
- 같은 자동 시전, 중복 방지와 에너지 규칙을 적용한다.

### 19.1 난이도

| 난이도 | 전략 재평가 | 전투 반응 | 특징 |
| --- | ---: | ---: | --- |
| 쉬움 | 약 60초 | 약 2초 | 느린 생산·확장, 단방향 공격, 제한된 고급 기술 |
| 보통 | 약 30초 | 약 1초 | 정상 운영, 정찰 기반 조합 변경과 후퇴 |
| 어려움 | 약 15~20초 | 약 0.6초 | 반복 정찰, 견제, 양방향 공격, 수송과 기술 활용 |

기본 난이도는 보통이다.

### 19.2 전략 전환

- 초반 압박, 균형 운영, 기술 발전과 빠른 확장 중 하나를 선택한다.
- 새 전략 평가가 현재 전략보다 충분히 높을 때만 바꾼다.
- 전략 변경 후 최소 45초 동안 급하게 다시 바꾸지 않는다.
- 이미 생산한 병력을 버리지 않고 새 조합의 지원 병력으로 사용한다.
- 비슷한 전략은 저장 가능한 시드를 이용한 가중 무작위로 선택한다.
- 오래된 정찰 정보의 신뢰도를 낮추고 정보가 부족하면 정찰을 우선한다.

### 19.3 공격과 후퇴

- 쉬움은 추정 전력 1.5배 우세 시 주력 공격을 고려한다.
- 보통은 1.15배 우세하거나 조합이 유리할 때 공격한다.
- 어려움은 비슷한 전력이라도 고지대, 포위와 측면 조건이 좋으면 공격한다.
- 주력의 약 40%를 잃거나 핵심 지원 유닛을 모두 잃으면 후퇴를 고려한다.
- 예상하지 못한 적 증원이나 강한 방어가 나타나면 재평가한다.
- 공격을 지나치게 미뤄 경기가 정체되지 않도록 확장 또는 압박을 실행한다.

## 20. 종족별 AI 전략

### 20.1 테란

**마린·메딕 기본 운영**

- 인구수 8 서플라이 디포, 10 배럭, 12 전후 리파이너리
- 배럭 건설 시작 후 SCV 정찰
- 두 번째 배럭과 아카데미, 스팀팩 연구
- 첫 공격 기준: 마린 8, 메딕 2
- 저글링·질럿 비중이 높으면 파이어뱃 2 추가
- 메딕 전멸 또는 전투력 약 40% 이하에서 후퇴
- 러시를 확인했을 때만 벙커 건설

**시즈 탱크 기계화**

- 팩토리, 머신 숍, 시즈 연구, 두 번째 팩토리
- 탱크 3, 벌처 4, 수리용 SCV 2를 기본으로 구성
- 공중 위협이 있으면 골리앗 2~4 추가
- 탱크 일부가 엄호하고 나머지가 전진하는 방식 사용
- 모든 탱크가 동시에 시즈를 해제하지 않음

**레이스와 드롭십**

- 적의 대공과 탐지가 약할 때 레이스 3~5기로 일꾼과 고립 유닛 견제
- 드롭 조합: 마린 6+메딕 2, 마린 4+파이어뱃 2+메딕 2, 탱크 2 또는 벌처 4
- 정찰된 약한 경로만 사용하고 발각된 경로는 변경
- 보통은 단일 견제, 어려움은 정면 공격과 측면 드롭 병행

### 20.2 저그

**저글링·히드라 기본 운영**

- 오버로드, 스포닝 풀, 두 번째 해처리, 익스트랙터, 히드라리스크 덴
- 저글링 이동속도, 히드라 사거리와 이동속도 연구
- 저글링 8~10, 히드라 6~8을 기본으로 구성
- 저글링이 전열과 측면, 히드라는 후열

**러커 매복**

- 레어, 러커 변태 연구, 러커 4~6 생산
- 통로, 확장기지 입구와 전투 부대 후방에서 직접 버로우
- 적의 이동을 전맵 정보로 미리 알지 않고 정찰 경로만 활용

**뮤탈리스크 견제**

- 레어, 스파이어, 뮤탈리스크 6~9
- 일꾼, 고립된 지원·공성 유닛과 수송선을 우선 공격
- 확인된 대공 방어를 피하고 같은 경로를 반복하지 않음
- 완벽한 겹치기 조작을 사용하지 않음

**울트라리스크·디파일러**

- 하이브, 울트라리스크 캐번, 디파일러 마운드
- 울트라 4~6, 저글링 8~10, 디파일러 2, 히드라 4~6
- 다크 스웜으로 진입로를 만들고 플레이그는 밀집한 적에게 사용
- 컨슘은 체력이 낮거나 전투에서 떨어진 저글링을 우선 희생

### 20.3 프로토스

**질럿·드라군 기본 운영**

- 인구수 7 전후 파일런, 9 전후 게이트웨이
- 게이트웨이 시작 후 프로브 정찰
- 어시밀레이터, 사이버네틱스 코어, 두 번째 게이트웨이
- 드라군 사거리 연구
- 질럿 4~6, 드라군 6~8을 기본으로 구성

**하이 템플러·리버 지원**

- 밀집 지상군에는 하이 템플러와 사이오닉 스톰
- 방어선과 밀집 지상군에는 로보틱스, 리버 1~2, 셔틀 1
- 리버를 반복해서 완벽하게 태웠다 내리는 초고속 조작은 사용하지 않음
- 어려움 후반에는 두 지원 체계를 함께 사용할 수 있음

**다크 템플러 침투**

- 다크 템플러 2~4기를 정면과 다른 경로로 이동
- 탐지기가 없는 일꾼, 본부와 테크 건물을 우선 공격
- 탐지기가 나타나면 목표를 포기하고 후퇴

**캐리어와 아비터**

- 본부 건물 2개 이상과 안정된 수입이 있을 때 캐리어 평가
- 캐리어 3~5와 인터셉터, 옵저버·드라군·커세어 호위
- 아비터는 강한 지상 주력군의 후방에서 은폐장 제공
- 스테이시스는 적 병력 분리에 사용
- 리콜은 정찰이 끝난 위치에만 사용하며 플레이어 조작은 수동

## 21. 아직 정하지 않은 항목

- 게임 시작 화면과 종족·지도·AI 난이도 선택 흐름
- 각 종족의 전체 테크트리 표시 방식
- 명령 예약과 다중 경유지 입력
- 사운드, 음악, 음성 알림과 접근성 옵션
- 그래픽 아트 방향, 애니메이션과 효과 강도
- 튜토리얼과 첫 경기 안내
- 온라인 1대1의 연결, 재접속과 동기화 규칙
- 세부 전투 수치 검증 및 모바일 밸런스 조정 기준
- 저장 데이터 구조와 리플레이
