# 단계 6E · 러커

2026-11-14. 엔진 `0.15.0-stage6e`, 저장·스키마 14, 통신 15. 세로 화면 전용.

- 완성된 레어가 있으면 히드라리스크 덴에서 러커 변태 연구: 200/200, 37.5초. 일반 운영에서는 모두 비용을 지불한다.
- 지상 히드라리스크를 선택해 러커 변태: 추가 50/100, 추가 인구 1, 12.5초. 여러 기는 ID 순으로 자원·인구가 허용하는 만큼만 변태한다. 잠복·탑승 중에는 불가.
- 변태 중에는 체력 200·방어력 10의 공격받는 알이다. 이동·공격·탑승은 불가하고 최종 인구 2를 예약한다. 취소하면 히드라로 돌아오며 변태 비용 전액 환불. 파괴 시 환불 없음. 기존 부대·진형·태세·공격 대기 시간을 유지한다.
- 변태·취소 때 최대 체력 대비 비율을 유지한다. 고정 소수점 HP까지 보존하되 1/256 HP 아래는 버린다.
- 러커 자체 잠복에는 버로우 연구가 필요 없다. 지상에서는 이동만 하며, 잠복 중에만 지상 공격한다. 잠복 중 직접 지정 공격도 제자리에서 실행하고 추격하지 않는다. 잠복 해제에는 기존 충돌 검사 적용.
- Subterranean Spines: 일반 피해 20, 원작 37프레임 공격 간격, 충돌 상자 기준 사거리 6타일, 반경 20픽셀. 고정 직선 경로를 진행하며 각 적 지상 유닛·건물에 한 번만 피해를 준다. 아군·공중·수송 중·미착공 청사진 제외. 최초 표적은 시야·탐지 필요, 범위에 걸리는 잠복한 적은 탐지 없이도 피해를 받는다. 지하 범위 공격에는 일반 고지대 빗나감 판정을 적용하지 않는다.
- 발사 후 표적 이동으로 방향이 바뀌지 않으며 공격자 사망·잠복 해제 후에도 이미 진행하는 공격은 유지된다. 속도 12타일/초, 최대 수명 2초, 동시 최대 128개는 이 게임의 연출·안정성 규칙이다. 원작 애니메이션 프레임별 가시 생성은 재현하지 않는다.
- 렌더러에는 현재 보이는 파동 머리의 좌표·진영·일련번호만 전달한다. 숨은 러커의 ID·원점·궤도·피격 목록·피해량은 전달하지 않는다. 잠복하지 않은 러커와 변태 알을 서로 다른 벡터 그림으로 표시한다.
- 변태 진행, 파동 위치·분수 나머지·기존 피격 목록을 저장해 중복 피해 없이 이어간다. 저장 6~13을 원본 체크섬·원본 버전 해시 검사 후 14로 변환하며 단계 6D 파일은 `.stage6d-backup`으로 남긴다. 시즈 전환·은폐 에너지·수송·RNG 상태를 유지한다.

## 확인 방법

`/stark-rift-dev` → 저그 → 특수 연습 → 새 테스트 시작. 러커(3번 부대), 히드라 2기, 수송선, 완성 연구와 추가 연습 자원 100/200을 제공한다. `러커 선택 → 버로우`로 일렬 표적의 범위 피해 확인. `히드라 선택 → 러커 변태`로 비용·인구·진행 막대·취소·저장/복구 확인. 완료한 러커는 4칸 수송 가능.

## 데이터와 검증

BWAPI v4.4.0과 OpenBW 고정 커밋을 참조한 `data/lurker-original.json`에 비용·체력·방어·무기·수송 크기·연구를 추출했다. `python tools/stark-rift-data/extract-lurker.py <원본 폴더>`로 재생성한다. 원본 URL과 SHA256을 기록하며 기존 JSON/버전 해시는 유지한다. 총 경제 정의 49개. 러커·알은 일반 생산 메뉴에서 직접 구매할 수 없다.

`tests/stark-rift/lurker.test.ts`는 연구·자원·인구 예약·알·취소·부대·잠복·직선 충돌·범위 피해·은폐 정보·저장 결정성·이전 버전 보존을 검증한다. `tools/stark-rift-lab/lurker-smoke.py`는 실제 배포용 Worker/Pixi를 휴대폰 크기 Chromium에서 터치하고 정상 시간으로 변태를 기다린다. 물리 Android/iOS 또는 실제 GPU의 성능 보증과는 별개다. 아비터 은폐장·추가 주문·전략 AI는 후속 구현 대상이다.
