후속 복사·검증·예약 비용 보완 결과는 [2차 성능 기록](stark-rift-stage3-performance-2.md)을 따른다. 아래 표는 1차 최적화 시점의 기록이다.

# 3단계 이동·탐색 비용 1차 최적화

2026-11-03. 엔진 0.6.2-stage3, 저장/스키마 5, 통신 6 유지.
기준: a134c98d21d3f63b4eed710a42ada83a0e979701.
엔진 검증 대상: 9fd33a403b2cd35a6acbcea8ba3218a04bf5a4e7.
검증 실행: https://github.com/itnad/games/actions/runs/41642299759

## 변경

- 안전한 정수 범위의 원/타일 구간 판정은 Number 정수 연산을 사용하고, 범위를 넘으면 BigInt 판정으로 돌아간다. 접선과 층 분리 규칙은 유지했다.
- 타일 후보를 행별로 나누고, 각 행에서 이동 선분과 반경이 닿을 수 있는 열만 검사한다. 나눗셈 경계에서는 바깥으로 한 단위를 더 포함한 뒤 원래의 정확한 판정으로 확인한다. 빈 행은 건너뛴다.
- 장애물 후보와 목적지 예약을 공간 버킷으로 조회한다. 큰 사각 구간이 많은 빈 버킷에 걸치면 전체 순회로 전환한다.
- 탐색 실행 중 고정된 장애물에 대한 격자 중심/인접 간선의 판정을 재사용한다. 반경·층·제외 대상이 다르면 결과를 공유하지 않는다. 캐시는 탐색 실행마다 새로 만들며 저장 상태에 넣지 않는다.
- 이동 중 정지 장애물을 따로 추적한다. 먼저 도착한 개체는 같은 틱의 후속 개체가 검사하기 전에 즉시 등록한다.
- 회피 후보의 거리/y/x 순위를 그대로 유지한다. 최상위 후보가 통과 가능하면 나머지 후보 배열을 만들고 정렬하는 비용을 줄인다.

탐색 시작/확장 예산, A* 순서, 목적지·대열, 이동 속도와 저장 규약은 바꾸지 않았다. 기준 엔진과 상태 전개가 같음을 확인한 최적화이며 버전을 바꿔 저장 호환성을 끊지 않았다.

## 자동 검증

- 전체 Paperoid 빌드, 기존 게임·한국어 조사 회귀 검사, 타입 검사와 Stark Rift 테스트 **203개** 통과.
- 내부 검증 화면 빌드, 실제 별도 Worker 통신, 기존 50기 좁은 통로 전원 도착과 저장 복원 검사 통과.
- 큰 반경·접선·지상/공중·살아 있는/죽은 장애물·도착 후 즉시 장애물 등록·지도 갱신·제외 ID·캐시 간선을 검사했다.
- 기하 판정을 정확한 정수 참조식과 대조하고, 행별 후보/격자 캐시를 켠 조회와 전체 순회 조회를 대조했다.
- 기준 엔진과 선택 시나리오 200틱, 통로 1,200틱, 실제 지도 1,200틱, 교차 600틱, 총 **3,200틱의 매 틱 전체 상태 체크섬이 일치**했다.
- 기존 10,000틱 결정성 검사는 CI에서 5초 실행 제한을 넘겼다. 반복 횟수·비교 조건은 유지하고 이 검사만 20초로 설정했다. 게임의 틱 성능 예산을 완화한 것은 아니다.

CI는 이후에도 내부 화면 빌드와 서버 측정 결과를 남긴다. 고정 기준과의 매 틱 비교는 이번 최적화 PR에만 적용해 향후 의도적인 게임 규칙 변경을 막지 않도록 했다. 결과는 stark-rift-performance 아티팩트로 저장한다.

## 성능 전후 비교

같은 CI 프로세스에서 기준 엔진과 최적화 엔진을 번갈아 실행했다. 첫 20틱을 제외한 평균이다. 외부 클라우드의 이전 측정값과 섞어 개선율을 계산하지 않았다.

| 시나리오 | 기준 평균 ms | 최적화 평균 ms | 변화 |
| --- | ---: | ---: | ---: |
| 선택·명령 | 0.56 | 0.56 | 동일 |
| 50기 통로 | 0.90 | 0.79 | 약 12% 감소 |
| 50기 실제 지도 | 26.28 | 6.17 | 약 77% 감소 |
| 200기 교차 | 17.08 | 9.06 | 약 47% 감소 |

체크섬 비교의 계측 영향과 분리하기 위해 동일 코드로 별도 벤치마크도 실행했다.

| 시나리오 | 틱 평균 ms | 틱 p95 ms | 탐색 평균 ms | 종료 시 남은 명령 |
| --- | ---: | ---: | ---: | ---: |
| 선택·명령 | 0.61 | 1.08 | 0.05 | 0 |
| 50기 통로 | 0.85 | 2.71 | 0.16 | 0 |
| 50기 실제 지도 | 6.13 | 10.87 | 0.22 | 4 |
| 200기 교차 | 9.15 | 13.76 | 3.89 | 80 |

실제 지도는 게임 시간 60초, 교차는 30초를 측정했다. 종료 시 미완료 명령 수는 기준 엔진과 같으며, 이번 변경이 혼잡 해소나 장기 교착 해결을 완료했다는 의미는 아니다.

## 판정과 다음 작업

기능·저장 결정성을 유지하는 비용 절감과 원격 CI 검증은 마쳤다. **성능 목표 전체를 통과하지는 못했다.** 목표는 틱 평균 6ms/p95 10ms 이하, 탐색 평균 2.5ms 이하이며 실제 지도와 200기 시나리오에 초과가 남아 있다.

다음 보완은 교차 200기의 탐색 비용, 재탐색 대기와 미완료 명령, 전체 틱 복사·검증 비용을 분리해 측정하고 줄이는 것이다. 기존의 매 틱 상태 비교를 유지하면서 진행한다. 실제 모바일 GPU·터치·메모리 검증도 남아 있으므로 3단계 최종 완료는 보류한다.

작업 도중 클라우드 실행 도구 연결이 끊겨 변경 기록을 GitHub 작업 브랜치로 복구한 뒤 기존 CI에서 검증을 이어갔다. 로컬 실행 연결의 복구는 확인하지 못했다. Sites 작업 스크립트 부재로 Sites 소스 동기화·배포도 미완료다. 이전 공개 버전 227을 이번 코드의 배포로 표시하지 않는다.
