# Stark Rift 대화 결정 감사표

> 감사 범위: 이 대화에서 Stark Rift 개발을 처음 제안한 시점부터 오프라인 구현 설계 작성까지  
> 최초 감사: 2026-10-30
> 구현 설계 재검토: 2026-11-01
> 기준 문서: `docs/stark-rift-game-design.md`, `docs/stark-rift-implementation-plan.md`

## 1. 감사 목적과 판정 기준

이 문서는 대화에서 합의한 내용을 기획 자료가 빠짐없이 반영하는지 확인하기 위한 추적표다.

판정은 다음 네 가지로 나눈다.

- **확정**: 사용자가 동의했거나 직접 지정한 최종 규칙
- **변경**: 앞선 안을 뒤의 대화에서 수정한 규칙
- **보류**: 필요성은 인정했지만 초기 구현에서는 제외한 항목
- **폐기**: 최종 기획에 사용하지 않기로 한 안

GitHub 권한 설정, 모바일 앱 대화 동기화와 Sites 인증 문제처럼 게임 규칙이 아닌 운영 대화는 기획서 본문에 넣지 않는다. 저장소 경로, 공개 위치, 빠른 시작 순서와 기존 소스 폐기는 게임 개발 범위에 직접 영향을 주므로 포함한다.

## 17. 이번 감사에서 발견하고 보완한 항목

기존 두 문서는 핵심 게임 규칙을 대부분 포함하고 있었다. 다음 항목은 대화에서 확정됐지만 명시성이 부족해 이번 감사에서 보완했다.

1. 최종 영문·한글 게임명과 `Stark Raft` 미사용
2. 자유 이동 RTS라는 상위 구조
3. 별도 v2와 시제품 프로젝트를 만들지 않는 원칙
4. 최종 `/stark-rift` 공개 경로
5. 공개 후 빠른 시작 6개의 정확한 순서
6. `이어서 하기`가 있어도 `빠른 시작`을 유지하는 규칙
7. 전체 게임 목록과 목표 안내 등록

그 외 대화에서 확정된 게임 규칙, UI, AI, 저장, 신고, 밸런스와 구현 순서는 기준 문서에 반영돼 있다.
