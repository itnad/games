# paperoid 게임 UI 가독성 기준

이 문서는 기존 게임과 앞으로 추가되는 모든 게임에 적용하는 필수 기준이다.

## 필수 글자 크기

- 본문, 규칙, 결과 설명: 최소 `15px`(모바일 `16px`)
- 버튼, 입력, 선택지, 탭: 최소 `15px`(모바일 `16px`)
- 상태, 보조 설명, 점수 단위, 범례: 최소 `13px`(모바일 `14px`)
- 카드·말·지도처럼 공간이 제한된 실제 게임 요소: 최소 `12px`
- 장식용 영문이라도 사용자가 의미를 읽어야 한다면 보조 설명 기준을 적용한다.

## 구현 규칙

1. 모든 게임은 `page.tsx`의 `GuidedGame` 안에서 렌더링한다.
2. 공통 하한은 `app/game-readability.css`가 자동 적용한다.
3. 좁은 게임 요소에만 `.game-compact-text` 또는 `data-compact-text="true"`를 사용한다.
4. `12px` 미만의 보이는 텍스트를 새로 추가하지 않는다.
5. 색상만으로 점수·상태를 구분하지 않고 숫자, 글자 또는 아이콘을 함께 표시한다.
6. 모바일에서는 줄바꿈과 영역 높이를 늘려 글자가 잘리거나 겹치지 않도록 한다.

## 검토 항목

- 360px 폭에서 버튼과 안내 문구가 잘리지 않는가?
- 흐린 색의 작은 글씨가 없는가?
- 카드와 말의 숫자·이름이 확대 없이 읽히는가?
- 색각에 관계없이 점수와 상태를 식별할 수 있는가?
- 규칙과 승리 조건을 화면 안에서 확인할 수 있는가?
