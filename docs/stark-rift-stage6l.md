# 단계6L · 메딕 옵티컬 플레어와 리스토레이션

2026-11-17. BWAPI4.4.0과 OpenBW 고정 커밋 `4b046d5f65302b10cb0a745f0fecd37ec85b20a8`의 기술 비용·사거리·대상·실명/복구 규칙을 추출했다. `tools/stark-rift-data/extract-medic-spells.py`가 출처와 파일 SHA256을 포함한 `medic-spells-original.json`을 재생성한다.

## 연구와 시전

아카데미에서 각각100미네랄/100가스에 연구한다. 옵티컬 플레어는 원작1800프레임의 경제시간50%인750틱(37.5초), 리스토레이션은1200프레임의500틱(25초)이다. 한 번만 연구하며 취소 시 전액 환불한다. 기존 특수 연습 시설·자원·유닛 배치를 유지하며 두 기술 연구나 추가 에너지를 무료 지급하지 않는다.

메딕이 옵티컬 플레어75에너지·9타일(288px), 리스토레이션50에너지·6타일(192px)로 시전한다. 실제 양쪽 유닛의 충돌 경계를 기준으로 포함 사거리를 계산한다. 현재 보이는 지상/공중, 유기체/기계, 아군/적군/자신의 비건물 유닛 한 기를 대상으로 한다. 수송 내부와 스테이시스 대상은 제외한다. 시전자도 수송·탑승 대기·스테이시스·시전 대기 상태에서는 사용할 수 없다. 실패한 시전은 에너지와 치료 지시를 소모하지 않는다.

현재 주문 구현 정책은 기존 기술과 같이 사거리 밖을 거절하며 자동 접근하지 않는다. 유효 명령이 실행되는 틱에 상태 효과를 즉시 적용한다. 원작 무기22프레임에서 공유 시전 대기18틱(0.9초)을 적용하며 원작 무작위 지연과 애니메이션 선행시간은 재현하지 않는다. 성공 시 치료·이동·탐색을 정리하고 자동치료에20틱 유예를 준다. 대기 중 새 치료/주문을 막고 이동 명령은 허용한다. 두 기술의 자동시전은 제공하지 않는다.

## 실명과 복구

원작 OpenBW의 `get_unit_sight_range`에 따라 실명 유닛의 시야를2타일로 제한하고 탐지를 중단한다. 공동 시야·고지대 가시성에도 반영하며 이미 탐색한 안개 기억은 유지한다. 지속시간은 영구이며 다른 유닛의 공유 시야·탐지는 정상 동작한다. 재시전은 다시 에너지를 지불하고 시전자 소유자 비트를 합친다. 시전자 사망, 수송, 스테이시스, 유닛 변태로 실명을 해제하지 않는다. 실명 드론은 건설 취소 시 실명을 유지하고 건물 완성 시 해제한다. 공사 중 건물에 유닛용 실명 표시·시야 축소를 적용하지 않는다.

리스토레이션은 현재 구현된 해제 대상인 실명을 제거한다. 체력/보호막 회복, 스팀팩·은폐·스테이시스 해제는 하지 않는다. 아직 없는 인스네어·플레이그·패러사이트 등은 이 단계에 추가하지 않았다. 건강한 대상에게도 시전과 에너지 지불이 가능하다. 기술 무기 데이터의 피해량 필드를 실제 피해로 적용하지 않는다.
