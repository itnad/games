# 3단계 최종 검토 — 2026-11-11 (KST)

## 판정과 범위

구현과 자동 검증의 판정은 아래 실행 결과를 따른다. 실제 Android Chrome·iOS Safari, 물리 GPU와 해당 기기 전체 메모리 심사는 별도 미확인 항목이다. 실물 검사를 자동 통과로 바꾸지 않는다.

게임은 모바일 세로 화면만 지원한다. 가로 전환·가로 최초 접속에서는 안내·입력 차단·일시정지를 적용하고, 세로 복귀 시 카메라·선택·부대 슬롯을 유지하며 사용자가 재개한다. 공개 라우트와 경제·건설·생산은 후속 단계 범위다.

## 확인 및 보완

- 검증 도구의 버튼 스타일을 도구 영역으로 한정해 실제 게임 버튼의 최소 52 CSS px를 유지했다.
- 슬롯 영역의 기본 브라우저 스크롤을 막아 가로 연합 선택과 전장으로의 공격 이동이 끊기지 않게 했다.
- 일시정지 중 그룹 선택을 임시 선택으로 유지하고 등록·이동 등의 실행 명령을 보내지 않는다. 같은 틱의 정지/재개도 UI에 즉시 전달한다.
- 거절된 부대 교체는 기존 그룹과 명령 순번에 영향을 주지 않는다. 실제 게임의 확인창을 유지하며 자동 합성 테스트에서만 수락 응답을 사용한다.
- 화면 방향 MediaQueryList를 재사용하고 구독을 해제한다. 전장·미니맵의 도형은 모양/색/선택 표시가 바뀔 때 갱신하며 위치 보간마다 GPU 도형을 다시 만들지 않는다.
- 개발 모드 React의 UserTiming 누적을 관찰했다. 내부 검증 화면의 개발 버퍼를 1초마다 비우고 장시간 성능 검증은 프로덕션 빌드로 수행한다. 자체 틱·프레임 표본은 이 버퍼와 독립적이다. 초기 개발 검사 약 406초의 탭 충돌 기록을 보존하며 성공 결과로 치환하지 않는다.
- 합성 테스트에서 모달·화면 안정화 대기로 멈추던 부분을 명시적인 확인 응답·스크롤 처리로 바꿨다. 명령 1회 발행과 Worker 승인은 계속 검사한다. 화면 캡처가 실패해도 원래 실패 내용을 보존한다.

엔진의 정수 이동 규칙·저장 구조·통신 형식은 바꾸지 않았다. 엔진 0.6.2-stage3, 저장/스키마 5, 통신 6을 유지한다.

## 자동 검사

- 전체 npm test: 프로덕션 빌드, 기존 게임/한국어 회귀, 타입 검사, Stark Rift 전용 221개.
- 유닛/통합 범위: 결정성·실제 별도 Worker·체크포인트·선택·부대·경로 탐색·충돌·대열·저장 복원.
- 브라우저: Chromium 154, SwiftShader 소프트웨어 WebGL, 390×844 / 360×640 세로 합성 터치. 선택·등록 승인·저장/복원·연합 선택·공격 이동 1회 승인·취소·키보드·가로 차단·세로 복귀·가로 최초 접속을 검사한다.
- 10분 관찰은 실제 96×96 지도에서 50기를 두 목적지 사이로 이동시킨다. 단일 Worker·50개체·진행 상태·명령 거절·JavaScript/Worker 오류를 관찰한다. 전원 도착/중첩의 별도 판정은 기존 Node 교통 검사를 따른다.

## 실행 결과

- 전체 npm test와 별도 내부 화면 빌드 통과. 전용 테스트 **221개**와 타입 검사 통과.
- 세로 두 크기, 가로 최초 접속/회전 차단, 저장·복원, 부대·키보드·취소 검사 모두 통과. 원본 보고서의 오류 목록은 비어 있고 화면 캡처와 JSON 내보내기도 완료했다.
- 연속 실행 **600.04초**, 50기 이동 명령 **7회**, Worker 최종 틱 **12,000**. Worker 1개·50개체를 유지했고 명령 거절·JavaScript/Worker 오류가 없었다.
- Chrome 프로세스 RSS 합계: 시작 약 **704.8MB**, 종료 표본 **794.8MB**, 최대 **851.3MB**. 메인 JS 힙은 종료 GC 후 약 **8.79MB**였다. 초기 개발 검사에서 보였던 수 GB의 급증/탭 충돌은 이 프로덕션 실행에서 재현되지 않았다.
- 마지막 200틱의 평균/p95는 **1.47/3.10ms**다. 전체 세션 최대 틱 **115.5ms**와 최대 프레임 간격 **1433.4ms**도 관찰됐다.
- 종료 시 최근 600개 rAF 간격의 평균/p95는 **48.4/100.0ms**다. 소프트웨어 WebGL에서 60fps를 입증한 결과가 아니며 끊김/실제 기기 성능 인수는 계속 남아 있다.
- 자료: `stark-stage3-production-complete/stark-rift-browser-qa.json`, `stark-rift-browser-soak.json`, `stark-rift-browser-soak-session.json`과 세로/가로 차단 화면 캡처를 작업 산출물에 보존했다.


rAF 간격은 GPU 실행 시간이 아니다. JS 힙은 Worker/GPU 메모리를 제외한다. Chrome RSS는 테스트 브라우저 프로세스 집계이며 공유 페이지가 중복 계상될 수 있다. 해당 서버의 관찰을 실제 휴대폰 성능 수치로 해석하지 않는다.

## 저장과 배포

최신 소스는 기존 GitHub main에 반영하고 동일한 커밋을 기존 Sites 소스 저장소로 동기화한다. 해당 커밋에서 생성한 공개 앱 빌드와 기존 D1 마이그레이션을 아카이브에 포함한다. 내부 검증 번들은 공개 배포 산출물에 넣지 않는다. 배포 성공은 별도의 Sites 응답과 배포 기록으로 확인한다.

실행: npm run build:stark-rift-lab → npm run preview:stark-rift-lab → python tools/stark-rift-lab/browser-smoke.py --soak-seconds 600. 기본 주소는 127.0.0.1:4175다.
