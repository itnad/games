# 단계 3 구현 계획

2026-11-02. 공개 라우트 없이 기존 내부 Worker/전장에 연결한다.

1. 엔티티에 종류·이동층·속도·반경을 추가하고 그룹 등록 명령, 이동 상태와 탐색 중간 상태의 저장 계약을 확장한다.
2. 반 타일(128단위) 탐색 격자, 정수 A*, 결정적 동률 처리, 한 틱 신규 탐색 4건·확장 8,000개 제한과 목적지 보정을 구현한다. 탐색 진행·캐시는 저장해 복원 시 완료 시점도 동일하게 한다.
3. 이동/공격이동/집중공격/정지/사수/순찰 명령과 전열·종대·분산, 공간 해시 충돌, 막힘 재탐색을 연결한다. 전투 피해·자동 표적·시야는 단계 5 범위다.
4. 가시 스냅샷 기반 히트 검사, 같은 종류 최대 10기 선택, 5개 슬롯과 복수 선택, 명령 버튼·부대 스와이프를 연결한다. 다른 부대에서 이동/기존 슬롯 교체는 명시적으로 확인한다.
5. 50기 연합 이동, 좁은 통로, 도달 불가 위치, 순찰/사수, 저장·복원 결정성과 UI/Worker 계약을 자동 검증한다. 모바일 GPU·터치의 실제 기기 심사는 별도로 남긴다.

기획 O-03의 기본 선택 반경은 권장안인 4타일을 채택하고 동률은 엔티티 ID로 정렬한다. 실제 원작 유닛 수치는 임의로 채우지 않으며 테스트용 이동 개체는 내부 테스트에만 사용한다.
