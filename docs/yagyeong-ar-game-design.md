# 야경단 AR 게임 기획서

> 상태: 신규 기획 초안 (코드 없음, 규칙·조작·기술 방향 확정용)  
> 최종 갱신: 2026-11-12  
> 저장소: `itnad/games`

## 0. 한 줄 요약

**스마트폰을 들고 실제 거리를 걸어 다니며, 카메라로 비춘 현실 공간에 나타나는 악귀를 조준해 퇴치하는 위치 기반 1인칭 AR 협동 슈팅.**

- 이동·탐색은 `포켓몬 GO`처럼 지도와 GPS로 한다.
- 조우가 시작되면 폰을 들어 카메라 화면 위에서 `오버워치`처럼 역할(격수·결계사·치유사·추적자)을 나눠 싸운다.
- 지역 단위 대형 이벤트는 `배틀그라운드`의 좁아지는 자기장을 빌려 와, 좁아지는 **결계** 안에서 여러 분대가 동시에 악귀를 몰아낸다.
- 테마는 `고스트버스터즈`의 유쾌한 퇴마단을 한국 설화(도깨비·처녀귀신·달걀귀신·물귀신·지박령)로 옮긴 **야경단(夜警團)**이다.

## 1. 프로젝트 원칙

- 게임명은 가제 `야경단`, 영문 표기는 `Yagyeong`이다. 상표 조사 전까지는 가제로 취급하며 "AR 고스트 슈팅"과 같은 설명형 이름은 쓰지 않는다.
- `itnad/games` 저장소의 Paperoid 프로젝트 안에서 개발한다. 공개 경로는 `/yagyeong`으로 예약하고, 완성 기준을 통과하기 전까지 Paperoid 메인, 전체 게임 목록, 빠른 시작에 노출하지 않는다.
- 네이티브 앱이 아닌 **웹(PWA) 우선**으로 만든다. 카메라, 자이로, GPS, 진동은 모두 브라우저 API로 처리한다. 스토어 배포는 웹 버전이 검증된 뒤 별도 판단한다.
- 모바일 세로 화면만 지원한다. 가로 화면에서는 플레이를 막고 세로 전환 안내를 표시한다. 조준은 폰을 든 손의 방향으로 하므로 세로 한 손 파지가 기본 자세다.
- **PvP 직접 사격은 하지 않는다.** 길에서 다른 사람을 폰으로 "쏘는" 연출은 사회적 오해와 안전 문제를 만든다. 플레이어 간 경쟁은 점수·구역 점령·순위로만 한다.
- 안전이 재미보다 우선이다. 이동 중 사격 금지, 도로 위 스폰 금지, 심야 경고는 밸런스가 아니라 규칙이다.
- 카메라 영상은 기기 밖으로 나가지 않는다. 서버는 위치·방향·입력·전투 결과만 받는다.
- 모든 한국어 동적 문구는 `app/korean-particles.js` 헬퍼를 사용한다(AGENTS.md 규칙).

| 집안 순찰 | 걷지 않고 실내에서 하는 보조 모드 | 홈 모드 |

## 3. 핵심 플레이 루프

1. **순찰**: 지도 화면에서 주변 `기운`과 `터`를 확인하고 걸어서 접근한다. 약 40m 안에 들어오면 조우 버튼이 켜진다.
2. **조우 진입**: 폰을 세워 들면 카메라가 켜지고, 지도 화면이 카메라 화면으로 바뀐다. 3초 카운트 뒤 악귀가 현실 공간 위에 나타난다.
3. **교전**: 몸을 돌려 악귀를 화면 중앙 조준점에 맞추고 발사 버튼을 누른다. 역할 기술과 수호령, 분대원이 같은 공간에 보인다. 악귀는 플레이어를 중심으로 이동하므로 제자리에서 회전해야 한다.
4. **정화**: 체력이 0이 된 악귀는 `정화 가능` 상태로 10초 동안 떠 있다. 조준점을 맞춘 채 길게 누르면 부적이 날아가 봉인된다. 이때만 보상과 도감 등록이 생긴다.
5. **정비**: 조우가 끝나면 결과 화면에서 경험치·부적·도감을 확인하고, 다음 순찰 전에 장비와 기술을 바꾼다.

한 조우는 60~150초를 목표로 한다. 걷다가 멈춰서 하는 놀이이므로 3분을 넘기는 조우는 재앙급에서만 허용한다.

## 4. 조작 체계 (세로 한 손 기준)

| 입력 | 동작 |
| --- | --- |
| 폰 방향(자이로·지자기) | 조준. 화면 중앙에 고정 조준점이 있고, 몸과 폰을 돌려 맞춘다 |
| 오른손 엄지 큰 버튼 탭 | 기본 사격(단발). 길게 누르면 연사 또는 충전 |
| 조준점 위 악귀를 길게 누르기 | 정화(봉인) |
| 왼손 엄지 버튼 2개 | 역할 기술 1·2 |
| 화면 상단 중앙 버튼 | 필살. 게이지가 가득 찼을 때만 켜진다 |
| 폰을 아래로 내리기(화면이 땅을 향함) | 재장전. 다시 들면 끝난다 |
| 폰을 세게 흔들기 | 긴급 결계(짧은 무적, 조우당 1회) |
| 화면 좌우 가장자리 화살표 | 화면 밖 악귀 방향 안내. 상단 레이더에도 표시 |

- 터치 조준(드래그로 시점 이동)은 **기본으로 제공하지 않는다.** 몸을 돌리는 것이 이 게임의 정체성이다. 단, 접근성 설정에서 `고정 자세 모드`를 켜면 드래그 조준을 허용하고 악귀 이동 범위를 전방 120도로 제한한다.
- 조준 보정: 조준점 반경 안에 들어오면 약한 끌림을 준다. 자이로 드리프트는 조우 시작 시 지도 방위와 맞춰 보정하고, 30초마다 지자기 센서로 다시 맞춘다.
- 진동: 피격·명중·정화 성공마다 다른 패턴을 쓴다. 지원 기기에서만 켠다.

## 5. 역할 (오버워치식 분업)

분대 최대 4명, 역할 중복 가능. 혼자 할 때는 수호령이 빈 역할 하나를 맡는다.

| 역할 | 핵심 무기 | 기술 1 | 기술 2 | 필살 |
| --- | --- | --- | --- | --- |
| 격수 | 소금총(산탄, 근거리 강함) | 쇠침 투척: 단일 대상 큰 피해 | 횃불: 전방 범위 지속 피해 | 벼락 부름: 화면 안 모든 악귀 큰 피해 |
| 결계사 | 방울창(중거리, 느린 연사) | 결계 펼침: 분대 전체 보호막 | 끌어당김: 은신·도주 악귀 강제 노출 | 금줄: 20초 동안 악귀가 분대 10m 안으로 못 들어옴 |
| 치유사 | 향 연기(약한 범위 피해) | 치유 향: 조준한 분대원 회복 | 부정 씻기: 디버프 해제 | 되살림: 쓰러진 분대원 전원 복귀 |
| 추적자 | 활(장거리, 충전 사격) | 표식: 악귀 약점 노출, 피해 증폭 | 정찰 등: 조우 전 악귀 종류·수 공개 | 혜안: 15초 동안 모든 은신 악귀 노출 + 약점 자동 표시 |

- 역할은 조우 밖에서 자유롭게 바꾼다. 조우 중에는 못 바꾼다.
- 역할별 성장은 **장비**(총·창·향·활의 등급)와 **기술 강화**(레벨업 선택)로 나뉜다. 밸런스 수치는 엔진 상수에 한 번만 두고 이 문서에 복제하지 않는다.
- 분대원은 카메라 화면에 **반투명 아바타와 이름표**로 보인다. 위치는 서로의 GPS 상대 좌표와 나침반으로 추정하므로 2~5m 오차를 전제하고, 아바타는 "방향 표시"로 쓴다. 정밀 위치가 필요한 기술(치유 향)은 분대원 이름표를 조준하는 것으로 처리한다.

## 6. 수호령 (AI 아군)

- 플레이어마다 수호령 1기가 조우에 함께 나타난다. 시작 수호령은 `삽살개`(격수 보조)·`까치`(추적자 보조)·`해태`(결계사 보조) 중 선택한다.
- 수호령은 자동으로 행동하되, 플레이어가 수호령을 조준한 뒤 탭하면 지시(집중 공격·보호·후퇴)를 내린다.
- 혼자 하는 플레이어가 소외되지 않도록, 수호령은 분대가 2명 이하일 때 성능 보정을 받는다.
- 수호령은 정화 성공 수에 따라 성장하고, 특정 터에서만 만나는 희귀 수호령이 있다(수집 동기).

## 7. 악귀 설계

### 7.1 등급

| 등급 | 조우 길이 | 특징 | 보상 |
| --- | --- | --- | --- |
| 잡귀 | 30~60초 | 1~3마리, 단순 패턴, 혼자 가능 | 소량 부적·경험치 |
| 원귀 | 60~120초 | 약점·은신·분열 중 1개 기믹, 2인 권장 | 장비 재료 |
| 지박령 | 120~180초 | 특정 터에 묶인 보스, 터마다 고정 패턴, 주간 리셋 | 희귀 장비·도감 |
| 재앙 | 최대 15분 | 결계 이벤트 전용, 분대 여러 개 동시 참가 | 시즌 보상·칭호 |

### 7.2 행동 유형

AR에서는 적이 "플레이어를 중심으로 어디에 있는가"가 전부다. 모든 악귀 행동은 **방위(수평각)·높이(수직각)·거리** 세 값의 변화로 정의한다.

| 유형 | 행동 | 대응 |
| --- | --- | --- |
| 급습형 | 측면·후방에서 빠르게 다가와 들이받는다 | 레이더를 보고 몸을 돌린다 |
| 포위형 | 여러 마리가 둘레를 돌며 번갈아 공격한다 | 결계사의 금줄, 격수의 횃불 |
| 은신형 | 보이지 않다가 가까이에서 드러난다 | 추적자 표식, 결계사 끌어당김 |
| 분열형 | 피해를 입으면 작은 개체로 나뉜다 | 산탄 무기, 범위 기술 |
| 공중형 | 머리 위에 머물며 아래로 공격한다 | 폰을 위로 들어야 한다. 짧게만 쓴다(목 피로) |
| 저주형 | 공격 대신 디버프(화면 흐림, 조준 흔들림)를 건다 | 치유사 부정 씻기 |

- 수직각은 -20도~+45도 안에서만 쓴다. 바닥이나 바로 머리 위를 보게 하는 패턴은 넣지 않는다.
- 악귀는 플레이어 주변 **2~12m 가상 반지름** 안에 배치한다. 실제 거리를 걸어가게 하지 않는다. 걷는 것은 순찰 단계의 일이다.
- 모든 악귀는 **약점 부위**가 있고, 추적자의 표식이나 혜안으로 노출된다. 약점 명중은 피해 2배 + 짧은 경직.

### 7.3 소재

한국 설화 기반이되, 특정 종교 의례를 직접 묘사하지 않는다. 초기 도감 20종 예시: 달걀귀신, 처녀귀신, 몽달귀신, 물귀신, 도깨비(중립→적대), 두억시니, 그슨대, 어둑시니, 야광귀, 손말명, 객귀, 장산범(지박령), 구미호(재앙급) 등.

## 8. 위치 기반 설계

### 8.1 터와 기운

- `터`는 서버가 공개 지도 데이터(공원, 광장, 정자, 하천변, 오래된 골목)에서 고른 고정 지점이다. 터는 사용자가 직접 등록할 수 없다(장난·사유지 문제).
- `기운`은 서버가 시간·날씨·플레이어 밀도에 따라 터 주변에 뿌리는 임시 출현이다. 해가 진 뒤와 비 오는 날에 원귀 비율이 올라간다.
- 기운은 **도로 중앙선 기준 15m 안쪽, 철도·하천 수면 위**에는 절대 놓지 않는다. 지도 데이터 분류를 믿지 못하는 지역은 기운을 보행자 전용 구역에만 둔다.
- 플레이어가 적은 지역에서는 플레이어 현재 위치 기준 100~300m 안에 최소 기운 2개를 보장한다(시골 보정).

### 8.2 하루와 한 주의 리듬

| 주기 | 내용 |
| --- | --- |
| 일일 순찰 | 매일 KST 기준으로 바뀌는 과제 3개(걷기 거리, 특정 유형 정화, 분대 조우). 해루질럿 일일 도전과 같은 KST 날짜 규칙을 쓴다 |
| 지박령 주간 | 월요일 00:00 KST에 터별 지박령이 바뀐다. 한 터에서 주 1회 정화 가능 |
| 결계 이벤트 | 금·토 저녁 특정 광장·공원에 재앙급이 등장. 20분 전 지도에 결계 범위가 예고된다 |

### 8.3 결계 이벤트 (배틀그라운드식 좁아지는 전장)

- 반경 150m 결계가 15분 동안 세 단계로 60m, 25m까지 좁아진다. 결계 밖에서는 조우가 끊기고 부적을 얻지 못한다.
- 결계 안의 모든 분대는 같은 재앙급 체력을 공유해서 깎는다. 경쟁은 **기여도 순위**로 한다. 상위 분대는 추가 보상을 받지만, 결계 안 모든 참가자가 기본 보상을 받는다.
- 마지막 단계(25m)에서는 참가자 전원이 사실상 한 곳에 모인다. 이 순간을 위해 광장·공원 중앙처럼 **사람이 모여도 안전한 장소**에만 결계 중심을 둔다.
- 결계 중심에 접근 못 하는 참가자(장애·혼잡)를 위해 결계 밖 50m까지는 `원격 지원` 역할로 치유·표식만 가능하게 한다.

## 9. 안전·개인정보 규칙

- **속도 잠금**: 12km/h 초과로 이동 중이면 조우 진입이 막히고 "멈춰서 플레이하세요" 안내만 나온다. 운전자 확인 질문 같은 우회 장치는 두지 않는다.
- **조우 중 이동 억제**: 조우 중 GPS 기준 15m 이상 이동하면 악귀가 사라지고 조우가 중단된다. 걷기와 사격을 분리한다.
- **심야 경고**: 23:00~05:00 KST 조우 시작 전 1회 경고. 미성년 계정은 이 시간대 야외 조우를 막고 집안 순찰만 허용한다.
- **카메라 영상**은 화면 합성에만 쓰고 서버로 전송·저장하지 않는다. 스크린샷 공유 기능도 플레이어가 직접 누를 때만 동작한다.
- **위치 저장**은 터 단위(수십 m 격자)로 뭉뚱그려 저장한다. 원시 GPS 궤적은 서버에 남기지 않는다.
- **사유지·민감 장소**(병원, 학교 운동장 외 교내, 종교 시설 내부, 묘지)는 터 후보에서 제외한다. 신고 기능으로 터를 24시간 안에 비활성화한다.
- 카메라·위치 권한을 거부한 사용자도 `집안 순찰`로 핵심 전투를 할 수 있어야 한다.

## 10. 집안 순찰 (보조 모드)

- 카메라 없이 자이로만으로 방 안에서 하는 모드. 배경은 반투명 어둠 위에 그린 "방 안" 연출이며 카메라 권한이 있으면 카메라를 쓴다.
- 보상은 야외의 50%, 도감 등록은 가능하지만 지박령·재앙은 없다.
- 비·추위·장애·안전 문제로 못 나가는 사용자를 위한 모드이자, 조작 튜토리얼의 기본 장소다.

## 11. 진행과 경제

- **야경꾼 레벨**: 경험치로 오르고 기술 강화 선택지를 준다.
- **장비**: 역할별 무기 1종 + 공용 장비 3종(등롱: 시야·은신 탐지, 염주: 체력, 짚신: 조우 진입 반경). 장비는 재료로 제작·강화한다.
- **부적**: 소모형. 치유 부적, 결계 부적, 유인 부적(기운 생성, 하루 1회), 정화 부적(정화 성공률 보정).
- **도감**: 악귀와 수호령을 수집하는 포켓몬 도감 격 콘텐츠. 같은 악귀를 정화할 때마다 도감 숙련이 올라 약점 정보가 상세해진다.
- **유료화 원칙**: 외형(야경단 의복, 등롱 모양, 정화 연출), 도감 슬롯, 시즌 패스만 판다. 전투력에 영향 주는 판매는 하지 않는다. 걸은 거리와 결계 참가는 돈으로 대체할 수 없다.

## 12. 기술 설계 방향

### 12.1 플랫폼 현실

| 기능 | 안드로이드 크롬 | iOS 사파리 | 대응 |
| --- | --- | --- | --- |
| 카메라 배경 | `getUserMedia` | `getUserMedia` | 공통. 카메라 `<video>` 위에 캔버스 레이어 |
| 자이로·지자기 | `DeviceOrientation` | 권한 요청 후 `DeviceOrientation` | 공통. iOS는 사용자 제스처 뒤 권한 요청 |
| GPS | `Geolocation` | `Geolocation` | 공통 |
| WebXR 평면 인식·앵커 | 가능(`immersive-ar`) | **불가** | WebXR은 선택적 향상. 기본 설계는 WebXR 없이 동작 |
| 진동 | `navigator.vibrate` | 불가 | 소리·화면 효과로 대체 |
| PWA 설치 | 가능 | 가능 | 홈 화면 추가 안내 |

**결론**: 기본 AR은 "카메라 배경 + 자이로 방향 기반 투영"(AR-lite)로 만든다. 악귀는 플레이어를 원점으로 한 구면 좌표(방위·고도·거리)에 놓고, 폰의 방향 벡터와 비교해 화면에 투영한다. 바닥 인식·물체 뒤 가림(오클루전)은 하지 않는다. WebXR이 되는 기기에서는 바닥 높이 고정과 앵커 안정화만 추가한다.

### 12.2 렌더링

- 캔버스 2D 또는 WebGL 2D 스프라이트. 해루질럿의 캔버스 유틸(`app/mudflat-canvas-utils.ts`)과 세로 화면 터치 정책을 재사용한다.
- 악귀는 방향별 2D 스프라이트(8방향)에 거리에 따른 크기·투명도·흐림을 적용한다. 3D 모델은 1차 범위에서 제외한다.
- 60fps 목표, 중저가 안드로이드에서 30fps 보장. 카메라 해상도는 720p로 제한한다.
- 배터리: 조우 밖(순찰)에서는 카메라를 반드시 끈다. 순찰 화면은 지도 타일 + 저빈도 GPS 갱신(5초)만 쓴다.

### 12.3 서버

- Cloudflare Workers + D1(기존 구성)로 계정·도감·터·기운·일일 과제·순위를 처리한다.
- 분대 조우의 실시간 동기화는 Workers Durable Objects + WebSocket 1개(조우 방 1개 = DO 1개)로 한다. 서버가 악귀 체력·위치 시드·정화 판정의 최종 권위다. 클라이언트는 입력(조준 방향, 발사 시각)만 보낸다.
- 악귀 이동은 **결정적 시드 RNG**로 서버·클라이언트가 같은 수열을 계산한다(해루질럿의 결정적 런타임 RNG 규칙과 동일). 분대원끼리 같은 악귀를 같은 방위에 봐야 하므로, 방위 원점은 조우 방의 "분대 중심 좌표 + 진북"으로 고정한다.
- 명중 판정은 **서버 관대 판정**: 클라이언트가 보낸 조준 벡터와 서버 악귀 위치의 각도 차이가 허용 반경 안이면 명중. 왕복 지연 200ms까지 보정한다.
- 치트 억제: 발사 간격 하한, 1초당 회전 각속도 상한, GPS 순간 이동 감지. 정교한 치트 대응보다 "협동 PvE라서 치트 이득이 작다"는 설계로 버틴다.

### 12.4 저장 형태(초안)

| 저장소 | 내용 |
| --- | --- |
| 로컬 | 조작 설정, 접근성 모드, 마지막 역할, 튜토리얼 진행, 임시 조우 재접속 토큰 |
| D1 | 계정, 레벨, 장비, 부적 수량, 도감, 수호령, 일일 과제 진행, 터별 지박령 정화 기록 |
| Durable Object | 진행 중 조우 방 상태(악귀 체력·시드·참가자·시작 시각). 조우 종료 후 결과만 D1에 기록 |

## 13. 화면 구성 (세로)

```
┌──────────────────────┐
│ 레이더(상단 중앙)  필살 │  ← 화면 밖 악귀 방위, 분대 방향
│ 체력·보호막 바        │
│                      │
│    [카메라 영상]       │
│        ╋  ← 조준점    │
│   ◁          ▷       │  ← 화면 밖 악귀 안내 화살표
│                      │
│ 기술1  기술2    발사(큼) │  ← 왼손 / 오른손 엄지
│ 부적      탄약·정화 게이지│
└──────────────────────┘
```

- 결과 화면, 정비 화면, 도감 화면은 기존 Paperoid 게임의 가독성 규칙(`docs/game-ui-readability.md`)을 따른다.
- 조우 화면의 모든 글자는 야외 직사광 아래 가독성을 위해 외곽선 + 반투명 바탕을 쓴다.

## 14. 단계별 개발 계획

| 단계 | 목표 | 완료 기준 |
| --- | --- | --- |
| 0. 기술 검증 | 카메라 배경 + 자이로 조준 + 잡귀 1마리 | 안드로이드·iOS 실기기에서 몸을 돌려 조준·명중이 되고, 30초 드리프트가 5도 이하 |
| 1. 혼자 순찰 | 지도·기운·터, 역할 4종, 잡귀·원귀, 수호령, 집안 순찰, 속도 잠금 | 한 사람이 20분 산책에서 조우 5회 이상, 조우당 60~150초 |
| 2. 분대 조우 | DO 기반 2~4인 동기화, 분대원 아바타, 치유·표식 | 두 기기가 같은 악귀를 같은 방위에서 보고 체력 공유 |
| 3. 지박령·주간 | 터별 보스, 주간 리셋, 도감 숙련, 장비 제작 | 주 1회 복귀 동기가 지표로 확인 |
| 4. 결계 이벤트 | 좁아지는 결계, 다분대 재앙급, 기여도 순위 | 특정 공원에서 분대 3개 이상 동시 테스트 |
| 5. 공개 | Paperoid 메인·게임 목록·빠른 시작 등록, QA 매트릭스 완성 | 해루질럿과 같은 수준의 회귀 테스트 |

0단계를 통과하지 못하면(특히 iOS 자이로 드리프트) 기본 조작을 `고정 자세 모드`로 뒤집어야 하므로, 0단계 전에 다른 단계 코드를 쓰지 않는다.

## 15. 검증 지표

- 조우 진입 후 첫 악귀가 보일 때까지 3초 이내
- 조우당 평균 회전 각도 270도 이상(몸을 실제로 돌리는지)
- 조우 중단율(이동·이탈·오류) 10% 이하
- 30분 플레이 배터리 소모 15% 이하(카메라 켜진 시간 비율 40% 이하)
- 안전 신고 터 24시간 내 처리율 100%

## 16. 변경 원칙

- 조우 규칙, 악귀 등급·행동 유형, 안전 규칙, 저장 형태를 바꾸면 이 문서와 구현, 목표 안내 문구(`app/game-objectives.js`), 테스트를 같은 커밋에서 고친다.
- 밸런스 수치는 엔진에 한 번만 정의하고 이 문서에는 의미와 원본 위치만 쓴다.
- 용어는 2절 표를 따른다. 화면 문구와 코드 변수 의미가 다르면 코드를 고친다.

## 17. 미결 사항

- 게임명 `야경단`의 상표·도메인 확인
- 터 선정에 쓸 지도 데이터 출처(공개 지도 vs 상용 API)와 라이선스 비용
- 사운드 방향: 공포 연출을 어디까지 할지(어린이 접근성과 충돌)
- iOS에서 WebXR이 없어 생기는 체감 차이를 어느 수준까지 허용할지
- 오프라인·통신 불안정 지역에서 혼자 조우를 로컬 판정으로 허용할지(치트와 상충)
