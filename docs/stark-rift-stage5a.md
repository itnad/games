# 스타크 리프트 단계 5A: 기본 전투

2026-11-12. 단계 4와 터치·건설 보완을 유지하며 공격 → 피해 → 사망을 실제 production Worker에 연결한다. 단계 5 전체 완료를 의미하지 않는다.

## 이번 구현 범위

- 마린, 저글링, 질럿, SCV, 드론, 프로브의 기본 무기를 연결한다. 마린은 지상/공중, 나머지는 지상 공격만 한다. 질럿의 두 타격에 각각 방어력을 적용한다. 무기 피해·보너스·재사용 시간·사거리·대상 크기·충돌 경계는 BWAPI v4.4.0 / Brood War 1.16.1 자료를 추출한다. `combat-original.json`에 원본 URL과 SHA256을 기록한다.
- 공격 간격은 경제 시간 단축을 적용하지 않는다. 원본 24프레임/초를 20틱/초로 변환하며 나머지를 저장한다. 마린 15프레임은 13틱/12틱을 번갈아 적용한다. 이동/정지 명령으로 공격 재사용 시간을 초기화하지 않는다.
- 보호막을 먼저 소모하고 초과분에 체력 방어력과 크기 배율을 적용한다. 체력/보호막의 1/256 잔여 피해를 저장한다. 방어력 이후 최소 체력 피해는 0.5다. 현재 연결한 여섯 무기는 Normal 피해이며 Explosive/Concussive 배율 함수도 검증한다. 보호막 방어력 업그레이드는 아직 제공하지 않는다.
- 집중공격은 유효한 보이는 적을 무기 사거리까지 추적한다. 시야에서 사라지면 마지막 확인 위치로 이동하고 집중공격을 종료한다. 공격 이동은 자신의 원본 시야 거리 안에 있는 보이는 적을 추적하고 사거리 안에서 정지해 공격한다. 표적이 사라지면 저장한 원래 목적지로 이동을 계속한다. 이 목적지도 저장/복원하며 새 이동·채취·건설 명령으로 취소된다. 일반 병력은 대기/위치 사수 중 사거리 안의 가장 가까운 적에 반격한다. 일꾼은 명시적 집중공격만 수행하여 채취·건설을 자동 중단하지 않는다. 일반 이동과 순찰에는 이번 자동 교전을 적용하지 않는다.
- 같은 틱의 공격을 먼저 수집한 뒤 타격별 피해를 계산하여 상호 사망을 허용한다. 사망은 기존 경제 정리와 통합하여 인구·생산 예약·자원 잠금·건설 참조·부대 슬롯을 정리한다. 건설 체력은 진행 증가량만 더하며 피해를 지우지 않는다.
- 공격선/근접 타격/사망 효과와 선택/피해 체력바·보호막바를 표시한다. 효과는 최대 128개, 8틱으로 제한하고 현재 보이는 양 끝 좌표만 렌더 스냅샷으로 보낸다. 숨은 적 위치는 보내지 않는다.

## 직접 확인

기존 `/stark-rift-dev`에서 종족과 `전투 연습`을 선택한다. 테란 마린 4기, 저그 저글링 6기, 프로토스 질럿 2기와 적 3기가 준비된다. 부대 1번을 선택하고 붉은 적을 터치하거나 `공격 이동` 후 위치를 터치한다. 적 저글링은 제자리에서 반격하고 적 드론은 표적이다. 남은 적/아군 수와 연습 목표 완료를 표시한다. 이는 경기 전체 승패 판정이나 상대 AI가 아니다. 기본 모드 `기지 운영`도 유지한다.

## 저장 호환성

엔진 `0.8.0-stage5a`, 스키마/형식 7, Worker 프로토콜 8. 전투 규칙 해시는 별도 저장하고 로드 시 검사한다. 기존 단계 4 형식 6은 원본 체크섬과 엔진/스키마를 검증한 뒤 현재 스키마로 변환한다. 지도·경제 자료 버전도 기존대로 검사한다. 읽는 동안 기존 저장은 변경하지 않는다. 첫 교체 전 원문을 `.stage4-backup`에 보존하며 백업에 실패하면 원래 기록을 덮어쓰지 않는다. 단계 3 이전 형식은 지원하지 않는다.

운영 저장 키는 기존 `paperoid.stark-rift.development.v1.<race>`를 유지한다. 전투 연습은 `paperoid.stark-rift.development.v1.combat.<race>`에 따로 저장한다. 자동·수동 저장, 새로고침 복원, 세로 전용 정지 규칙을 유지한다. 이전 단계 4 실행 코드로의 저장 역호환은 제공하지 않는다.
