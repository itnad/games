# 3단계 브라우저 터치 보완 기록

## 세로 화면 전용 확정 및 후속 보완 — 2026-11-10

사용자 지시에 따라 가로 플레이를 지원하지 않는다. 세로 전용 게이트를 내부 세션과 검증 화면 양쪽에 적용했다. 가로 전환 시 즉시 일시정지하고 전체 게임 컨트롤을 inert 처리하며 세로 전환 안내를 표시한다. 진행 중 전장·슬롯 터치는 취소하고 가로에서는 이동·등록·미니맵 입력과 렌더링을 막는다. 세로 복귀 시 기존 세션을 재생성하지 않으며 카메라·선택·슬롯을 유지하고 명시적인 재개를 기다린다. 가로 전용 레이아웃과 가로 조작 검증은 완료 조건에서 제외한다.

- 전체 `npm test`(프로덕션 빌드·기존 게임/한국어 회귀·전용 **217개**·타입 검사)와 별도 내부 검증 화면 빌드 통과. 일시정지 중 그룹 선택 유지, 가로 명령 차단과 명령 시퀀스 보존 회귀를 추가했다.
- Chromium 154/SwiftShader, 390×844와 360×640에서 확장 터치 검사를 통과했다. 부대 등록 승인, 슬롯·카메라·선택 저장 복원, 연합 선택, 공격이동 1회 승인, 입력 취소, 키보드 슬롯, 회전 시 정지·입력 차단·상태 보존·수동 재개를 확인했다. JavaScript 오류·Worker 오류·명령 거절은 없었다. 실제 휴대폰 결과가 아니다.
- 이 통과 이후 추가한 가로 최초 접속·10분 반복 이동 검사 코드는 준비됐으나 실행 호출이 중단됐고 결과 파일이 생성되지 않았다. 실행 완료나 통과로 처리하지 않는다.
- 실제 Android/iOS의 터치·GPU·Worker 포함 메모리와 10분 관찰은 계속 미확인이다. 3단계 최종 완료로 선언하지 않는다.

## 이전 판정

핵심 구현과 서버 성능 보완은 구현되어 있으나 **3단계 최종 완료 심사는 보류**한다. 실제 Android Chrome·iOS Safari의 터치, GPU·전체 메모리, 10분 이상 이동 검증이 남아 있다. 공개 스타크 리프트 게임 라우트와 4단계 경제·생산 구현은 추가하지 않았다.

## 확인하고 보완한 결함

- 내부 검증 도구의 광범위한 버튼 스타일이 실제 게임의 최소 터치 높이 52px를 40px로 덮어썼다. 검증 도구 스타일을 도구 영역으로 한정했다.
- 부대 슬롯의 가로 스와이프를 Chromium이 기본 스크롤로 해석하여 연합 선택이 10기에서 끊겼다. 슬롯 영역에 `touch-action: none`을 지정했다. 수정 후 3개 슬롯의 30기 선택과 위쪽 공격 이동이 동작했다.
- 일시정지 상태에서 길게 누르면 부대 등록 명령이 거절되고 비어 있는 슬롯으로 선택이 연결되어 선택이 풀렸다. 일시정지 중에는 임시 그룹 선택을 유지하고 등록·이동 등의 실행 명령을 보내지 않는다. 실행 버튼도 비활성화한다.
- 렌더 틱이 바뀌지 않거나 렌더 버퍼가 가득 찬 상황에서도 일시정지·재개 즉시 최신 `uiState`를 발행한다. 동일 틱에서 정지→재개→정지하는 회귀 검사를 추가했다.

엔진의 이동 규칙, 저장 구조와 통신 메시지 형식은 변경하지 않았다.

## 실행한 검증

- 타입 검사와 Stark Rift 전용 테스트 **215개 통과**.
- Chromium 154, headless, SwiftShader 소프트웨어 WebGL, Playwright/CDP 합성 터치로 검사했다. 실제 휴대폰 결과가 아니다.
- 390×844와 360×640: 전장·미니맵, 52px 버튼, 개별 선택, 길게 눌러 10기 선택, 일시정지 중 명령 없음, 선택 저장·복원, 가로 슬롯 연합 선택, 위쪽 공격 이동, 초기화 후 Worker 1개, JavaScript 오류 없음.
- 844×390: 전장·미니맵, 52px 버튼, Worker 1개, JavaScript 오류 없음만 확인했다. 이는 가로 지원 확정 이전의 표시 기록이다. 현재 가로 플레이는 지원하지 않는다.
- 원본 결과와 스크린샷은 작업 산출물 `stark-rift-browser-qa.json`, `stark-rift-browser-390x844.png`, `stark-rift-browser-360x640.png`, `stark-rift-browser-844x390.png`로 보존했다.

## 후속 검사 실행

추가한 `tools/stark-rift-lab/browser-smoke.py`는 더 엄격한 부대 등록 승인, 카메라·슬롯 복원, 입력 취소, 키보드 슬롯 선택와 가로 플레이 차단·세로 복귀를 검사한다. 확장 선택·슬롯·회전 검사는 위 최신 기록대로 통과했다. 가로 최초 접속·10분 검사는 이후 추가되었으며 아직 실행 확인되지 않았다.

Python Playwright와 Chromium이 설치된 환경에서 내부 검증 서버를 먼저 실행한다.

```sh
npm run dev:stark-rift-lab
python tools/stark-rift-lab/browser-smoke.py
# 선택: 세로 화면에서 50기 이동을 10분 반복 관찰
python tools/stark-rift-lab/browser-smoke.py --soak-seconds 600
```

브라우저 경로는 `--chromium`, 접속 주소는 `--url`, 결과 폴더는 `--output`으로 지정한다. 결과는 기본적으로 Git 제외 폴더인 `work/stage3-browser`에 저장한다. 이 선택 실행 검사는 기본 Node 테스트에 브라우저 설치를 요구하지 않는다.
