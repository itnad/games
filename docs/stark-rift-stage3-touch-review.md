# 3단계 터치 보완 기록

최신 판정·수치·원격 반영 기준은 [최종 검토](stark-rift-stage3-final-review.md)를 따른다. 이 문서의 초기 미실행 상태를 현재 판정으로 해석하지 않는다.

## 보완한 결함

- 내부 검증 도구의 광범위한 스타일이 실제 게임의 52px 버튼을 40px로 덮어썼다. 도구 스타일을 도구 영역에 한정했다.
- 슬롯 스와이프를 브라우저가 기본 스크롤로 처리해 연합 선택이 끊겼다. 슬롯 영역에 touch-action: none을 지정했다.
- 일시정지 중 부대 등록 거절 뒤 빈 슬롯으로 선택이 연결돼 선택이 풀렸다. 임시 선택을 유지하고 실행 명령을 막는다. 정지/재개 UI 상태는 같은 틱에서도 즉시 발행한다.
- 가로 플레이 미지원으로 확정하고 가로 전환/최초 접속의 정지·입력 차단·안내와 세로 복귀 상태 보존·수동 재개를 연결했다.
- 반복 렌더링에서 방향 조회 객체와 도형을 재생성하는 비용을 줄였다. 개발용 React 성능 기록 버퍼를 정리하며 장시간 검사는 프로덕션 빌드로 수행한다.

## 자동 검증과 한계

전체 빌드·기존 게임/한국어 회귀·타입 검사·전용 221개 테스트를 통과했다. Chromium 154/SwiftShader의 390×844와 360×640 합성 터치, 가로 최초 접속 차단, 600초 반복 이동·단일 Worker·오류 없음, JSON 내보내기와 화면 캡처를 확인했다. 실제 휴대폰 결과가 아니다. 최대 틱/프레임 간격과 실제 기기 미확인 항목은 최종 검토에 남겼다.

## 실패 기록 보존

초기 개발 모드의 약 406초 탭 충돌과 화면 안정화/모달 대기로 멈춘 자동 검사 기록을 보존한다. 검증 도구는 합성 fixture의 교체 확인을 명시적으로 수락하고 기존 그룹 거절 동작은 Node 회귀로 별도 검사한다. 게임의 실제 확인창을 제거하지 않았다. 화면 안정화 대기는 명시적인 스크롤/좌표 확인으로 바꾸고 명령 발행·승인 검사는 유지한다.

## 재현

```sh
npm run build:stark-rift-lab
npm run preview:stark-rift-lab
python tools/stark-rift-lab/browser-smoke.py --soak-seconds 600
```

기본 주소 127.0.0.1:4175. Python Playwright와 Chromium이 필요하다. 원격 저장을 Sites 배포로 표시하지 않으며 각 완료는 대응 커밋/배포 응답으로 확인한다.
