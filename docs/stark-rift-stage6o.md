## 연구와 시전

퀸즈 네스트에서 미네랄100·가스100으로 연구한다. 원본1200프레임에 기존 경제 시간50% 정책을 적용해500틱(25초)이다. 퀸 한 기가 에너지150으로 보이는 지상 비건물·비로봇 유닛 하나에 시전한다. 유기체 또는 기계 속성이 필요하므로 SCV·탱크·드라군도 가능하며 프로브·리버는 제외된다. 아군도 즉시 처치한다. 보이는 잠복 대상은 허용하되 탑승·스테이시스·숨겨진 적은 거절한다. 양쪽 몸체 간9타일(288px) 포함 거리다. 실패 시 에너지나 이동 명령을 소모하지 않는다.

기존 주문과 같은 즉시 실행·사거리 밖 거절 정책이며 자동 접근·원작 발사체/선행 애니메이션은 재현하지 않는다. 패러사이트·인스네어와18틱 시전 대기를 공유한다. 다른 능력의 부분 성공 정책을 유지한다. 자동시전은 추가하지 않는다.

## 생성과 전투·수명

즉사 시 일반 엔티티 정리 경로로 대상의 작업·탑승·부대·상태 참조를 제거한다. 시전자 소유 브루들링을 최대2기 생성한다. 원본±2px 지점을 먼저 검사하고 반 타일 격자의 맨해튼4링 안에서 거리·y·x 순으로 지형과 원형 몸체 충돌을 피한다. 첫 생성 위치는 두 번째 생성에 예약된다. 이것은 현재 엔진의 명시적 배치 정책이며 원작의 겹쳐 생성/밀어내기와 다르다. 공간·2048개체 한도가 부족하면0~1기만 생겨도 처치와 비용은 유지한다. 생성에 자원·보급을 추가로 지불하지 않으며 일반 생산/반복 생산은 허용하지 않는다.

체력30, 보급0, 속도6px/원본프레임, 시야5타일. Toxic Spores는 일반 피해4(+근접 공격 업그레이드당1), 간격15원본프레임, 몸체 간2px 지상 근접 공격이다. 공중 공격은 없다. 기존 선택·부대·이동·집중 공격·치료·수송 규칙을 사용한다. 간단한 전용 벡터 외형을 제공한다.

소멸 타이머는1800원본프레임→1500틱(75초)이며 경제 시간 단축을 적용하지 않는다. 생성 틱에 절대 만료 틱을 저장한다. 시전자 사망·거리 이탈과 무관하고 탑승·스테이시스 중에도 진행하며 정확한 만료 틱에 참조를 정리한다. 남은 수명은 아군 선택 및 수송 승객 화면에 표시하고 적의 수명·퀸 대기는 패킷에 보내지 않는다. 시전 효과는 보이는 대상 지점만 전송하며 내부 참조를 포함하지 않는다.

## 화면과 저장

`/stark-rift-dev` → 저그 → 특수 연습 → 새 테스트 시작 → 퀸즈 네스트 선택 → 브루들링 생성 연구 →5번 부대의 퀸 선택 → 에너지150까지 회복 → 브루들링 생성 → 오른쪽(30,26) 질럿 터치. 생성 후 ‘브루들링 선택’으로 이동·공격을 지시한다. 기존 프로브는 로봇 대상 제외를 확인할 수 있다. 새로운 연습에 질럿 한 기를 추가하며 기존 저장에는 유닛·자원·에너지를 지급하지 않는다. 초기 퀸 에너지50을 유지한다.

엔진0.25.0-stage6o, 저장/스키마24, 프로토콜25. 형식6..23을 과거 체크섬·버전과 대조해 변환한다. 단계6N 경제·전투 해시는 고정하며 기존 패러사이트·시야·연구·생산·명령·에너지·RNG를 보존한다. 형식23 원문은 `.stage6n-backup`에 그대로 남긴다. 과거 형식의 새 브루들링/연구/상태/무기 효과 위장과 현재 중복·잘못된 참조·만료·상호 대기·지도 좌표는 거절한다.
