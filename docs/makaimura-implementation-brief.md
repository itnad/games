# 마계촌 고전 보드게임 구현 준비서

작성일: 2026-07-29

## 1. 조사 결론

현재 확인한 한국판 `마계촌`은 2~4인이 즐기는 고전 롤앤무브 게임이다. 한 장의 긴 보드에서 주사위를 굴려 1~6단계를 통과하고, 몬스터를 상대하며 단계에 맞는 무기를 확보한 뒤 공주를 먼저 구출하는 참가자가 승리한다.

단순히 도착 순서만 겨루는 사다리 게임과 달리 다음 요소가 결합되어 있다.

- 여섯 단계로 나뉜 진행 경로
- 일반 칸, 물음표 칸, 몬스터 칸, 강제 정지·분기 칸
- 창·검·십자가 등 무기 타일의 획득과 상실
- 몬스터 카드와 주사위 결과에 따른 전투
- 다음 단계로 넘어가기 위한 무기 또는 주사위 조건
- 길을 잃은 느낌을 만드는 비선형 이동 구간
- 마지막 보스 구간과 공주 구출

## 2. 근거와 신뢰도

### 확인된 내용

- 한국판 상자는 8세 이상, 2~4인용으로 표시되어 있다.
- 보드라이프 실물 후기에는 주사위 이동, 몬스터 처치, 공주 구출, 단계별 무기 보유가 핵심이라고 기록되어 있다.
- 실물 보드는 1~6단계로 구성되고, 각 단계에 번호 칸·물음표 칸·몬스터 그림·정지 또는 분기 지점이 있다.
- 별도 몬스터 카드 더미, 무기 타일, 기사 또는 생명 타일, 말, 주사위나 룰렛이 사용된다.
- 학술 자료는 일본판에 무기 강화, 서로 다른 단계, 보스전, 반복 구간이 존재하며 한국판이 Bandai판과 Hanayama판의 요소를 함께 차용했다고 설명한다.

### 높은 가능성으로 추정되는 진행

1. 차례가 되면 육면체 주사위를 굴린다.
2. 현재 단계 경로에서 나온 수만큼 이동한다.
3. 도착한 칸이 물음표 또는 몬스터 칸이면 해당 효과를 해결한다.
4. 몬스터 전투는 몬스터 카드에 적힌 주사위 범위와 필요한 무기로 판정한다.
5. 단계 끝의 정지 칸에서는 지정 무기나 특정 주사위 결과를 만족해야 다음 단계로 간다.
6. 최종 구간의 보스를 통과하고 공주를 먼저 구출하면 승리한다.

### 설명서 확인 전 확정하면 안 되는 값

- 시작할 때 받는 기사·생명·무기의 정확한 수
- 각 무기 종류의 전체 수량과 교환 규칙
- 물음표 칸마다 뽑는 카드 또는 즉시 효과
- 몬스터 카드별 성공·실패 범위와 보상·벌칙
- 단계별 통과에 필요한 정확한 무기 조합
- 같은 칸에 선 말 사이의 상호작용
- 갑옷을 잃고 기사 타일을 소모하는 정확한 순서
- 5·6단계 및 최종 룰렛의 상세 판정
- 참가자 탈락, 재시작, 무승부 처리

이 값들은 낮은 해상도의 실물 사진만으로 임의 확정하지 않는다.

## 3. 디지털 게임 규칙 구조

구현은 화면과 규칙을 분리한다.

### 핵심 상태

- `players`: 위치, 현재 단계, 기사·생명, 보유 무기, 쉬는 차례 여부
- `board`: 단계, 칸 번호, 칸 종류, 다음 칸 또는 분기
- `monsterDecks`: 단계별 카드 더미와 버린 카드
- `weaponPool`: 무기별 남은 수량
- `turn`: 현재 참가자와 행동 단계
- `log`: 이동·전투·획득·상실 기록
- `winner`: 공주를 구출한 참가자

### 차례 상태 흐름

`주사위 굴리기 → 이동 애니메이션 → 칸 효과 → 전투 또는 선택 → 단계 통과 판정 → 다음 참가자`

행동 중에는 버튼을 잠가 중복 입력을 막고, AI 행동도 같은 순서와 속도로 화면에 보여준다.

### AI 기본 방향

- 다음 관문에 필요한 무기를 우선 확보한다.
- 이미 필요한 무기가 있으면 진행 속도를 우선한다.
- 선택 가능한 분기에서는 실패 시 손실과 기대 이동량을 비교한다.
- 쉬운 AI는 진행 중심, 보통 AI는 무기와 위험을 함께 계산한다.
- AI도 주사위, 이동, 카드 공개, 무기 증감을 생략하지 않고 보여준다.

## 4. 화면 설계

### 시작 화면

- 참가자 수: 2~4인
- 사람 1명 + AI 1~3명
- AI 난이도: 쉬움 / 보통
- `게임 방법`, `튜토리얼 시작`, `게임 시작`
- 원본 규칙 확정 전에는 `복원 규칙 베타` 표시

### PC

- 가운데에 세로형 전체 보드
- 왼쪽에 참가자 순위·위치·생명
- 오른쪽에 보유 무기·현재 관문 조건·최근 기록
- 현재 단계와 현재 말에만 은은한 강조 표시

### 모바일

- 전체 보드를 작게 축소하지 않고 현재 단계만 크게 표시
- 상단 미니맵에서 1~6단계 진행률 확인
- 하단 고정 행동 영역에 주사위와 선택 버튼 배치
- 몬스터 카드는 하단 시트로 열어 글자를 충분히 크게 표시
- 다음 단계로 이동하면 세로 스크롤 대신 화면 전환 애니메이션 사용

### 튜토리얼

1. 주사위 이동
2. 물음표 칸
3. 몬스터 카드 전투
4. 무기 획득·상실
5. 단계 관문
6. 최종 보스와 승리 조건

## 5. 디자인 복원 가능성

### 기술적 판단

보드 구조, 색 구획, 긴 세로 진행감, 픽셀풍 몬스터 카드, 무기 타일, 룰렛을 웹에서 재현하는 것은 가능하다. 다만 현재 확보한 사진은 원근 왜곡과 반사가 있고 글자가 작아 원본을 정확히 복원할 자료로는 부족하다.

정확한 복원에는 다음 자료가 필요하다.

- 펼친 전체 보드 정면 사진 또는 300~600dpi 스캔
- 설명서 전 페이지
- 모든 몬스터 카드 앞면과 공통 뒷면
- 무기·기사·기타 타일을 종류별로 한 장씩 촬영한 사진
- 룰렛과 주사위의 면 정보
- 상자 앞·뒤면은 선택 사항

사진은 그림자 없이 정면에서 촬영하고, 카드나 타일 옆에 자를 두어 실제 비율을 확인할 수 있게 한다.

### 권리 판단

원본 이름, 캐릭터, 로고, 픽셀 이미지, 카드 문구, 보드 그림을 그대로 공개 사이트에 올리는 것은 권리 문제가 생길 수 있다. 오래된 게임이거나 한국판의 정식 라이선스 관계가 불분명하다는 사실만으로 자유 이용이 가능해지는 것은 아니다. 원작 `Ghosts 'n Goblins / 마계촌`의 캐릭터와 시각 자산은 Capcom 계열 권리와 연결된다.

따라서 공개되는 Playroom 기본판은 다음 방식이 안전하다.

- 규칙 구조와 세로 6단계 모험 느낌은 유지
- 게임명·인물·몬스터·무기 그림은 독자적인 것으로 교체
- 원본 카드 문구는 그대로 복사하지 않고 기능만 새 문장으로 작성
- 원본 스캔을 사이트 자산으로 포함하지 않음
- 추후 정식 사용 권한이 확인되면 테마 자산만 교체할 수 있게 엔진과 그림을 분리

개인 취미 목적이라도 인터넷에 게시하면 제3자가 접속할 수 있으므로, 정확한 원본 디자인 복제본을 기본 공개 버전으로 만드는 것은 권장하지 않는다.

## 6. 구현 파일 계획

- `app/makaimura-engine.js`: 보드, 이동, 카드, 전투, AI, 승리 판정
- `app/makaimura-game.tsx`: 시작 설정과 실제 게임 화면
- `app/makaimura.css`: PC·모바일 반응형 디자인
- `app/page.tsx`: 게임 목록과 진입 연결
- `app/game-objectives.js`: 게임 목표·승리 조건
- `tests/rendered-html.test.mjs`: 규칙 엔진과 화면 연결 테스트

게임 데이터는 엔진 파일과 분리 가능한 구조로 만들어 설명서 확인 후 숫자만 교정할 수 있게 한다.

## 7. 구현 단계

1. 사용자 자료로 한국판 설명서와 구성물 전체를 확보한다.
2. 각 칸·카드·관문 조건을 표로 전사하고 모순을 검토한다.
3. 원본 규칙 엔진과 자동 테스트를 먼저 작성한다.
4. 독자적인 레트로 호러 테마로 PC·모바일 UI를 구현한다.
5. 2인부터 4인까지 AI 진행을 반복 검증한다.
6. 게임 방법과 단계별 튜토리얼을 추가한다.
7. 원본 자료와 구현 규칙을 다시 대조한 뒤 게시한다.
