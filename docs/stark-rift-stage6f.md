# 단계 6F · 아비터 은폐장

2026-11-14. 엔진 `0.16.0-stage6f`, 저장·스키마 15, 통신 16. 세로 화면 전용.

- 스타게이트: 150/150, 21.9초, 사이버네틱스 코어 필요. 아비터 트리뷰널: 200/150, 18.75초, 스타게이트와 템플러 아카이브 필요. 프로브로 동력 범위에 건설한다.
- 스타게이트에서 아비터 생산: 100/350, 인구 4, 50초. 완성된 아비터 트리뷰널 필요. 일반 운영에서는 건설·생산·예약·취소·전력 규칙과 비용을 모두 적용한다.
- 아비터 체력 200, 보호막 150, 방어력 1. 공중 이동하며 지상·공중에 Phase Disruptor Cannon(폭발형 10, 45 원작 프레임 간격, 사거리 5타일)을 발사한다. 기존 무기처럼 1/256 HP 피해·장갑·크기·보호막·고지대·가시성 규칙을 따른다. 공중 공격이므로 지상 고저차 빗나감은 적용되지 않는다.
- 은폐장은 자동 적용하며 연구·에너지 소모가 없다. 범위는 원작 공중 무기의 160픽셀(5타일)을 사용하고, 이 엔진의 기존 거리 규칙과 같이 충돌 상자 사이의 유클리드 거리로 판정한다. 원작의 정수 근사 거리·프레임별 재적용 지연은 재현하지 않는다.
- 같은 소유자의 완성된 지상·공중 유닛과 일꾼을 은폐한다. 자신·다른 아비터·건물·수송 중인 유닛은 제외한다. 다른 소유자의 유닛에는 적용하지 않는다. 현재 게임은 두 적대 플레이어 구성이며 동맹 팀 공유는 없다.
- 은폐된 아군은 이동·공격·채취·수송할 수 있다. 적은 현재 시야와 탐지기가 모두 있어야 관측·지정 공격할 수 있다. 이미 발사한 탄은 기존 비행 규칙을 따른다.
- 은폐는 살아 있는 아비터와 대상의 현재 위치에서 매번 계산한다. 이동·사망·겹치는 은폐장·탑승·하차 시 저장된 효과가 남지 않는다. 다크 템플러/옵저버의 영구 은폐와 고스트/레이스의 개인 은폐 상태를 덮어쓰지 않는다.
- 선택한 아비터의 범위를 보라색 선으로 표시하고 적용 중인 아군 수를 보여 준다. 범위선은 아비터 충돌 상자에서 5타일 확장한 영역이며 대상의 충돌 상자와 겹치면 적용한다. 적용된 유닛에는 별도 테두리와 은폐 표시를 쓴다. 적에게는 탐지·시야 검사를 통과한 유닛만 전달하고 은폐장 소스 ID는 전달하지 않는다.
- Phase Disruptor Cannon 탄은 저장되는 추적 비행체로 처리하며 공격자 사망 후에도 비행한다. 연출 속도 240픽셀/초, 최대 수명 10초는 이 게임의 규칙이다. 기존 발사체 상한·수송 중 표적 회피·비행 위치의 시야 필터를 적용한다.
- 저장 6~14를 원본 체크섬·원본 데이터/전투/시야 태그 검사 후 변환한다. 이전 경제·무기 해시는 그대로 유지한다. 단계 6E 원본은 `.stage6e-backup`에 보존한다. 러커 변태/파동, 시즈 전환, 클로킹 에너지, 화물, 부대, 자원, RNG를 보존한다. 새 은폐장은 위치에서 재계산하므로 별도 소스-대상 목록을 저장하지 않는다.

## 확인 방법

`/stark-rift-dev` → 프로토스 → 특수 연습 → 새 테스트 시작. 아비터(3번 부대), 질럿·다크 템플러·셔틀·옵저버를 제공한다. `아비터 선택` 후 전장의 다른 위치를 터치해 이동시키면 질럿과 셔틀의 은폐가 해제되고, 돌아오면 다시 적용된다. `호위 질럿 선택`으로 은폐 중 조작과 수송을 확인할 수 있다. 새 연습에서는 아비터와 병력이 보이도록 카메라를 배치한다. 기존 저장 경기는 보유 유닛·시점을 유지한다.

## 데이터와 범위

`data/arbiter-original.json`은 BWAPI v4.4.0의 유닛·무기와 고정 OpenBW 커밋의 `secondary_order_CloakNearbyUnits` 동작을 참조한다. 원본 URL과 SHA256을 포함한다. `python tools/stark-rift-data/extract-arbiter.py <원본 폴더>`로 재생성한다. 경제 정의는 총 52개다. 리콜·스테이시스 필드·추가 연구와 전략 AI는 후속 범위이며 이 단계는 생산·일반 무기·자동 은폐장을 연결한다.

엔진 테스트는 생산 선행 조건·비용·인구·취소, 거리 경계, 이동·사망·다중 은폐장, 수송, 적 시야/탐지와 명령, 영구/개인 은폐 독립성, 탄 비행, 저장 결정성 및 이전 버전 보존을 검증한다. `tools/stark-rift-lab/arbiter-smoke.py`는 배포용 Worker/Pixi를 휴대폰 크기 Chromium에서 실제 터치해 이동·은폐 변화·저장 복구·수송을 확인한다. 물리 Android/iOS 또는 실제 GPU 인증과는 별개다.
