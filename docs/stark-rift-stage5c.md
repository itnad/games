# 단계 5C: 시야·정찰 기억·고지대·본부 승패

2026-11-12. 단계 5B를 이어 현재 시야, 정찰 기억, 탐지 판정과 본부 파괴 승패를 production Worker에 연결한다. 모든 유닛·기술·수송·자동 시전·상대 AI와 최종 아트가 완성됐다는 의미는 아니다.

## 시야와 정찰 정보

- 플레이어별 탐색 셀과 관측 기록을 저장한다. 미탐색은 검정(0), 탐색했지만 현재 시야 밖은 어두운 안개(1), 현재 시야는 2다. 아군 이동과 사망 뒤 현재 시야를 다시 계산한다. 지형·자원 위치는 탐색 후 남고 자원 잔량도 마지막 관측 값으로 유지한다. 숨은 실제 자원 잔량을 보내지 않는다.
- 적 유닛은 마지막으로 실제 관측한 좌표에만 기억 표식으로 남으며 600틱(30초) 동안 희미해진 뒤 사라진다. 적 건물은 마지막 종류·위치·건설 진행 모습을 유지한다. 옛 위치를 다시 관측해 부재를 확인하면 지운다. 시야 밖 이동·사망으로 기억을 갱신하거나 삭제하지 않는다.
- 기억 표식은 `entities`와 분리된 `scouting.contacts`로 전송하고 메인 화면·미니맵에 회색으로 표시한다. 선택·집중공격 대상에는 포함하지 않는다. 해당 위치로 지점 이동하는 것은 허용한다. 건물은 일부 발판만 보여도 관측할 수 있으며 렌더와 명령 판정에 동일한 몸체 시야 검사를 쓴다.
- 높은 지형은 낮은 지상 시야를 가린다. 첫 고지대 가장자리 셀은 보이고 그 뒤의 높은 셀은 가려진다. 공중 시야는 높이 차이를 무시한다. 정적 지형 시야 캐시는 지도별 최대 512개로 제한하며 저장된 게임 상태나 난수를 변경하지 않는다.

## 탐지와 고지대 공격

- 은폐/버로우 상태 등록과 현재 시야·탐지 동시 판정을 연결한다. 현재 구현된 오버로드는 11타일 탐지 반경을 사용한다. 탐지기가 죽거나 범위를 벗어나면 현재 적 표시와 명령 유효성이 갱신된다. 숨은 적의 실시간 좌표·ID를 렌더나 미니맵의 살아 있는 개체 목록에 보내지 않는다.
- 이 단계는 탐지 판정 기반이다. 현재 공개된 기본 유닛에 임의의 은폐 능력을 부여하지 않는다. 은폐 유닛 콘텐츠, 버로우 연구/조작, 다른 탐지기와 은폐 공격 위치 경고는 콘텐츠·특수 전투 작업에서 이어 연결한다. 테스트에서는 상태 등록으로 탐지의 작동과 정보 차단을 검증한다.
- 저지대 지상 원거리 공격이 고지대 지상 표적을 공격할 때, 고지대 또는 공중 아군의 시야 지원이 없으면 50% 빗나감 판정을 한다. 근접 공격과 공중 표적에는 적용하지 않는다. 기술/범위 효과는 아직 연결한 무기 대상에 포함되지 않는다.
- 판정은 저장되는 combat 난수 스트림에서 실제 발사 시 한 번 뽑는다. 비행 탄에는 결과를 보존하여 도중에 탐지·시야가 달라져도 다시 뽑지 않는다. 빗나간 탄도 비행과 회색 명중 실패 표시를 보이지만 피해를 주지 않는다. 기존 저장에서 이미 발사된 5B 탄에는 빗나감을 소급하지 않는다.
- 집중공격 표적의 최신 관측 좌표를 별도 저장하고 시야를 잃으면 그 위치로 전환한다. 경로 탐색을 계획했던 좌표와 구분하여 숨은 적의 실제 이동을 추적하지 않는다.

## 승패와 화면

- 살아 있고 건설을 시작한 모든 본부 건물을 센다. 건설이 멈춘 본부도 포함하며 아직 시작하지 않은 대기 청사진은 포함하지 않는다. 일반 건물과 일꾼이 남아 있어도 본부가 없으면 패배한다.
- 피해와 사망 정리를 모두 적용한 같은 틱에 양쪽 마지막 본부가 없어지면 무승부다. 마지막 본부 위치를 자동 공개하지 않는다. 종료 시 대기 명령을 비우고 틱·전투를 멈춘다.
- 일시정지 화면에서 항복을 확인하면 기존 결정적 명령 경로로 경기를 종료한다. 결과창에 승리/패배/무승부, 종료 이유와 게임 진행 시간을 표시한다. 결과 저장·선택 화면 복귀·결과 다시 보기와 가로 화면 차단을 제공한다. 종료된 경기를 다시 실행하지 않는다.

## 본부 공략 연습

기존 `/stark-rift-dev`에 `본부 공략` 모드를 추가한다. 기존 기지 운영·기본 전투·원거리 연습을 유지한다. 세 종족의 기본 병력이 `정찰 출발` 버튼으로 경사로 아래의 중립 경유지까지 공격 이동한다. 화면도 경유지로 이동하지만 숨은 적 본부 좌표를 미리 공개하지 않는다.

상대는 건설이 멈춘 테란 커맨드 센터(정상 체력/건설 진행 비례 상태)를 앞마당의 건설 가능한 위치에 갖는다. 본부 파괴 전까지 살아 있는 본부로 인정하고, 파괴하면 실제 경기 승리 시스템으로 종료한다. 상대의 남은 일꾼이 승리를 막지 않는다. 이는 전략 AI 대전이 아닌 짧은 정찰·승패 확인용 연습이다. 저장 키는 `paperoid.stark-rift.development.v1.siege.<race>`로 분리한다.

## 저장과 검증

엔진 `0.10.0-stage5c`, 스키마/형식 9, Worker 프로토콜 10. 형식 6(단계 4), 7(5A), 8(5B)은 원본 체크섬·엔진·전투 규칙을 확인하고 변환한다. 비행 중인 탄, 체력 잔여값, 공격 대기시간, 난수와 자원·생산·건설을 유지한다. 이전 버전은 탐색 이력을 저장하지 않았으므로 과거 이력을 만들어내지 않고 복원 시 실제 현재 시야부터 탐색 기록을 시작한다. 원문은 읽을 때 변경하지 않으며 첫 교체 전 `.stage4-backup`, `.stage5a-backup`, `.stage5b-backup`에 보존한다. 백업 실패 시 덮어쓰지 않는다.

검증은 전체 회귀와 `vision.test.ts`의 안개/기억/자원/탐지/높이/난수/본부/무승부/항복/끝난 저장·이전 비행 변환을 포함한다. 모든 모드×종족의 production Runtime 초기 스냅샷 검사로 통신 허용 목록의 누락도 확인한다. `vision-smoke.py`는 실제 터치로 세 종족×두 세로 화면의 정찰·본부 승리·결과 저장/복원과 가로 차단을 확인하고, 별도 관측 후 후퇴로 고정 기억 표식·공격 불가와 일시정지 항복을 검사한다. 실기기·실제 GPU와 별도의 10분 연속 실행 인증을 대신하지 않는다.

남은 작업은 은폐/기술·수송 등 콘텐츠 연동, 특수 전투/재생/순찰 세부 규칙, 세 종족 전체 콘텐츠, 전략 AI, 최종 아트와 실기기 검증이다. 단계 5 전체의 최종 완료 선언은 이 남은 경계와 별도로 판단한다.
