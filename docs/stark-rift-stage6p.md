# 단계6P · 커맨드 센터 감염과 감염된 테란

2026-11-18. BWAPI4.4.0/OpenBW4b046d5f65302b10cb0a745f0fecd37ec85b20a8의 고정 유닛·기술·소유권 전환·자폭 규칙을 `extract-infestation.py`로 추출한다. 원본 SHA256과 재생성 데이터는 `infestation-original.json`에 기록한다.

## 감염과 소유권 전환

퀸의 기본 기술이며 연구·에너지를 요구하지 않는다. 현재 보이는 완성된 적 지상 커맨드 센터만 대상으로 하며, 표시 체력의 정수 백분율이50 미만이어야 한다. 체력750/1500은 거절하고749/1500은 허용한다. 양쪽 몸체 사이32px(1타일) 이내에서 한 기의 퀸으로 지정한다. 실패 시 이동이나 자원을 소모하지 않는다. 다른 건물·미완성·아군·시야 밖·지원하지 않는 시전자는 거절한다.

현재 주문의 즉시 적용·사거리 밖 거절 정책을 따른다. 원작의 자동 접근, 3프레임 건물 전환 지연과60프레임 퀸 숨김은 재현하지 않으며 퀸을 소비하지 않는다. 감염은 에너지/마법 대기를 사용하지 않고 패러사이트·인스네어·브루들링 생성의 기존 공유 대기를 바꾸지 않는다. 이 차이를 자동 접근/애니메이션 작업과 구분한다.

건물 ID·위치·기본 발자국을 유지하며 소유자를 퀸의 플레이어로 바꾸고 감염된 커맨드 센터로 교체한다. 체력을1500으로 복구하고 기존 생산·반복·집결·연구 예약, 부착 연결·원래 소유자의 부대 참조·작업자 반납 본부 참조를 정리한다. 현재 유료 예약 정책은 남은 생산/연구 비용을 원래 지불자에게 전액 돌려주며 감염한 플레이어에게 자원을 주지 않는다. 이 환급 정책은 OpenBW의 소유자 변경 후 대기열 취소 순서를 그대로 복제하지 않은 의도적 차이다. 보급과 경로 장애물 버전을 다시 계산한다. 이전 소유자의 이후 명령은 소유권 검사로 거절한다. 화면의 남은 적 수에도 전환을 반영한다.

감염된 센터는 저그 건물이지만 본부·자원 반납소·보급 제공·건설 메뉴 대상이 아니다. 크립 없이 생산할 수 있다. 띄우기/착륙·크립 확산은 현재 지원하지 않는다. 상대의 마지막 본부를 감염시키면 기존 본부 소멸 승리 규칙을 따른다. 일반적인 모든 건물 파괴 승리 조건으로 바꾸지 않는다.

## 감염된 테란과 자폭

감염된 센터에서100미네랄·50가스·보급2하프(1명)·250틱(12.5초)으로 생산하며 라바를 사용하지 않는다. 원본600프레임 생산 시간에 기존 경제 시간50% 정책을 적용한다. 체력60, 속도5.82px/원본프레임, 시야5타일, 수송 공간1칸, 연구한 버로우를 지원한다. 기존 선택·이동·부대·공격·수송·치료 규칙을 사용한다.

Suicide Infested Terran은 기본 피해500·폭발형·추가 업그레이드 피해0이며 지상 근접 사거리3px에서 자동으로 한 번 폭발하고 시전 유닛을 제거한다. 수동 자폭 버튼은 선택한 유효 유닛들의 현재 위치에서 폭발한다. 혼합 선택은 유효 유닛만 처리하는 부분 성공 정책이다. 같은 틱에 수동 자폭을 예약한 유닛은 추가 명령을 받지 않으며 요청은 전투 단계에서 소모되어 저장에 남지 않는다.

자폭 중심과 대상 몸체의 가장 가까운 점 사이 거리를 사용한다.20px 이하는500,40px 이하는250,60px 이하는125의 원시 피해이며 기존 보호막·방어력·폭발형 크기 배율을 적용한다. 지상 아군과 건물도 포함한다. 공중·탑승·스테이시스·미착공 건물은 제외한다. 잠복 대상은20px 안에서만 맞으며 잠복한 시전자는 자폭할 수 없다. 단순히 죽는 유닛은 폭발 피해를 내지 않는다. 모든 자폭과 일반 공격을 모은 후 피해를 적용해 서로 죽이는 자폭도 둘 다 성립한다. 원작 폭발 선행 애니메이션 대신 해당 틱 즉시 폭발을 사용한다.

감염된 건물의 외피/유기체 장식·감염된 테란 외형·감염 고리·자폭 범위 효과를 제공한다. 효과의 내부 엔티티 참조와 상대의 생산·자원 정보는 보내지 않는다. 이미 없는 적 공격원의 종류를 가리는 기존 렌더 개인정보 정책을 유지한다.

## 연습과 저장

`/stark-rift-dev` → 감염 연습 → 새 테스트 시작. 저그 전용이며 상대는 테란이다. 퀸1기(1번 부대), 체력600의 추가 적 커맨드 센터, 추가 미네랄500/가스200을 제공한다. 원래 적 본부는 별도로 남아 생산과 전투를 계속할 수 있다. 퀸을 건물 가까운 빈 지점으로 이동 → 커맨드 센터 감염 → 건물 터치 → 감염된 센터 선택 → 감염된 테란 생산. 생산 후 적 SCV에 집중 공격하거나 원하는 지점에서 수동 자폭한다. 새 연습은 `infestation.zerg` 키를 사용해 특수 연습·일반 저장과 분리된다. 기존 저장에는 자원·유닛을 추가하지 않는다.

엔진0.26.0-stage6p, 저장/스키마25, 프로토콜26. 형식6..24의 과거 데이터·전투·시야 해시와 원본 체크섬을 확인해 변환한다. 단계6O 경제/전투 해시와 기존 브루들링 수명·패러사이트·퀸 상태·생산/연구·명령·부대·에너지·RNG를 유지한다. 형식24 원문은 `.stage6o-backup`에 그대로 보관한다. 과거 형식의 감염 유닛·상태·자폭 무기·새 연습 시나리오 위장을 거절한다. 현재 저장의 중복/잘못된 효과·시간·지도 범위·소모되지 않은 단발 자폭 요청을 거절한다.
