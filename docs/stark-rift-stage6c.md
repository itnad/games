# 단계 6C — 고스트·레이스 능동 클로킹

2026-11-12. 엔진 `0.13.0-stage6c`, 저장·스키마 12, 통신 13. 단계 6B의 영구 은폐·탐지·수송에 수동 클로킹과 에너지를 연결한다. 세로 플레이만 지원한다.

## 확인 방법

`/stark-rift-dev` → **특수 연습 → 테란 → 새 테스트 시작**. **고스트 선택** 또는 **레이스 선택 → 클로킹 · 에너지 25**. 전장 위치를 터치하면 은폐를 유지하며 이동한다. 공격도 은폐를 해제하지 않는다. **은폐 해제**는 수동 해제이며 에너지 소진 시에는 자동 해제된다. 부대 3번은 고스트, 4번은 레이스다. 기존 수송용 부대 1·2번은 유지한다. 연습은 병력·보급·연구를 제공하며 일반 기지 운영은 실제 선행 조건과 비용을 적용한다.

## 생산과 연구

| 내용 | 선행·생산 | 비용(미네랄/가스) | 반감된 경제 시간 |
| --- | --- | --- | --- |
| 아카데미 | 배럭 → SCV 건설 | 150/0 | 25초 |
| 사이언스 퍼실리티 | 스타포트 → SCV 건설 | 100/150 | 18.75초 |
| 코버트 옵스 | 사이언스 퍼실리티의 부속 건물 | 50/50 | 12.5초 |
| 고스트 | 아카데미 + 연결된 코버트 옵스 → 배럭 | 25/75, 인구 1 | 15.65초(313틱) |
| 레이스 | 스타포트 | 150/100, 인구 2 | 18.75초 |
| 개인 은폐 | 코버트 옵스 연구 | 100/100 | 25초 |
| 클로킹 필드 | 컨트롤 타워 연구 | 150/150 | 31.25초 |

부모 건물이 파괴돼 분리된 애드온은 연구를 시작하거나 진행하지 못하며 선행 조건으로도 쓰이지 않는다. 진행 중 연구는 보존·정지하고 수동 취소 시 기존 전액 환불 규칙을 적용한다. 이 보완은 머신샵·컨트롤 타워·코버트 옵스에 동일하게 적용한다. 건물 이륙·재부착은 아직 제공하지 않는다.

## 에너지와 전투

- BWAPI v4.4.0에서 5개 유닛/건물, 3개 무기, 2개 연구를 별도로 추출해 총 46개 경제 정의를 제공한다. 기존 원작 JSON과 버전 해시를 보존한다. 출처·SHA256은 `data/cloak-original.json`, 재생성기는 `tools/stark-rift-data/extract-cloak.py`다. 에너지 프레임 동작은 해당 JSON에 고정된 OpenBW 커밋의 `bwgame.h`를 참조한다.
- 생성 에너지 50, 최대 200. 시작 비용은 25이며 은폐 중에는 재생하지 않는다. 원작 한 프레임당 고스트 `10/256`, 레이스 `13/256` 소모, 비은폐 시 `8/256` 재생한다. 초당 24 원작 프레임을 20 시뮬레이션 틱에 잔여 프레임과 함께 적분한다. 경제 시간 반감은 에너지에 적용하지 않는다.
- 이동·공격·정지·태세·대열·부대를 유지한 채 은폐 상태만 바꾼다. 여러 유닛 지시는 연구와 에너지를 충족한 유닛에만 적용한다. 중복 활성화는 추가 결제하지 않는다. 소진 시 적 표적 탐색 전에 은폐를 해제한다.
- 아군과 현재 탐지된 적에게 반투명 실루엣과 에너지 정보를 보낸다. 탐지되지 않은 적의 엔티티·에너지·정체는 렌더 패킷에서 제외한다. 탐지에는 현재 시야와 살아 있는 탐지기가 모두 필요하다. 영구 은폐 유닛은 에너지를 쓰지 않는다.
- 고스트 C-10은 진동형 10, 지상/공중 사거리 224픽셀, 22 원작 프레임 주기다. 레이스는 지상 Burst Lasers 일반형 8/30프레임, 공중 Gemini Missiles 폭발형 20/22프레임, 사거리 160픽셀이다. 크기별 피해·방어력·고지대 규칙을 적용한다. 고스트는 연결된 기존 보병 무기 1단계 강화도 적용한다. 레이스 무기는 이번 범위에서 즉시 명중하는 원거리 공격이며 별도 비행 미사일·함선 무기 연구는 제공하지 않는다.
- 수송 중에도 고스트 에너지·은폐·잔여 프레임을 유지하고 계속 소모/재생한다. 탑승 상태에서 수동 시전은 차단한다. 수송선 파괴 시 에너지 참조도 삭제한다. 아군 초상화에는 수송 중 에너지를 표시한다.

## 저장·검증·후속 범위

에너지 정수(1/256)·잔여 프레임·은폐·미래 명령을 함께 저장한다. 형식 6~11의 엔진·데이터·체크섬을 검증해 12로 이관한다. 단계 6B 수송·변태·시야·자원·그룹·투사체·RNG를 보존하며, 원문은 덮어쓰기 전에 `.stage6b-backup`에 보관한다. 백업 실패 시 원문을 교체하지 않는다.

엔진 회귀에서 에너지 정확도, 시전 조건, 소진 시점, 이동·공격, 탐지, 수송, 연구 비용·환불·완료·분리, 이전 저장 및 실행 결정성을 검증한다. 실제 운영 빌드의 두 세로 화면 크기에서 터치, 실제 경과 시간 소모/재생, 소진, 저장/재접속을 검증한다. 배포 SHA·CI·증빙은 별도 검증 영수증에 기록한다. Chromium/SwiftShader 자동 검증을 실제 Android/iOS·물리 GPU 검수로 표시하지 않는다.

에너지 최대치 250 연구, 락다운·핵·스팀팩·추가 주문, 아비터 은폐장, 러커·시즈 모드, 적 전략 AI, 최종 미술·애니메이션은 후속 범위다.
