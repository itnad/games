# 스타크 리프트 단계 4 구현 현황

2026-11-11. 단계 3 기준 `8871a9afd1be3040fac3a233971452de39ae1d4b`에서 시작했다. 엔진 `0.7.0-stage4`, 저장 스키마/형식 6, Worker 프로토콜 7이다. 이전 단계 저장은 버전 경계에서 명확히 거부하며 자동 변환하지 않는다.

## 구현 범위

- 실제 시작 상태: 본부 1, 일꾼 4, 미네랄 50. 테란 인구 4/10, 저그·프로토스 4/9. 저그 초기 오버로드와 라바 3 포함.
- 미네랄/가스 채취·운반·반납, 노드별 작업 잠금, 미네랄 소진과 고갈 가스, 아군 기지 구역/시야에 제한된 자동 채취. 명시적 이동·정지는 자동 행동을 중단한다.
- 사각형 건물 충돌/배치, 녹색·빨간색·노란색 미리보기와 확정, SCV 지속 건설/재개, 드론 변태/취소, 프로브 독립 워프, 크립·파일런 동력·팩토리 애드온.
- 유닛 5개 대기열, 즉시 비용/인구 예약, 여러 선택 건물 중 짧은 대기열 선택, 취소 환불, 조건부 반복, 연구 중복 방지, 집결지. 일꾼 집결은 이동, 병력 집결은 공격 이동 명령이다. 출구가 막히면 비용과 인구 예약을 유지하며 기다린다.
- 연속 건설은 일꾼당 최대 16개 후속 배치를 순서대로 처리한다. 대기 중인 하나를 취소해도 현재 작업을 유지한다. 저그는 선택 작업반의 아직 건설하지 않는 드론을 다음 배치에 사용한다.
- 세 종족 본부·건물·일꾼·병력과 자원 벡터 표시, 보유 자원/인구 HUD, 작업/건설/생산/연구 패널. 본부 생산, 일꾼 건설, 자원 터치 채취, 미완성 테란 건물 터치 재개, 전장/미니맵 집결지 지정을 연결했다.
- 저장/복원에 자원 잔량·운반 화물·노드 잠금·건설 연결·연속 예약·생산 비용/인구·라바·연구·크립·RNG를 포함한다. 소유자/개체 참조/비용/타이머/인구 보존과 지도 경계를 검증한다. 렌더 메시지에는 아군의 비공개 경제 정보만 보낸다.

## 검증

`npm test`에서 전체 빌드, 기존 Paperoid 렌더 HTML/한국어 조사 감사, 해루질 회귀, 스타크 리프트 타입 검사와 테스트 258개가 통과했다. 새 경제 테스트 30개에는 세 종족 실제 이동 채취, 확장 본부와 기본 병력, 비용/인구 중복 사용 방지, 종족 건설/연속 건설/취소, 애드온 연결, 동력, 연구, 반복, 자원 보존과 저장 결정성이 포함된다. 수천 틱을 진행하는 정확성 테스트는 공유 CI CPU의 경합을 고려해 20초 한도를 사용한다. 성능 기준은 별도 벤치마크로 측정한다.

재현 명령:

```sh
npm test
npm run build:stark-rift-lab
npm run bench:stark-rift
npm run preview:stark-rift-lab
# 다른 셸에서 Chromium/Playwright가 설치된 경우
python tools/stark-rift-lab/economy-smoke.py --url http://127.0.0.1:4175
python tools/stark-rift-lab/browser-smoke.py
```

`economy-smoke.py`는 자원 주입/시간 가속 없이 시작 자원 50에서 추가 일꾼→채취→서플라이 디포→배럭→마린→집결지→저장 복원을 확인하고 세 종족 시작 화면을 남긴다. `browser-smoke.py`는 390×844·360×640 터치, 최소 52px 버튼, 슬롯 합치기/공격 이동, 저장 복원, 화면 회전 시 정지/입력 차단을 확인한다. 최종 실행 결과·스크린샷·원격 커밋/트리·Sites 버전은 별도 검증 영수증에 보관한다. Chromium 터치 에뮬레이션/SwiftShader 결과를 실기기 검증으로 표시하지 않는다.

## 노출과 남은 단계

2026-11-11 사용자 요청으로 `/stark-rift-dev` 체험 페이지와 메인 하단 진입 링크를 연결한다. 정식 `/stark-rift` 공개 라우트·게임 목록 등록 게이트는 유지한다. 세 종족의 실제 경제 규칙을 브라우저에서 확인하고 종족별 저장/복원할 수 있다. 개발 테스트 예외와 검증은 `stark-rift-hosted-preview.md`를 따른다. 내부 측정 도구는 계속 `npm run dev:stark-rift-lab`으로 실행한다.

이번 콘텐츠는 BWAPI v4.4.0에서 추출한 30개 유닛/건물과 기본 무기 업그레이드 3종의 1단계이다. 전체 기술/상위 콘텐츠는 단계 6이다. 라바/알은 해처리의 상태/병렬 주문으로 표현하며 개별 전투 개체는 추후 추가한다. 최종 아트·애니메이션(단계 9)은 완료하지 않았다.

다음 구현은 단계 5 전투·시야이다. 현재 공격 이동은 이동 명령이며 무기 피해/승패 AI는 연결하지 않았다. 지역 작업 시야는 고지대·은폐/탐지·30초 마지막 정보가 포함된 최종 전장의 안개가 아니다. 건물 파괴 후 크립 소멸은 전투 생명주기에서 연결한다. 실제 Android/iOS, 실제 GPU와 장시간 성능 재검증은 별도 장치 검증 항목으로 남아 있다.
