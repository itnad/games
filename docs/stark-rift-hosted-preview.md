# 스타크 리프트 사이트 개발 테스트

2026-11-11 사용자 요청으로 단계 4의 플레이 가능한 개발 테스트를 기존 Paperoid 사이트에 연결한다. 미완성 게임 공개를 미루던 I-09에 대한 명시적 예외다. 정식 게임 `/stark-rift`와 게임 목록 등록/최종 출시 게이트는 유지한다.

- 주소: `/stark-rift-dev`. 메인 화면 하단 `스타크 리프트 개발 테스트 →`로도 진입한다.
- 별도 인증이 붙은 비공개 페이지가 아니다. 기존 공개 사이트의 개발 테스트이며 `noindex, nofollow`를 선언한다. 검색 제외 표시는 접근 제어를 의미하지 않는다.
- 테란·저그·프로토스를 선택하고 `새 테스트 시작`으로 실행한다. 본부 1·일꾼 4·미네랄 50에서 시작하는 운영 규칙과 실제 브라우저 Worker를 사용한다. 내부 lab의 가상 개체·전맵 시야·측정 기능은 사이트에 노출하지 않는다.
- 기존 세로 전용/1:2:1 전장을 유지한다. PC는 브라우저 창의 폭을 높이보다 줄여 사용한다. 회전으로 가로 화면이 되면 정지하며 복귀 뒤 직접 `이어서 진행`한다.
- 현재 가능한 조작은 자원 채취·건설·생산·이동·집결지·연구·취소/반복이다. 기본 전투와 전투 연습은 단계 5A에서 연결했다. 승패·상대 AI·정식 아트는 준비 중임을 시작 화면에 표시한다.
- 10초 자동 저장, 수동 `저장`, `저장하고 나가기`, `이어서 하기`를 제공한다. 저장은 종족별 `paperoid.stark-rift.development.v1.<faction>`에 분리되며 이 브라우저에만 남는다. 새 게임은 기존 저장이 있을 경우 교체 확인을 거친다.
- 저장 복원은 버전/체크섬/소유권/경제 상태/지도 경계를 검증한다. 손상/비호환 데이터는 자동 삭제하지 않는다. 저장 공간 부족/차단은 사용자에게 표시하고 현재 창의 복구본을 보존한다. 저장 실패 시 사용자가 명시적으로 선택 화면으로 나갈 수 있다.

검증은 `npm test`와 `python tools/stark-rift-lab/hosted-smoke.py --url <origin> --full-economy`로 진행한다. 브라우저 검증은 실제 정적 경로·production Worker·종족별 시작/채취·저장 후 새로고침 복원·가로 정지를 확인한다. 자원 주입/시간 가속은 하지 않는다. 실기기/GPU 검증은 별도다.

## 2026-11-12 터치·건설 보완

사이트 푸터와 전장 명령 패널의 스타일 충돌을 수정했다. `일꾼 선택` → `건설` → 건물 메뉴 → 전장 터치 → `건설 확정`으로 진행한다. 비용 부족/선행 조건은 미리보기에서 설명하며 실제 비용 검사는 유지한다. 명령 위치의 900ms 원형 표시와 자원 근처 일꾼 선택 보완은 `stark-rift-touch-construction-fix.md`를 따른다.

## 2026-11-12 기본 전투

`기지 운영 / 전투 연습` 모드 선택, 마린·저글링·질럿·일꾼 기본 공격, 피해·사망·사거리, 체력/보호막과 타격 효과를 연결했다. 연습 저장은 운영과 분리되며 단계 4 저장은 체크섬 검증 후 변환하고 첫 교체 전에 원문을 백업한다. 세부 범위와 남은 단계 5 작업은 `stark-rift-stage5a.md`를 따른다.
