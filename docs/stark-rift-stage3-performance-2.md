## 원인 분리와 변경

전체 틱을 체크포인트 복사, 명령/시스템 실행, 최종 검증으로 나눠 측정했다. 측정은 선택 사항이며 일반 엔진 실행에는 시계를 읽지 않는다. 통계는 게임 상태와 체크섬에 넣지 않고 관측 콜백 오류도 경기 진행에 영향을 주지 않도록 했다.

- **상태 복사**: 엔진의 배열·일반 객체 데이터를 빠르게 복사한다. 공유 참조, 순환 참조, 희소 배열, 부호 있는 0, 자체 `__proto__` 키를 보존한다. 일반 데이터 밖의 타입과 깊은 그래프는 기본 structuredClone으로 처리한다. 롤백 검사에서 원본 상태 복구와 복사본 격리를 확인했다.
- **런타임 검증**: 객체 스키마의 필드 정보를 준비해 재사용한다. 내부 기본형 판정이 통과하면 오류 경로 문자열과 임시 배열 생성을 줄이고, 실패하면 원래의 검증 경로로 오류를 기록한다. 배열의 getter는 실패 시에도 한 번만 읽는다. 사용자 검사·refine, 희소 값, 범위, 알 수 없는 필드와 사전 검사는 유지한다.
- **탐색**: 캐시 경로의 도착점 한 곳을 확인하려고 모든 개체의 예약 인덱스를 만들던 비용을 없앴다. 여러 셀을 확인하는 실제 탐색에서는 기존 인덱스를 사용한다. 한 탐색 확장 안에서 변하지 않는 최선 셀의 통과 여부와 거리를 재사용한다.
- **충돌**: 겹침 여부만 필요한 이동 구간 검사에서는 후보 집합을 정렬하지 않는다. 이동 후보의 거리/y/x 순위와 충돌 결과는 바꾸지 않는다.

내부 검증 화면에는 상태 복사/최종 검증 통계를 추가했다. 내보내기 JSON과 Node 보고서에도 구간별 수치를 남긴다. 기준 비교 도구는 실제 기준 폴더의 Git 커밋·트리를 읽어 기록하며 이전 기준 SHA를 고정해서 표시하지 않는다.

## 검증

- 전체 Paperoid 빌드·기존 게임/한국어 조사 회귀 검사, 타입 검사, 전용 테스트 **214개**, 내부 검증 화면 빌드를 통과했다.
- 기준 엔진과 네 시나리오 총 **3,200틱의 매 틱 전체 상태 체크섬**을 비교했다. 선택 200틱, 통로 1,200틱, 실제 지도 1,200틱, 교차 600틱을 비교했다.
- 체크포인트 그래프의 참조 관계와 격리, 예외 후 롤백·일시정지, 관측 오류 격리, getter 읽기 횟수, 기본형 검증 오류의 순서·경로, 단일 도착점 판정과 예약 인덱스의 일치를 검사했다.
- 장시간 이동 검사 2개를 추가했다. 두 시나리오 모두 게임 시간 120초 이내에 전원이 도착하며, 검사 지점에서 20초 이상 움직이지 않은 활성 명령이 없음을 확인한다.

기준 소스와 후보를 대조하려면 다음 명령을 사용한다. 기준 체크아웃에 위 기준 커밋의 소스를 준비한다.


## 서버 측정 결과

Linux x64, Node 24.19.0, AMD EPYC 9V74, 논리 CPU 3개의 같은 환경에서 측정했다. 아래 전후 표는 각각 별도 실행이며 첫 20틱을 제외했다. 다른 실행의 부하·JIT·GC에 따른 변동이 있으므로 고정된 기기 성능 보증으로 사용하지 않는다.

| 시나리오 | 기준 틱 평균/p95 ms | 보완 후 틱 평균/p95 ms | 보완 후 탐색 평균 ms |
| --- | ---: | ---: | ---: |
| 50기 실제 지도 | 5.92 / 11.04 | 3.96 / 7.66 | 0.20 |
| 200기 교차 | 9.73 / 15.09 | 4.37 / 7.31 | 1.44 |

틱 평균 6ms, p95 10ms, 탐색 평균 2.5ms의 목표를 이 서버 측정에서 모두 통과했다. 별도의 같은 프로세스 상태 비교에서도 기준과 후보의 결과가 일치했다. 원본 측정 보고서에는 최대값·워밍업·실행 환경·소스 식별자도 기록된다.

최대값의 한계도 남아 있다. 실제 지도 측정의 최대 틱은 약 67.9ms였고 그중 상태 복사 최대값이 약 56.2ms였다. 평균/p95 통과를 긴 멈춤이 완전히 없다는 뜻으로 해석하지 않는다. 실제 기기에서 장시간 메모리·GC·프레임 관찰이 필요하다.

## 미완료 이동 조사

짧은 측정 창의 끝에 남아 있던 명령을 전원 도착 실패로 단정하지 않고 실행 시간을 늘렸다.

| 시나리오 | 짧은 창의 남은 명령 | 전원 도착 틱 | 게임 시간 |
| --- | ---: | ---: | ---: |
| 50기 실제 지도 | 1,200틱에서 4 | 1,232 | 61.6초 |
| 200기 교차 | 600틱에서 80 | 1,000 | 50초 |

추가 명령 없이 전원이 도착했고 교차 시나리오는 1,800틱까지 관찰해 다시 이동 명령이 생기지 않는 것도 확인했다. 이 두 합성 시나리오에서는 영구 교착이 재현되지 않았다. 실제 원작 이동 수치·전투가 연결된 상황까지 검증한 것은 아니다.
