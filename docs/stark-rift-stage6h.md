# 단계 6H · 스테이시스 선택적 자동시전

2026-11-15. 엔진 `0.18.0-stage6h`, 저장·스키마17, 통신18. 세로 플레이 전용.

`/stark-rift-dev` → 프로토스 → 특수 연습 → 새 테스트 시작 → 아비터 선택. **스테이시스 버튼을 0.55초 길게 누르거나 자동시전 켜기 버튼**으로 선택한 아비터의 자동시전을 켠다. 켜진 기술은 `A`로 표시하며 혼합 선택은 `A 일부`로 표시한다. 짧게 누르면 기존 수동 위치 지정이다. 키보드는 별도 자동시전 버튼 또는 Shift+Enter/Space를 사용한다. 드래그·터치 취소·선택 변경·일시정지는 길게 누르기 대기를 취소한다.

## 판단과 수동 우선

- 기본 꺼짐. 연구·에너지100·현재 시전 가능 상태가 필요하다. 에너지나 연구가 없어도 설정은 미리 켜거나 끌 수 있고, 정지 중인 아비터도 자동시전 설정을 끌 수 있다. 리콜은 계속 수동이다.
- 현재 시야와 탐지로 확인한, 살아 있고 정지되지 않은 적 2기 이상이 원래 스테이시스 정사각형 범위와 겹치는 지점을 찾는다. 지상/공중과 일꾼을 포함하며 건물·잠복·화물은 제외한다. 정찰 기억과 숨은 적은 후보·밀집도 판단에 사용하지 않는다.
- 같은 범위에 영향을 받을 아군이 하나라도 있으면 보류한다. 시전자 자신은 원래 주문의 제외 대상이다. 다른 아비터·수송선도 아군 보호 검사에 포함한다. 원래 수동 시전은 계속 아군을 정지시킬 수 있다.
- 현재 사거리 안에서만 시전하며 자동 접근·추격하지 않는다. 대기·사수 또는 이동 명령의 도착이 끝난 상태에서만 판단한다. 이동·공격·순찰 중에는 해당 수동 명령을 유지한다. 실제 수동 명령이 실행되면 저장되는20틱(1초) 유예를 적용하며, 같은 틱의 수동 주문을 자동시전보다 먼저 처리한다. 기술 버튼을 눌러 위치를 고르는 동안에도 시뮬레이션은 계속된다.
- 먼저 처리한 아비터가 실제로 정지시킨 대상은 다음 아비터 후보에서 빠져 중복 결제를 막는다. 서로 다른 적 군집에는 각각 사용할 수 있다. 기존 수동 시전의 연구·에너지·사거리·정지·피해·지속시간 규칙을 그대로 사용한다.
- 판단 비용을 제한하기 위해5틱마다 ID순 원형 순회로 최대4시전자를 평가한다. 각 시전자는12타일 안 보이는 적 중 가까운32기를 후보 기준점으로 삼아 중심점과 각자의 가장 가까운 이웃과의 중점을 검사한다. 적 수가 많은 지점, 가까운 지점, Y/X 순으로 선택한다. 이는 게임 고유 자동 판단 규칙이며 전역 최적 영역 탐색이나 원작 AI 재현을 뜻하지 않는다.

## 부대·저장·정보 경계

선택한 유닛의 설정과 수동 유예 틱을 저장한다. 한 부대의 전원을 선택해 켜거나 끄면 그 부대 설정도 바뀐다. 해당 슬롯으로 새 아비터를 배정하면 슬롯의 자동시전 설정을 상속한다. 다른 종류의 부대로 교체하면 스테이시스 설정을 지운다. 개별 설정 변경 시 일부만 켜진 부대는 가능하며, 부대 전체 토글로 통일할 수 있다.

저장6~16의 원본 버전·데이터·체크섬을 검증해17로 이관한다. 이전 저장은 자동시전 꺼짐으로 시작하고, 단계6G의 리콜·스테이시스·에너지·자원·부대·RNG·대기 명령을 보존한다. 원문은 덮어쓰기 전 `.stage6g-backup`에 남기며 기존 세대 백업도 유지한다. 자기 아비터의 자동시전 여부만 렌더 패킷에 제공한다. 적 설정·탐색 후보·숨은 적 위치는 제공하지 않는다.

## 검증과 후속 범위

엔진 회귀는 기본 꺼짐, 시야·탐지·연구·에너지·단일 적·범위 밖 거절, 아군 보호, 수동 우선·이동 중 보류, 다중 시전자 중복 방지, 부대 설정 상속, 저장 결정성과 단계6G 원문 백업을 검사한다. 실제 운영 빌드에서 두 세로 화면 크기의 터치 길게 누르기·짧게 누르기·자동시전·저장/재접속·가로 차단을 검사한다. 실행 결과·배포 SHA·CI·증빙은 별도 영수증에 기록한다.

물리 Android/iOS와 실제 GPU 검수는 별도다. 다른 주문 자동시전, 추가 종족 기술·유닛, 적 전략 AI, 최종 미술과 애니메이션은 후속 작업이다.
