# 단계 6D — 시즈 모드와 지상 범위 포격

2026-11-14. 엔진 `0.14.0-stage6d`, 저장·스키마 13, 통신 14. 단계 6C 능동 클로킹에 이어 시즈 탱크 연구·전환·포격을 연결했다. 세로 플레이만 지원한다.

## 확인 경로

`/stark-rift-dev` → **특수 연습 → 테란 → 새 테스트 시작 → 시즈 탱크 선택 → 시즈 모드**. 2초 후 지상 적을 자동 포격한다. 붉은 적을 터치하면 특정 적을 지정한다. **시즈 해제**도 2초가 걸리며 완료 후 전장 지점을 터치하면 이동한다. 부대 2번의 기존 탱크 두 기와 시즈 모드 연구를 제공하고 적 프로브 셋을 모아 배치해 범위 피해를 확인할 수 있다. 기존 고스트·레이스·수송 연습도 유지한다. 기존 저장을 이어 하면 제공 병력을 새로 추가하지 않는다.

일반 기지 운영은 **배럭 → 팩토리 → 머신샵 → 시즈 모드 연구** 순서다. 연구는 원작 150 미네랄/150 가스, 1,200 프레임을 경제 시간 반감해 500틱(25초)이다. 머신샵이 자기 팩토리에 연결되어야 연구를 시작·진행한다. 중복 연구를 막고 수동 취소는 전액 환불한다. 전환은 추가 비용이나 에너지를 쓰지 않는다.

## 상태·이동·수송

- 전차 모드와 시즈 모드는 같은 유닛 ID·소유자·체력 및 소수부·인구·부대·대열·태세를 유지한다. 기존 무기 대기시간과 프레임 잔여값도 보존해 반복 전환으로 포격 주기를 초기화하지 않는다. 혼합 모드의 탱크를 같은 탱크 부대로 취급한다.
- 진입·해제 각각 40틱(2초) 동안 이동·공격·탑승·재전환·정지/사수 명령을 차단한다. 부대·대열·태세 변경은 허용한다. 기존 이동·추격·탑승 접근 예약은 전환 시작 시 정리한다.
- 원작은 포탑 방향 정렬과 애니메이션 신호에 따라 전환한다. 현재 2초는 이 엔진의 고정 전환 규칙이며 원작 애니메이션 프레임을 완전히 재현했다는 의미가 아니다. 연구 시간 반감은 전환 시간에 적용하지 않는다.
- 시즈 상태에서는 이동·공격 이동·순찰·수송 탑승을 차단한다. 보이는 적을 지정할 수 있지만 사거리 밖의 적을 추격하지 않는다. 적이 사라지면 현재 위치에서 대기하며 새 목표를 찾는다. 이동 경로 탐색에서도 고정 탱크를 제외하고 충돌 장애물로 유지한다. 해제 후 전차 모드의 원래 이동 속도와 4칸 수송을 복구한다.
- 전환 중에도 적의 공격은 받는다. 파괴되면 전환 기록을 삭제하고 인구·부대 참조를 정리한다. 저장·메뉴·가로 전환·백그라운드 일시정지 중에는 전환 시간이 흐르지 않는다.

## 원작 포격 자료와 적용

BWAPI v4.4.0의 시즈 모드 유닛, Arclite Shock Cannon, Tank Siege Mode 연구를 `data/siege-original.json`에 별도로 추출했다. 기존 JSON과 이전 버전 해시는 보존한다. 총 47개 경제 정의 중 시즈 모드 정의는 전차에서만 전환하며 생산 메뉴에서 직접 구매하지 않는다. `python tools/stark-rift-data/extract-siege.py <원작 소스 폴더>`로 재생성할 수 있다. BWAPI 원본과 범위 피해 동작을 참조한 고정 OpenBW 커밋의 URL·SHA256을 JSON에 기록한다.

| 항목 | 적용 |
| --- | --- |
| 피해 | 폭발형 70, 크기별 피해·방어력·보호막 적용 |
| 주기 | 원작 75프레임을 20Hz에 잔여값과 함께 환산 |
| 사거리 | 충돌 상자 가장자리 간 최소 64픽셀(2타일), 최대 384픽셀(12타일) |
| 범위 | 착탄점부터 피해 대상 충돌 상자까지 10픽셀 이내 100%, 25픽셀 이내 50%, 40픽셀 이내 25% |
| 피해 순서 | 범위 비율로 원 피해를 나눈 뒤 보호막·방어력·크기 보정 |
| 대상 | 지상 유닛·시작된 건물. 아군도 범위 피해를 받으며 발사자 자신·공중·수송 화물·미착공 청사진은 제외 |
| 잠복 | 탐지 없이도 내측 범위에는 피해, 중·외측 범위에는 피해 없음 |

탱크 시야는 10타일이므로 긴 사거리 포격에는 아군의 전방 시야가 필요하다. 현재 시야·탐지·고지대 명중 규칙을 유지하며 한 틱의 공격을 먼저 모은 뒤 피해를 적용해 동시 치명타도 처리한다. 포격은 즉시 명중하는 공격과 착탄 효과로 제공한다. 별도 비행 포탄·지면 지정 공격·차량 무기 업그레이드는 후속 범위다. 원작 무기의 강화 증가값 +5는 자료에 보존하되 제공하지 않는 연구가 있는 것처럼 표시하지 않는다.

상단 자원 패널을 스크롤해도 일시정지 버튼은 위에 고정해 짧은 전환 중에도 바로 멈출 수 있다. 전환 진행률과 시즈 탱크 실루엣, 착탄 범위 효과를 표시한다. 적의 시야 밖에서 발사한 포격의 착탄은 위치 경고로 전달하며 발사자의 내부 ID·무기 이름을 노출하지 않는다.

## 저장과 검증

전환 목표 모드·남은 틱·전체 틱·고정 위치를 저장한다. 6~12 형식의 엔진·데이터 버전·원본 체크섬을 확인해 13으로 이관한다. 단계 6C의 에너지·클로킹·수송·연구·RNG·미래 명령을 보존한다. 최초 교체 전에 `.stage6c-backup`으로 원문을 보관하며 백업 실패 시 기존 저장을 덮어쓰지 않는다.

다른 능력 처리기로 넘길 때 성공 값 `null`을 오류로 바꾸던 연결 문제도 수정했다. 빌드한 실제 Worker에서 고스트·레이스 클로킹, 저그 버로우, 시즈 모드를 각각 실행하는 통합 검증을 추가했다.

연구 비용·취소·완료, 정확한 전환 틱, 명령 제한, 부대/체력/무기 주기 보존, 최소·최대 사거리, 전방 시야, 정확한 범위 경계, 아군·잠복·수송·보호막 피해, 시야 정보 제한, 전환 중 저장 및 실행 결정성을 검증한다. 실제 운영 빌드에서 두 세로 화면 크기의 터치·일시정지/재접속·범위 포격·해제 후 이동·수송을 확인한다. 배포 SHA·CI·증빙은 별도 검증 영수증에 기록한다. 자동 Chromium/SwiftShader 검증을 실제 Android/iOS·물리 GPU 검수로 표시하지 않는다.
