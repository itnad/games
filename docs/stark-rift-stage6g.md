# 단계 6G · 리콜과 스테이시스 필드

2026-11-14. 엔진 `0.17.0-stage6g`, 저장·스키마 16, 통신 17. 세로 플레이 전용.

## 연구·시전

- 동력이 있는 아비터 트리뷰널에서 리콜 연구: 150/150, 37.5초. 스테이시스 필드 연구: 150/150, 31.25초. 일반 운영에서는 비용·중복 연구·취소·동력 검사를 적용한다.
- 일반 생산 아비터는 에너지 50/200으로 시작하고 기존 고정 소수점 에너지 시스템을 사용한다. 원작 프레임당 8/256 회복, 24:20 프레임 나머지를 저장한다. 정지 중에도 에너지는 회복한다. 은폐장은 계속 무료다.
- 리콜은 에너지 150, 스테이시스는 100. 시전 버튼 → 전장 또는 미니맵 위치 터치. 한 번에 아비터 한 기가 시전하며, 선택한 아비터 중 연구·에너지·상태가 허용하는 첫 기를 사용한다. 시전 대기 취소는 자원을 사용하지 않는다. 실제 시전 후에는 비용을 환불하지 않는다.
- 특수 연습은 아비터 2기(3·4번 부대), 두 연구, 각 에너지 200을 명시적으로 제공한다. 일반 생산·이전 저장에 이 보너스를 적용하지 않는다. 에너지가 없던 단계6F 아비터 저장에는 50과 분수 나머지0을 초기화한다.

## 리콜

- 지정 지역에서 충돌 상자가 가로·세로4타일 정사각형과 겹치는 아군을 약0.9초(원작22프레임→18틱) 뒤 아비터 주변으로 소환한다. 거리·시야 제한 없이 지도 안을 지정할 수 있고, 대상은 완료 시점에 판정한다. 빈 지역도 비용을 사용한다.
- 건물·수송 중인 승객·잠복·러커 알·스테이시스·시즈 전환 중 유닛은 제외한다. 전환을 마친 시즈 탱크, 공중 유닛과 승객을 실은 수송선은 가능하다. 자기 자신은 제외한다.
- 각 유닛을 ID 순서로 배치하며, 아비터 주변 최대6타일에서 지형·충돌·공중/지상을 검사해 빈 곳을 찾는다. 배치할 곳이 없는 유닛은 원래 위치에 남는다. 탐색 순서·범위는 이 게임의 결정적 배치 규칙이다.
- 부대·정의·체력·보호막·피해 분수·공격 대기 시간·개인 은폐를 보존한다. 기존 이동·추격과 일꾼 작업은 해제한다. 들어오는 추적 발사체와 탑승·하차 예약을 정리한다. 소환된 수송선의 화물은 유지하며 승객 좌표도 함께 옮긴다. 이미 진행 중인 러커 파동은 고정 경로를 유지한다.
- 시전 중 이동·공격·재시전은 불가하다. 아비터가 정지되면 남은 시전 시간이 멈추고, 죽으면 소환이 취소된다.

## 스테이시스 필드

- 아비터 충돌 상자에서9타일 안을 직접 지정한다. 범위 밖은 자동 접근 없이 거절한다. 원작의 자동 접근 주문 동작과 다르다.
- 충돌 상자가 가로·세로3타일 정사각형과 겹치는 아군·적, 지상·공중 유닛을 정지한다. 시전자·건물·잠복·화물·이미 정지 중인 유닛은 제외하며, 기존 정지 시간을 연장하지 않는다. 숨은 지상·공중 유닛도 범위에 들면 정지할 수 있으나 렌더러는 기존 시야·탐지 경계를 지킨다.
- 원작131상태 주기×8프레임을20Hz로 환산한873틱(43.65초) 동안 정지·무적. 이동·공격·탑승·새 주문을 거절하며, 직접 피해·범위 포격·지하 파동·추적 탄에도 피해를 받지 않는다.
- 현재 이동·공격 명령을 정리하고, 일꾼의 작업 상태는 보존해 해제 후 재개한다. 건설 중 SCV의 공사, 러커 변태, 시즈 전환, 수송선의 탑승·하차와 대기 중 리콜을 멈춘다. 정지 중 아비터 은폐장과 탐지 능력은 꺼진다. 이 타이머/변태 처리와 명령 재개 규칙은 현재 엔진에서 명시적으로 정한 동작이다.
- 남은 정지 시간을 선택 창에 표시하며 유닛을 얼음 결정으로 그린다. 에너지·기존 클로킹 소모·공격 대기 시간은 원래 시간 규칙을 유지한다.

## 저장·검증 경계

스테이시스 위치·적용/종료틱, 리콜 대상 지역·남은 대기틱, 시전 효과·에너지를 저장한다. 원본 체크섬과 각 버전 해시를 검증해 저장6~15를16으로 변환하고, 단계6F 원본은 `.stage6f-backup`에 남긴다. 이전 러커·시즈·은폐·화물·부대·자원·RNG를 유지한다. 공개 렌더 자료에는 현재 보이는 효과 위치·정지/시전 남은 시간만 전달하고, 적 리콜의 먼 대상 지역이나 소스/피격 ID 목록은 전달하지 않는다.

`data/spells-original.json`은 BWAPI v4.4.0과 고정 OpenBW 커밋의 주문·상태 처리에서 연구 비용·시간·에너지·범위·대기·지속시간을 추출했다. 이전 원작 JSON과 해시는 보존한다. `python tools/stark-rift-data/extract-spells.py <원본 폴더>`로 재생성한다.

물리 Android/iOS·실제 GPU 인증은 별도다. 브라우저 검증은 Chromium/SwiftShader와 실제 터치 이벤트·정상 시뮬레이션 시간을 사용한다.
