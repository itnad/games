# Stark Rift 제품 평가와 재설계 계획

## 결론

현재 버전은 공개 게임으로 다듬어진 제품이 아니라, 규칙 엔진이 동작하는 기술 시제품이다. 자원 채취·건설·생산·부대 이동·전투 같은 기능 수는 많지만, 플레이어가 전황을 읽고 결정을 내리는 과정과 그 결과를 느끼는 표현이 약하다.

부분적인 색상·아이콘 교체로 해결하기 어렵다. 결정론적 시뮬레이션, 명령 검증, 경로 그래프, 테스트는 유지하고 화면 구조, 입력 방식, 전투 표현, 종족 고유 규칙은 다시 만든다.

## 1. 기존 초안 의존도

Stark Rift는 별도 폴더에 만들었지만 구현의 출발점은 원격 브랜치의 `Frontline Commander` 초안이다. 이름을 일반화한 뒤 줄 단위로 비교하면 다음과 같다.

| 영역 | 기존 초안과 유사도 | 판단 |
| --- | ---: | --- |
| AI | 96.5% | 사실상 같은 빌드 순서와 공격 파동 |
| 엔진 | 92.4% | 같은 경제·건설·부대·전투 구조 |
| 렌더러 | 88.1% | 같은 도형 중심 지도와 유닛 표현 |
| 화면 코드 | 80.6% | 같은 4개 탭과 선택→명령 흐름 |
| 타입 | 84.9% | 같은 상태 모델을 확장한 수준 |
| 데이터 | 78.8% | 종족 데이터가 추가됐지만 기본 역할은 동일 |

새로 추가한 종족 카탈로그와 정찰 시스템은 독립적인 개선이지만, 제품의 인상을 결정하는 핵심 구조는 기존 초안과 같다. 품질 문제가 참고자료를 많이 이식한 영향인지에 대한 답은 **그렇다**이다.

## 2. 냉정한 품질 평가

| 항목 | 점수 | 근거 |
| --- | ---: | --- |
| 시각적 완성도 | 2/10 | 원·사각형·문자 기호가 대부분이고 종족 실루엣, 건물 형태, 지형 재질이 없다. |
| 전황 가독성 | 3/10 | 어느 부대가 어디로 가는지, 누가 우세한지, 무엇이 공격받는지 한눈에 읽기 어렵다. |
| 모바일 조작 | 4/10 | 지도에서 지역 선택 후 탭을 바꾸고 버튼을 눌러야 한다. 같은 결정을 위해 화면을 여러 번 왕복한다. |
| 전략적 깊이 | 4/10 | 시스템은 많지만 선택 결과가 대부분 생산량과 수치 차이다. 명확한 상성·능력·타이밍 창이 부족하다. |
| 종족 차별화 | 3/10 | 이름과 능력치가 달라도 생산 구조와 전투 행동이 거의 같다. |
| 전투 손맛 | 2/10 | 사격·피격·폭발·후퇴 신호가 약하며 소리, 진동, 큰 상태 변화가 없다. |
| 온보딩 | 2/10 | 시작 전에 설명문을 읽어야 하고 첫 경기에서 다음 행동을 안내하지 않는다. |
| 재플레이 가치 | 3/10 | 지도 1개, 승리 조건 1개, AI 빌드 순서가 고정적이다. |
| 엔진 기반 | 6/10 | 결정론적 틱, 명령 검증, 전장의 안개, AI 공통 규칙, 회귀 테스트는 재사용 가치가 있다. |

전체 제품 평가는 **3/10**이다. 기능 완성도와 제품 완성도를 혼동한 것이 가장 큰 문제다.

### 현재 구현에서 확인한 수치

- 모바일 전투 화면의 하단 패널이 최대 43%를 차지한다.
- 핵심 기능이 부대·건설·생산·일꾼의 4개 탭으로 나뉜다.
- AI 대 AI 8개 시드 기준 보통 난이도 평균 경기 시간은 약 8분 32초이며, 가장 긴 경기는 약 12분 3초다.
- 쉬움에서는 플레이어 측 규칙이 8전 전승, 어려움에서는 8전 전패로 나타나 난이도가 판단 변화보다 수입·공격 타이밍 차이에 크게 의존한다.
- 사운드, 진동, 종족별 애니메이션 자산이 없다.

## 3. 핵심 문제

### 기능을 먼저 채우고 핵심 경험을 나중으로 미뤘다

4개 탭, 6종 건물, 일꾼 배치, 3개 부대, 3개 대열을 한꺼번에 넣었다. 플레이어가 가장 자주 반복할 `전황 확인 → 선택 → 명령 → 결과 확인` 흐름을 먼저 완성하지 않았다.

### 화면이 전장이 아니라 관리 양식처럼 보인다

화면 아래 42~43%를 탭 패널이 차지한다. 건설·생산·일꾼을 목록에서 관리하므로 지도는 결과를 보는 작은 배경이 되고, 플레이의 중심이 버튼 목록으로 이동한다.

### 직접 조작을 줄인 대신 결정의 밀도까지 줄었다

미세 조작을 없애는 방향은 맞다. 그러나 현재 자동 전투는 플레이어가 개입할 타이밍과 위험 신호도 함께 없앴다. 대열은 수치 보정이고 전투 중 능력이나 교전 수칙이 없어 관전 시간이 길다.

### 종족이 규칙이 아니라 스킨과 수치로 구분된다

세 종족 모두 같은 건물 역할, 같은 세 병종, 같은 생산 순서, 같은 부대 명령을 사용한다. 이름과 비용 차이만으로는 다른 운영 감각이 생기지 않는다.

### 표현 계층이 엔진 상태를 전달하지 못한다

지도는 실제 정보를 많이 가지고 있지만 렌더러가 작은 도형으로 압축한다. 이동 경로, 사거리, 목표, 화력 집중, 위험도, 점령 진행도를 명확하게 시각화하지 않는다.

## 4. 새 제품 목표

> 한 손으로 6~8분 동안 플레이하는 전술 지휘 게임. 유닛을 찍는 속도가 아니라 전선, 생산 우선순위, 정찰 정보, 공격 타이밍으로 승부한다.

제품 목표는 다음과 같다.

- 첫 의미 있는 명령까지 10초 이하
- 모든 주요 명령은 지도에서 시작해 두 번의 터치 안에 완료
- 5~10초마다 판단할 정보나 선택이 하나 이상 발생
- 전투 결과의 원인을 지도만 보고 설명 가능
- 세 종족은 첫 경기에서도 운영 방식이 다르게 느껴짐
- 360×780 화면에서 핵심 전장을 스크롤 없이 확인
- 한 경기는 평균 6~8분, 10분을 넘기지 않음

## 5. 유지·재작성·삭제 범위

### 유지

- 0.1초 결정론적 시뮬레이션과 시드 RNG
- 명령 검증과 비용·보급 계산
- 지역 그래프와 경로 탐색
- 동시 피해 처리와 기본 전투 판정
- 실시간 시야와 마지막 접촉 정보 모델
- AI가 플레이어와 같은 명령을 사용하는 원칙
- Node 기반 엔진 회귀 테스트

### 재작성

- `stark-rift-game.tsx`의 전투 화면과 입력 흐름
- `stark-rift-renderer.js` 전체 표현 계층
- `stark-rift.css` 전투 UI와 메뉴 디자인
- 종족 카탈로그를 고유 규칙과 능력 중심으로 확장
- AI의 정찰, 기만, 다중 부대 운용
- 첫 경기 튜토리얼과 상황별 안내

### 삭제 또는 단순화

- 항상 노출되는 부대·건설·생산·일꾼 4개 탭
- 별도 일꾼 배치 화면
- 세로 지도 확대/축소 모드와 드래그 탐색
- 시작 전 긴 사용 설명 목록
- 의미가 약한 개전 전략 수치 보정
- 문자 기호만으로 구분하는 유닛과 건물

## 6. 새 모바일 조작 구조

지도는 항상 전체가 보인다. 하단 패널은 고정 메뉴가 아니라 선택한 대상에 따라 바뀌는 얕은 컨텍스트 시트다.

```text
┌──────────────────────────┐
│ 광석 420   보급 18/26  04:12 │
├──────────────────────────┤
│          적 본진          │
│     ● 북부 ── ▲ 동부      │
│        ╲  교전  ╱          │
│     ■ 서부 ── ◆ 중앙      │
│          아군 본진         │
│ 이동 화살표·위험도·점령도  │
├──────────────────────────┤
│ 1부대  2부대  3부대       │
│ [정찰] [집결] [공격] [철수] │
└──────────────────────────┘
```

### 기본 흐름

1. 부대 카드를 누른다.
2. 지도 지역을 누른다.
3. 가능한 명령 2~4개만 나타난다.
4. 명령을 누르면 지도에 경로와 예상 위험도가 즉시 표시된다.

### 건설과 생산

- 아군 기지를 누르면 해당 기지의 생산 큐와 건설 후보가 한 시트에 표시된다.
- 생산 건물별 목록 대신 `전열 보강`, `화력 보강`, `정찰 보강`의 의도 중심 빠른 생산을 제공한다.
- 보급 부족이나 선행 건물 부족은 비활성 버튼 설명이 아니라 다음 행동 제안으로 표시한다.

### 경제

- 일꾼은 완전 자동 배치한다.
- 플레이어의 경제 선택은 `일꾼 생산`, `새 광산 확장`, `군사 투자` 세 가지로 압축한다.
- 광산별 효율은 지도 위 채굴 링과 경고로 보여준다.

## 7. 전투 표현 재설계

### 지도

- 지역마다 고유한 실루엣과 색면을 사용한다.
- 연결로는 장식선이 아니라 병력이 실제로 이동하는 폭 있는 전선으로 표현한다.
- 아군·적군의 영향력을 반투명 영역으로 표시한다.
- 선택한 부대의 경로, 도착 예상 시간, 예상 교전 위험을 한 번에 표시한다.

### 유닛과 건물

- 종족마다 형태 언어를 분리한다.
  - 개척 연맹: 각진 장갑, 청색 조명, 직선형 포신
  - 균열 군락: 비대칭 생체 형태, 자홍색 핵, 유기적 움직임
  - 성운 의회: 삼각형·고리 구조, 금빛 공명, 부유 이동
- 병력은 개별 원 대신 3~7개의 작은 실루엣 군집으로 보여준다.
- 건물은 역할을 한눈에 구분하는 고유 실루엣을 사용한다.

### 피드백

- 공격 시 포신 반동, 탄도, 피격 점멸, 파편 방향을 구분한다.
- 우세·열세가 바뀌는 순간 전선 색과 카메라 진동으로 알린다.
- 본진 공격, 보급 차단, 측면 돌파에는 서로 다른 경보음과 진동 패턴을 사용한다.
- 전투 로그는 제거하고 지도 위 짧은 사건 배너로 대체한다.

## 8. 종족을 실제 규칙으로 구분

### 개척 연맹

- 전진기지끼리 연결되면 보급과 생산 속도가 증가하는 `보급선` 규칙
- 임시 방벽을 배치해 전선을 고정
- 균형 잡힌 재배치와 방어 반격에 강함

### 균열 군락

- 전투 사망과 광산에서 `생체 물질`을 모아 즉시 증식
- 건물을 회수해 다른 지역에 다시 성장시킬 수 있음
- 저렴한 병력과 빠른 측면 압박에 강함

### 성운 의회

- 인접 거점이 연결될수록 능력이 강화되는 `공명망` 규칙
- 소수 병력이 짧은 거리 위상 이동 가능
- 비싸지만 정확한 타이밍 공격과 지역 봉쇄에 강함

세 종족이 같은 세 병종을 다른 이름으로 사용하는 구조를 끝내고, 생산 리듬과 지도 사용 방식부터 다르게 만든다.

## 9. 게임 흐름

### 0:00~1:00 정찰과 첫 선택

- 첫 정찰 경로와 첫 군사/경제 투자 중 하나를 선택한다.
- 튜토리얼은 화면 설명 대신 첫 목표 세 개로 진행한다.

### 1:00~3:00 확장과 첫 교전

- 중앙과 측면 중 어느 전선을 먼저 장악할지 결정한다.
- 첫 교전은 상성을 학습할 수 있도록 소규모로 제한한다.

### 3:00~6:00 종족 능력과 전선 변화

- 종족 고유 자원과 지휘 능력이 활성화된다.
- 정찰 실패와 보급선 차단이 실제 공격 기회를 만든다.

### 6:00~8:00 결판

- 핵심 지역 두 곳을 장악하면 적 사령부 보호막이 약해진다.
- 단순한 본진 체력 깎기보다 전선 장악이 승리로 연결된다.

## 10. 구현 단계와 완료 조건

### 단계 A — 경험 프로토타입

- 개척 연맹 대 개척 연맹만 사용
- 지도 전체 고정 표시
- 부대 선택 → 지역 선택 → 명령의 2터치 흐름
- 컨텍스트 시트와 명확한 이동 경로 구현
- 기존 엔진을 어댑터로 연결하되 기존 패널 UI는 사용하지 않음

완료 조건: 처음 보는 사용자가 설명 없이 병력을 생산하고 첫 공격 명령을 내릴 수 있다.

### 단계 B — 전투 가독성과 손맛

- 새 유닛·건물 실루엣
- 공격·피격·파괴 애니메이션
- 우세도, 공격 경보, 목표 경로, 예상 도착 시간
- 소리와 선택적 진동

완료 조건: 3초짜리 전투 화면만 보고 공격 방향, 우세 진영, 핵심 병종을 맞힐 수 있다.

### 단계 C — 종족 고유 규칙

- 보급선, 생체 물질, 공명망 구현
- 종족별 지휘 능력 2개
- AI가 각 종족 규칙을 실제로 사용

완료 조건: 이름과 색을 가려도 플레이 방식으로 종족을 구분할 수 있다.

### 단계 D — 온보딩과 밸런스

- 첫 경기 목표형 튜토리얼
- 20경기 이상 자동 시뮬레이션과 수동 플레이 테스트
- 평균 경기 시간, 첫 교전, 무행동 구간 계측
- 저사양 모바일 성능과 접근성 확인

완료 조건: 평균 경기 6~8분, 첫 교전 90초 이내, 15초 이상의 무의미한 대기 구간이 없다.

## 11. 다음 작업

다음 구현은 새 기능 추가가 아니라 **단계 A 경험 프로토타입**으로 시작한다. 기존 공개 버전을 기준선으로 보존하고, `stark-rift-v2` 작업 브랜치에서 화면과 렌더러를 교체한다. 첫 시연본은 한 종족·한 지도·한 난이도만 제공하며, 조작과 전투 가독성이 통과된 뒤 나머지 콘텐츠를 옮긴다.
