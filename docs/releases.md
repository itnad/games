# 배포 이력

GitHub 커밋과 Sites 버전을 함께 기록합니다. 배포 후 실제 URL 확인이 끝난 항목만 추가합니다.

| 날짜 | GitHub 커밋 | Sites 버전 | 확인 URL | 요약 |
| --- | --- | --- | --- | --- |
| 2026-11-01 | `a8ec431` | 226 | `/haeru` | 해산물 도감 모바일 레이아웃 보완 |
| 2026-11-02 | `db86de2` | 227 | `/haeru` | Stark Rift 기반 작업과 Sites 소스 동기화 |

새 배포는 `날짜 / 배포 커밋 / Sites 버전 / 확인 URL / 요약`을 작업 기록에 남깁니다. 커밋 자체가 자신의 SHA나 아직 생성되지 않은 Sites 버전을 미리 알 수 없으므로, 소스 문서에는 완료된 직전 배포까지만 기록합니다.
