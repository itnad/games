# 단계6J · 메딕 생산과 치료

2026-11-16. 메딕은 배럭에서 아카데미를 선행 조건으로 생산한다. 비용50/25, 인구1, 체력60·방어1, 생산188틱(9.4초). 기존 비용·생산시간 환산을 따른다. 카두세우스 반응로는 아카데미에서150/150·1042틱, 1회 연구한다. 최대 에너지200→250, 기존 에너지 보존, 새 생산62.5.

## 치료 규칙

BWAPI4.4.0과 고정 OpenBW 커밋에서 추출했다. `tools/stark-rift-data/extract-medic.py`가 출처·해시를 포함한 `medic-original.json`을 재생성한다. 원작 프레임마다 최대200/256HP, 에너지비용floor(회복량/2)/256, 충돌상자 사이30픽셀, 매 회복 최소 에너지1. 20Hz 틱에24fps를 정수 나머지로 적분하며 프레임별 재생→치료를 교차한다. 표시 체력과 전투 HP 나머지를 함께 수정한다. 보호막에는 관여하지 않는다.

같은 소유자의 살아 있는 유기체 지상 유닛을 치료한다. SCV도 유기체다. 자신·건물·기계·공중·적·잠복·수송 중·스테이시스 대상은 치료하지 않는다. 현 소유권 모델은 종족 혼합을 허용하지 않으나 치료 판정 자체는 유기체 속성을 사용한다. 환자는 메딕1기만 예약할 수 있다. 수동 명령은 자동 예약을 대체하며 이미 다른 수동 예약이 있으면 거절한다.

기본 자동치료는 켜짐. 5타일 유클리드 반경에서 가까운 부상병을 안정 ID 순으로 선택한다. 매5틱 최대8기씩 순환 탐색한다. 접근은 기존 경로 탐색을 사용한다. 보이는 무장 적을 향해 주변 아군 무장 지상 유닛보다 앞서는 목표점은 자동 접근하지 않으며 진행 중 전선이 바뀌어도 멈춘다. 이 전선 제한은 이 게임의 보수적인 자동 조작 정책이며 원작 수치와 구분한다. 숨은 적 상태는 선택에 사용하지 않는다.

수동 치료는 지정한 환자를 따라가며 완치까지 유지한다. 이동·공격·정지·순찰 명령은 치료를 취소하고20틱 자동 재시도를 유예한다. 위치 사수는 사거리 내 치료만 허용한다. 메딕 탑승 대기/수송은 치료를 중단하며 탑승 경로를 덮어쓰지 않는다. 스테이시스 중에는 수동 예약을 유지하되 치료는 정지하고 에너지는 재생한다. 리콜은 관련 치료 예약을 취소한다. 사망·제거·대상 잠복/수송 등 참조 무효화는 정리한다.

부대의 명시적인 자동치료 끄기와 초기 기본값을 구분한다. 같은 메딕 부대 보충 시 설정을 상속한다. 다른 유닛 부대가 해당 슬롯을 대체하면 치료 설정을 비운다.

## 조작과 확인

기존 사이트 `/stark-rift-dev` → 테란 → 특수 연습 → 새 테스트 시작. 메딕2기(5번 슬롯,18·22/27타일), 부상 마린2기(1번 슬롯), 배럭·아카데미·추가 보급고를 명시적인 연습용으로 제공한다. 메딕 선택 → 치료 → 부상병 또는1번 슬롯. 자동치료 버튼이나 치료 버튼 길게 누르기로 전환한다. 배럭 선택 후 메딕 생산, 아카데미에서 반응로 연구가 가능하다. 회복 중 초록빛 연결선과 십자 효과를 표시한다. 양 끝 유닛이 현재 렌더 화면에 공개될 때만 연결선을 내보내며 적의 자동치료 설정과 예약 ID는 공개하지 않는다.

## 저장과 검증

엔진0.20.0-stage6j, 저장/스키마19, 프로토콜20. 형식6..18을 원래 체크섬·데이터/전투 규칙 검증 후 이행한다. 형식18의 연구·250 이하 에너지·지불된 주문·RNG·명령·수송·부대 설정을 보존한다. 기존 저장에 연습 메딕이나 자원은 추가하지 않는다. 원본18은 `.stage6i-backup`에 바이트 그대로 보존한다. 이전 형식이 새 필드를 위장하면 거절한다.

게임 회귀검사, 빌드·공유 검사·랩·성능 검사, 360/390px 실제 터치 Worker/Pixi 브라우저 치료·생산·연구·복구 및 이전 실서비스 저장 복구로 검증한다. 평지뿐 아니라 연습장의 벽·경사로를 통과하는 통합 검사를 포함한다. 첫 실제 화면 시험에서 두 번째 메딕이 벽과 광물 사이 길을 막는 배치를 발견해 경사로 아래로 옮겼다. 최종 수치와 게시 버전은 별도 검증 영수증에 기록한다. 실제 Android/iOS 기기 및 하드웨어 GPU 검증은 이 실행환경에서 수행할 수 없다.

스팀팩·리스토레이션·옵티컬 플레어, 최종 유닛 아트, 전체 승리전/AI는 이번 범위에 포함하지 않는다. 다음 후보는 마린 스팀팩 및 치료 연계다.
